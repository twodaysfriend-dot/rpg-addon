# v0.5.70 무기 손 표시·방사열선 수정

## 무기 손 표시

공용 무기 7종과 해의 한손 도끼에 추가했던 확대 attachable 8개, 손 결합 모델 8개, 1·3인칭 회전 애니메이션을 제거했습니다.
스크린샷처럼 무기가 화면을 크게 덮는 확대 평면 모델 대신 Bedrock의 기본 hand_equipped 도구 렌더링을 사용합니다.
큰 사용자 지정 표시 크기도 함께 제거하여 기본 도구 크기·손 표시로 되돌립니다.
원본 무기 PNG·인벤토리 아이콘·공격력·등급·강화·제작법은 변경하지 않았습니다.
투신 장갑의 본인에게만 보이는 별도 모델은 유지합니다.
빌드 시에도 이전 확대 모델이 재생성되지 않도록 정리 도구를 바꿨습니다.

## 방사열선

기본 피해 1을 발사 중 매 게임 틱 적용합니다. 정상 20 TPS 기준 초당 20회, 발사 100틱(5초) 동안 최대 100회입니다.
이전 초당 15회/최대 75회에서 변경했습니다. 대상이 광선에 계속 맞고 생존한 경우의 명목 합계는 기본 100입니다.
피격 무적 시간을 우회하는 공통 피해 경로를 사용하며, 엔진이 반복 타격을 거부하면 직접 HP 처리로 대체합니다.
공통 처리의 마력·힘 버프·룬·레벨 방어·흡혈·처치 기여도 처리를 유지합니다.
준비 20틱(1초), MP 180, 쿨타임 600틱(30초), 햇빛 비용 20, 사거리 10칸은 그대로입니다.
실시간 시선·위아래 조준을 따라가며, 시전자가 사망·접속 종료·차원 변경하면 중단합니다.
기술 도감과 GPT NPC가 사용하는 기술 설명을 갱신했습니다.

## 적용

이전 버전의 BP·명령어 BP·RP를 비활성화하고 v0.5.70의 세 팩만 적용합니다.
이전 리소스팩이 함께 활성화돼 있으면 새 팩에서 제거한 모델이 이전 팩에서 다시 적용될 수 있습니다.
월드를 다시 열어 새 리소스팩을 로드하세요. 렐름에서도 갱신된 월드와 리소스팩을 함께 적용합니다.
팩 UUID와 기존 캐릭터·카멜레온·장비·재화 저장 키는 유지합니다.

## 검증

바닐라 hand_equipped 설정, 확대 모델·애니메이션 제거, 원본 PNG 해시, 투신 전용 표시 유지,
매 틱 타격 100회, 엔진 타격 거부 시 대체 피해, 시전자 사망 시 중단 및 기존 기능을 자동 검사합니다.
실제 모바일·렐름의 손 표시 화면은 이 환경에서 직접 확인하지 못했습니다.
