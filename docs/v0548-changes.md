# RPG v0.5.48 — 투신 독립 히든 직업·청백색 충격파

투신을 무투가·권골의 상위 직업에서 **별개 계열의 독립 히든 직업**으로 수정했습니다. 전직 조건은 아무 2차 이상 직업에서 레벨 40·적 150마리·보스 5마리 처치입니다. 권골과 무투 계열 처치는 요구하지 않습니다. 일반 적 처치·보스 처치의 기존 공통 누적 기록을 사용합니다.

기존 투신 플레이어는 같은 직업 ID·스킬·건틀릿·쿨타임·저장 상태를 유지합니다. 무투가/권골 스킬과 패시브를 자동으로 승계하지 않습니다. 카멜레온이 배운 투신 기술도 아래 연출을 사용합니다.

첨부 이미지의 청백색 충격파·상향 발차기·연속 폭발·방사형 섬광을 참고해 기존 텍스처를 전용 파티클과 궤적으로 구성했습니다. 새로운 캐릭터 모션/자세 애니메이션을 추가한 것은 아닙니다.

| 기술 | 연출 | 피해 유지 |
|---|---|---|
| 폭멸타 | 전방으로 퍼지는 청백색 부채꼴 충격파·타격 섬광 | 기본 물리 피해 40 |
| 난참 | 연타마다 전방 충격파·청백색 타격 폭발 반복 | 10×6=60 |
| 폭열권 | 아래에서 위로 솟는 청백색 발차기 궤적·상단 섬광 | 48 |
| 파황각 | 좌우 교차하는 발차기 궤적과 연속 폭발 | 18×4=72 |
| 풍신열각 | 강화 평타 적중점의 큰 청백색 섬광·8방향 충격파 | 다음 유효 평타 한 번 ×10 |

이펙트가 주변 적에게 추가 피해를 주거나 블록을 파괴하지 않습니다. 기존 사거리·범위·피해·타수·마나·쿨타임을 유지합니다. 시전자 사망/차원 이동 시 연타 피해와 연출을 함께 중단하며, 파티클 오류가 나도 기존 공격 피해는 처리합니다. 파티클 수와 외부 예약은 제한했습니다.

/rpg:jobs, /rpg:skillguide, /rpg:ask와 명령어 안내서의 투신 설명도 갱신했습니다. 작골염양의 최근 0.7배 너프, 검호 난도 연출, 월룡륜미 180도, 힘의 물리/마법 보정 등 이전 변경을 포함합니다.

행동팩·명령어팩·리소스팩을 모두 0.5.48로 갱신하세요. 팩 UUID와 저장 정보를 유지합니다.

검증: JavaScript 290개 + Python 5개, 총 295개 통과. 전직 조건, 기존 피해량·궁극기 단일 대상 배수, 연출 발생·개수 제한, 취소 및 파티클 오류를 모의 API로 확인했습니다. 실제 Bedrock 클라이언트에서 이펙트 외형과 모바일 성능은 실기 검증하지 못했습니다.
