# RPG v0.5.46 — 작골염양 3회 베기·검호 난도 초승달 연출

작골염양을 기존 대상당 1회에서 **0.5초 간격, 최대 3회 베기**로 변경했습니다. 1.4초 동안 각 회차에 같은 적을 한 번씩 타격합니다. 타격당 기본 피해는 검사·타락검성·카멜레온 18, 검성 27로 유지하며 전부 맞으면 각각 54·81입니다. 근력·힘 버프·장비·방어·이동에 따라 실제 피해는 달라집니다.

MP 50·쿨 8초·반경 3.4칸·4초 화상은 유지합니다. 점프 돌진은 최대 7칸 이동한 뒤 남은 시간에 회전베기를 이어갑니다. 적이 범위를 벗어나면 후속 베기는 빗나갑니다. 벽에 막혀 종료되거나 시전자가 사망·무기 해제·차원 이동하면 남은 공격을 멈춥니다.

검호 난도는 매 회차 큰 청록 초승달 3개와 작은 보랏빛 참격 12개가 전방에서 교차하는 연출을 추가했습니다. 기존 검 궤적과 소리를 함께 표시합니다. 이펙트는 피해를 추가하지 않으며 기존 사거리 5.5칸·3회 타격·각 기본 피해 12(총 36)·MP 65·쿨 11초를 유지합니다. 카멜레온이 배운 기술에도 반영합니다.

/rpg:skillguide와 /rpg:ask의 현재 스킬 설명도 갱신했습니다. 월룡륜미 전방 180도·힘의 물리/마법 보정·고정 피해 유지·RPG 정보 안내·던전과 HUD 등 이전 기능을 포함합니다.

행동팩·명령어팩·리소스팩을 모두 0.5.46으로 갱신하세요. UUID와 플레이어 저장 정보는 유지합니다.

자동 검증과 모의 Bedrock API로 타격 간격·횟수·돌진 후 후속타·사망/무기 해제/차원 이동 취소·검호 난도 피해 유지와 이펙트 개수를 확인합니다. 실제 Bedrock 클라이언트의 타격 무적·시각 효과는 실기 검증하지 못했습니다.

검증 결과: JavaScript 286개 + Python 5개, 총 291개 통과.
