# RPG v0.5.50 — 천체 신전·투신 무기 표시·근접 피해 목록

## 투신 무기 표시

투신의 흑염 건틀릿에 전용 1인칭 어태처블과 렌더 조건을 추가했습니다. 다른 플레이어가 보는 손의 건틀릿 그림과 3인칭 무기 모델을 숨기고, 본인의 인벤토리 아이콘과 1인칭 표시는 유지하도록 설정했습니다. 본인 3인칭 화면에서도 숨깁니다. 버려진 아이템의 그림을 숨기는 기능은 아닙니다. 아이템 ID·피해 설정 18·시전·강화 평타·쿨타임은 변경하지 않았습니다.

실제 두 플레이어의 화면을 비교하는 렌더링 검증은 아직 하지 못했습니다. 리소스 조건·연결된 모델·텍스처와 기존 피해량은 자동 검증했습니다.

## 천체 신전: 낮에는 해, 밤에는 달

한 장소에 해의 제단과 달의 제단을 함께 둔 지름 27칸·최대 높이 15칸의 원형 천체 신전입니다. 해 쪽은 석영/금, 달 쪽은 검은 석재/자수정으로 구분하며, 기둥·상부 아치·해와 달 문양을 배치합니다. 중앙과 제단 위쪽은 하늘이 열려 있습니다.

Minecraft 시간 0~11999는 해, 12000~23999는 달 제단이 활성화됩니다. 날씨와 현실 시각이 아니라 게임의 낮·밤 기준입니다. 활성 제단에 조명이 켜지며 전환 때 채팅을 자동으로 보내지 않습니다.

- 관리자 `/rpg:templecreate`: 앞쪽 약 22칸의 빈 공간에 신전을 생성합니다. 넓은 평지에서 사용하고 건축 지역에 머물러 주세요. 기존 건축물이나 상자가 있으면 블록을 쓰기 전에 중단합니다.
- `/rpg:temple`: 신전 위치·현재 활성 제단·전직 조건과 메뉴를 확인합니다. 자동 순간이동은 하지 않습니다.
- 제단 블록과 상호작용해도 같은 전직 메뉴가 열립니다.
- 관리자 `/rpg:templeremove`: 등록과 전직 기능·보호를 해제합니다. 건물은 지우지 않습니다. 다른 곳으로 옮길 때 사용하세요.

오버월드에 신전 하나를 등록합니다. 기존 신전이 완성돼 있으면 다시 생성하지 않고 위치를 알려줍니다. 건축은 분할 실행하며 청크를 읽지 못하면 해당 위치에서 대기합니다. 완성 검사로 누락 블록을 보완하고 검사 후에만 전직 기능을 엽니다. 공사 상태를 저장하여 서버 재접속 후에도 이어갑니다. 일반 플레이어의 신전 내 블록 파괴/설치와 폭발을 막으며 관리자는 편집할 수 있습니다. 관리자가 제단을 훼손하면 전직 조건이 충족되지 않을 수 있습니다.

## 후예 전직은 신전에서만

| 직업 | 필요 조건 |
|---|---|
| 해의 후예 | 아무 2차 이상 직업·레벨 20·오버월드 낮 적 60마리 처치·낮의 해 제단 주변 4칸 |
| 달의 후예 | 아무 2차 이상 직업·레벨 20·오버월드 밤 적 60마리 처치·밤의 달 제단 주변 4칸 |

`/rpg:job`, `/rpg:jobs`, 전직 NPC, 신전 메뉴 등 일반 전직 경로에 같은 장소·시간 조건을 적용합니다. 확인창이 열린 동안 시간이 바뀌거나 신전을 벗어나면 재검사로 전직을 차단합니다. 관리자 강제 전직 기능은 기존대로 유지합니다.

이미 후예인 캐릭터는 직업·스킬·진행도를 유지하며 신전 밖에서도 기술을 사용합니다. 전직할 때만 신전 조건이 추가됩니다. 기존 낮·밤 처치 기록도 유지합니다.

## 기본 아이템에 추가 근접 피해 설정이 없는 직업

| 직업 | 기본 아이템 |
|---|---|
| 마법사 | 마법사의 마법서 |
| 현자 | 현자의 지팡이 |
| 궁수 | 궁수 활 |
| 천궁 | 천궁 활 |
| 성직자 | 성직자의 성십자 |
| 천사 | 천사의 기도 |
| 미카엘 | 미카엘의 날개 |
| 타락천사 | 타락천사의 날개 |

총 8개입니다. **추가 근접 피해 설정이 없다는 뜻이며, 근접 공격이 무조건 0이라는 뜻은 아닙니다.** 맨손 수준의 엔진 기본 피해·힘/인챈트, 활의 화살 피해와 각 기술 피해는 별도입니다. 견습은 시작 장비에 따라 다르고, 마법책·십자가·활에는 추가 근접 피해 설정이 없습니다. v0.5.49의 공용 전투검·전투창으로 평타 사냥을 보완할 수 있습니다.

전체 30개 전직 직업의 기본 아이템 설정은 [기본 아이템 근접 피해 목록](v0550-melee.md)에 기록했습니다. 이번 변경으로 기존 기본 아이템의 공격 수치를 바꾸지는 않았습니다.

## 설치·검증

행동팩·명령어팩·리소스팩을 모두 0.5.50으로 갱신하세요. UUID·기존 저장 정보·캐릭터·장비·쿨타임을 유지합니다. 기존 성장/강화 이전/상위 갑옷/공용 무기/보스 CC/솔로 보상 변경을 포함합니다. 던전 핵심 기믹 구상은 여전히 구현하지 않았습니다.

자동 검증: JavaScript 320개 + Python 5개, 총 325개 통과. 신전 도면·분할 건축·기존 블록 보호·청크 대기·완성 검사·낮밤 조건·전직 확인 재검사·보호 이벤트·투신 1인칭 전용 렌더 설정을 모의 API로 확인했습니다. 실제 Bedrock 클라이언트의 대인 렌더링과 신전 외형은 실기 검증하지 못했습니다.
