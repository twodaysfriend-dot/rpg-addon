# RPG v0.5.53 변경 안내

세 팩(행동·명령어·리소스)을 함께 0.5.53으로 갱신하세요. 기존 UUID·월드 저장 정보는 유지합니다.

| 기술 | 변경 내용 |
|---|---|
| 해커 카피 | 등록된 공격·제어 궁극기에서 무작위 발동. 순수 버프 궁극기는 제외 |
| 빙주난사 | 이동 중인 적을 추적하는 유도탄 5발. 발당 기본 마법 피해 7·합계 35 유지 |
| 대빙해소 | 기본 마법 피해 42 |
| 영점빙옥 | 기본 마법 피해 38 |
| 마공학 감옥 | 사거리 16칸에서 표식 적 우선. 표식 적이 없으면 가장 가까운 적의 위치에 설치 |
| 마공학 광선 | 직접 명중한 적에게 10초 표식 부착. 기존 기본 피해 18 유지 |
| 흡혈 | 반경 10칸의 모든 적에 영혼 빨대 연결 |
| 수확 | 기본 물리 피해 36 |
| 햇빛·달빛 충전 | 저장 상한 각각 500. 수동 +35·자연 초당 +4 유지 |
| 일륜참 | 다음 기본 도끼 타격 총 4배·둔화 III 1초 |
| 방사열선 | 충전·발사 중 현재 시선의 좌우·상하 움직임을 따라 광선과 타격 방향 변경 |
| 달의 후예 | 공격 기술 전체를 물리 피해로 통일. 근력·물리 장비·힘 버프 보정 적용 |
| 초승달 참격 | 기본 물리 피해 30 |
| 월광 차크람 | 기본 물리 피해 28 |
| 만월의 파동 | 기본 물리 피해 50 |

카피는 데이터에 등록된 궁극기 여부와 실제 직업·실행 함수를 확인합니다. 현재 후보는 **17종**입니다: 일륜강림, 만월의 파동, 공포의 폭풍, 마공학 폭풍, 그림자 암살, 염제, 영점빙옥, 복수귀 처형, 적박, EMP, 현월수룡, 러쉬, 대폭발, 천궁, 권골 궁극기, 졸트라크, 종말. 정확한 기술명은 현재 스킬 도감에서 확인할 수 있습니다. 순수 강화·지원 기술인 광분화·축복 영역·다음 평타 강화인 풍신열각은 카피하지 않습니다. 공격과 버프를 함께 주는 일륜강림·염제·현월수룡은 공격 궁극기로 포함합니다. 표식·최근 공격 대상·빛 등 원래 조건이 충족되지 않는 후보는 건너뛰고 다른 후보를 시도합니다. 카피 자체의 마나·쿨타임만 지불하며 원래 직업은 바뀌지 않습니다. 야수 대폭발의 지연 타격도 해커에게서 정상 작동합니다.

빙주난사는 가까운 사거리 안의 적 중 시선 방향을 우선하고, 적이 여러 명이면 다섯 발을 분산합니다. 각각 비행 중 대상을 추적하며 벽에 닿거나 실제 비행 거리 24칸이 끝나면 사라집니다. 살아 있는 대상이 없으면 발동하지 않습니다. 아군/PvP 보호를 유지합니다.

마공학 감옥은 조준한 허공이나 지면이 아닌 선택한 적의 위치에 설치됩니다. 표식이 여러 개면 사거리 안에서 가장 가까운 표식 적을 고릅니다. 유효한 적이 없으면 발동하지 않습니다. 기존 반경 4칸·6초 지속·둔화 IV·내부 적 표식 갱신을 유지합니다. 광선은 보조 기계팔 높이에 맞게 몸통 판정 높이도 조정하여 일반 몹 명중·표식을 확인했습니다.

흡혈은 반경 10칸 안의 적 각각에 기존 기본 마법 피해 12를 한 번 주고, 적중 수만큼의 재생 단계(최대 50)를 7초 부여합니다. 빨대는 이 시간 동안 지속해서 표시되며 **추가 지속 피해를 새로 주지는 않습니다**. 대상 사망·아군 전환·차원 변경·반경 이탈 시 연결을 해제하고, 시전자 사망·차원 변경 시 전체 연결을 종료합니다.

방사열선의 준비 1초·사거리 10칸·지속 5초·초당 15회 기본 피해 1·마나·쿨타임은 유지합니다. 타격은 현재 시선의 3차원 광선 주위로 판정하며 화면 이펙트도 같은 방향을 사용합니다. 일륜참은 스킬 타격으로 소모되지 않고 다음 유효 기본 도끼 공격에 적용됩니다.

달의 후예의 일반 차크람 투척 기본 물리 피해 11은 유지합니다. 차크람 분열의 소형 차크람도 각 기본 물리 피해 4에 근력·물리 장비 보정을 받습니다. 달빛 회복의 최대 HP 50%·보유 달빛 30% 소비는 유지하며, 달의 후예의 마나 체계도 유지합니다.

표의 피해량은 능력치·장비 보정 전 수치입니다. 보스 CC 절반·파티 보호·카멜레온 호환과 이전 버전의 기능을 포함합니다. 게임 내 `/rpg:skillguide` 및 `/rpg:ask`의 안내도 갱신했습니다.

검증: 자동 검사 352개(JavaScript 347 + Python 5), JSON·JS·리소스·팩 버전·압축 무결성 검사. 실제 Bedrock 클라이언트에서의 전투·렌더링은 별도 확인이 필요합니다.
