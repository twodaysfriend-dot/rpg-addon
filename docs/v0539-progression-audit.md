# v0.5.39 게임 진행 점검

검토 기준은 v0.5.38에서 이어온 현재 코드·조합법·전직 조건·보상입니다. 일부 경험치/진행도는 모의 Bedrock API의 실제 사망 처리 경로로 확인했습니다. 실제 클라이언트 플레이 시간·승률을 측정한 결과는 아닙니다. 아래 제안은 분석이며 자동 적용하지 않았습니다.

## 이번에 적용한 수정

첫 접속·재접속·스크립트 시작 시 계열 선택창이 자동으로 열리는 동작을 제거했습니다. `/rpg:guide`를 직접 실행하면 시작 장비 선택·첫 사냥 보상을 사용할 수 있습니다. 기존 선택·보상 기록을 유지하며 전직 조건과 전투 밸런스는 변경하지 않았습니다. 시작 장비를 자동 지급하는 새 기능은 넣지 않았습니다.

## 진행 순서에서 막히는 지점

|---|---|---|---|
| 처음 접속 | 견습은 직업 무기가 없고, 시작 장비는 수동 `/rpg:guide` 또는 관리자 지급 경로. 대부분의 RPG 몹은 어두운 지상에서 생성 | 명령어를 모르는 초보자는 낮에 할 일을 찾기 어려움 | 계열 선택 없이 받는 공용 입문 장비·안내 NPC·낮에도 이용 가능한 초보 사냥터 |
| 레벨 10 첫 전직 | 검사 다이아 검 5개, 마법사 효과부여 책 10권, 무투가 샌드백 2개 | 레벨보다 자원 수급에 막힘. 평지맵에 자원·구조물·지급처가 없으면 일부 경로가 닫힘 | 기존 공물 조건을 유지하면서 재료를 얻는 일일 의뢰·상점·입문 던전 보상 추가 |

### 첫 전직의 직업별 격차

- 검사: 다이아몬드 검 5개를 직접 제작한다면 다이아몬드 10개가 필요합니다. 정상적인 자원 월드에선 가능하지만 첫 전직을 위해 채굴·거래 단계가 강제됩니다.
- 마법사: 효과부여 책 10권의 RPG 전용 확정 공급처가 없습니다. 바닐라 인챈트·낚시·주민 거래·전리품 등에 의존합니다. 초반에 마법을 쓰던 사람이 오랫동안 견습으로 남을 수 있습니다.
- 무투가: 샌드백 1개는 건초더미 9개, 밀 81개. 첫 전직 2개는 밀 162개·총 샌드백 HP 6,000. 권골의 추가 10개까지 직접 제작하면 누적 밀 972개입니다. 대미지가 없는 표적을 오래 때리는 과정은 난이도보다 반복 노동에 가깝습니다. 제작법과 요구 개수는 사용자 지정이므로 이번에는 유지했습니다.
- 궁수: 20칸 밖 과녁 명중은 자원만 준비되면 짧은 도전으로 끝납니다. 첫 궁수 전직 조건은 바닐라 활로도 기록할 수 있습니다. 과녁과 활·화살의 상시 제공처가 있으면 다른 직업보다 빠릅니다.
- 성직자: 레벨 10에서 `/rpg:jobs`의 전직 확인으로 진행할 수 있어 공물이 필요한 직업보다 접근이 쉽습니다.

레벨 1→10은 총 **1,848 RPG XP**입니다. 20 XP 적만 잡으면 **93마리**, 수동 안내의 첫 사냥 보상 100 XP까지 받으면 **88마리**입니다. 첫 사냥 5마리 보상은 레벨 2 근처이지 곧바로 전직시키는 보상이 아닙니다. 파티에 속하면 각자 75% XP라 필요한 처치 수는 달라집니다.

### 높은 던전으로 올라갈 이유가 약함

모든 몹 처치 재화가 해당 플레이어에게 전부 들어왔을 때 1회 총 골드는 다음과 같습니다. 반경 밖에 있거나 도중 사망하면 실제 수령량은 달라집니다.

- 1단계: 일반 5,700 + 엘리트 1,800 + 보스 3,600 + 클리어 2,000 = **13,100 골드**.
- 10단계: 동일 처치 골드 + 클리어 3,800 = **14,900 골드**. 총량 차이는 **약 13.7%**입니다.
- 10단계 HP 배율은 5.2이며 기본 보스도 바위 골렘에서 마공학 골렘으로 바뀝니다. 보스 HP는 600→7,280입니다.
- 촉매 확정 4개·3회마다 추가 1개, 룬 보급 순환, 기본 제작 재료에는 난이도별 전용 보상이 없습니다.

따라서 높은 단계는 도전 콘텐츠이지만 반복 파밍의 보상 근거는 약합니다. 최적 효율이 항상 1단계라고 실측한 것은 아니며, 실제 클리어 속도에 따라 달라집니다.

### 경험치와 전직의 연결이 약함

현재 모의 사망 이벤트에서 좀비·초록 고블린·엘리트 초록 고블린은 모두 **20 XP**입니다. 엘리트는 재화가 더 많지만 XP는 더 많지 않습니다. **닭도 20 XP**를 주는데 적 처치 시련과 재화는 주지 않습니다. 동물 농장으로 레벨을 올려도 전직 진행은 멈춘 상태가 가능합니다. 동물 XP의 감축/제외와 엘리트 XP 상향을 별도 검토할 만합니다.

파티 처치 진행을 공유하지 않는 현재 설계에서는 서포터·쩔 받은 플레이어가 레벨 요건을 먼저 채우고 보스 막타 요건에서 막힐 수 있습니다. 75% 경험치 공유 자체는 요청한 대로 작동하고 있습니다.

## 개선 우선순위

1. **첫 전직 재료 공급 + 명령어를 몰라도 찾는 안내 NPC**. 검사·마법사가 평지맵에서도 시작할 수 있어야 합니다. 첫 접속 계열 선택창을 다시 띄우는 방식은 권하지 않습니다.
2. **입문 사냥터/장비와 던전 운영 준비**. 초보자용 일반→엘리트→보스 순서로 실제 도전할 수 있게 연결합니다.
3. **파티 전직 시련 기여도 인정 + 스탯 재분배**. 성장했는데 전직/학습을 못 하는 상황을 줄입니다.
4. **미카엘 빛 수급 추가 + 상위 던전 고유 보상**. 지정된 조건을 낮추지 않고 획득 경로를 늘리는 방향입니다.
5. **동물 XP·엘리트 XP 구분**, 반복 파밍 외에 직업 의뢰·보스 도감 등 중간 목표를 추가합니다.

솔로 플레이에서 타락천사의 '치유한 다른 플레이어 사망 5회 목격'을 완료할 수 없고, 해커는 월드 최초 1명만 전직합니다. 이는 사용자가 지정한 조건이며 버그로 분류하거나 이번에 변경하지 않았습니다. 히든 직업의 이름과 조건이 `/rpg:jobs`에 모두 공개되는 점은 비밀을 찾는 재미를 줄입니다.

약 20시간 풀강 수치는 사냥/던전 속도를 가정한 강화 재화 모델입니다. 첫 전직 재료 채집·초기 던전 준비·실패/귀환·대기 시간까지 합친 처음 접속부터의 실측 완성 시간이 아닙니다. 레벨 100까지 20 XP 적만 잡으면 총 742,038 XP·37,102마리이며, 5초당 한 마리라는 가정을 써도 약 51.5시간입니다. 보스 XP·파티·첫 사냥 보상에 따라 달라집니다.
