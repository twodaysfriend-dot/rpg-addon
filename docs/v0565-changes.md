# RPG v0.5.65 — 견습 5계열 자유 체험

견습 상태에서 시작 계열과 관계없이 검·마법·활·격투·회복 견습 장비를 자유롭게 바꿔 사용할 수 있습니다.

사용: `/rpg:guide` → `견습 5계열 체험` → 체험할 계열 선택. 관리자 권한은 필요 없습니다. 받은 장비를 손에 들어 사용하세요. 이미 한 계열을 선택한 기존 견습도 사용할 수 있습니다. 다른 플레이어에게서 얻거나 보관해 둔 견습 장비도 원래 시작 계열과 관계없이 해당 견습 기술을 사용할 수 있습니다.

- 검·격투 견습은 기본 공격을, 마법은 파이어볼·라이트닝, 회복은 힐, 활은 에어워크·연사를 체험합니다. 정식 전직 직업의 전체 기술을 미리 지급하는 기능은 아닙니다.
- 가방에 없는 견습 장비만 보충합니다. 가방에 이미 있는 같은 장비는 중복 지급하지 않습니다. 분실했거나 전직 후 견습으로 돌아와 장비가 없으면 다시 보충할 수 있습니다.
- 시작 빵 16개와 체험 화살 64개는 각각 한 번만 지급합니다. 체험 계열 변경·재접속·장비 재지급으로 추가 지급되지 않습니다.
- 첫 사냥 5마리 진행도와 보상 수령 여부는 체험 계열을 바꿔도 유지합니다. 전직 조건·SP·경험치를 임의로 초기화하지 않습니다.
- 인벤토리가 가득 차면 다른 아이템을 덮어쓰지 않습니다. 저장 실패 시 체험 장비·기술 목록·체험 기록을 복구합니다.
- 정식 전직 후에는 기존 직업의 장비·기술 제한을 그대로 적용합니다.
- 시작 선택창은 첫 접속에 자동으로 열리지 않습니다. `/rpg:guide`에서 원할 때 시작하세요.

종합 룰북과 GPT 시작 안내도 수정했습니다. 동봉 BP·명령어 BP·RP를 모두 0.5.65로 갱신·활성화하세요. 기존 팩 UUID와 저장 데이터를 유지합니다. 이전 버전의 통합 공물·평화 서버·사냥 구역·룰북·전직관 소환알·구조물 보호·장비 강화/합성을 포함합니다.

자동 테스트 441개(JavaScript 436 + Python 5)를 검증합니다. 실제 모바일 Bedrock 플레이는 미검증입니다.
