# RPG v0.5.64 — 통합 공물·평화 서버 종합 룰북·사냥 구역

## 명령 통합
- `/rpg:offer`: 검과 책을 바칩니다. 인벤토리와 현재 직업·진행도에 맞춰 공물을 처리합니다.
- 기존 `/rpg:book`, `/rpg:sword` 등록과 실행 경로를 제거했습니다. 기존 스크립트 이벤트·채팅 경로로도 옛 공물 동작을 실행하지 않습니다.
- 전직 메뉴의 공물 버튼도 같은 기능으로 통일했습니다. 별도 비공개 공물 안내 버튼은 제거했습니다. 공개 명령 설명과 룰북에는 검과 책만 안내합니다.
- 검은 필요한 시련 수량까지만 소비합니다. 효과부여 책은 마법공학 시련의 남은 수량에 먼저 사용하고, 나머지는 기존 마나 공물 규칙으로 처리합니다. 같은 책을 중복 계산하지 않습니다.
- 공물 저장에 실패하면 소비한 아이템·진행도·마나를 함께 복구합니다.

## 평화 서버 종합 룰북
`/rpg:rulebook`으로 41쪽의 서명된 종합 룰북을 받습니다. 서명 후에는 플레이어가 내용을 직접 편집할 수 없습니다. 기존 책은 자동으로 바뀌지 않으므로 새로 받으세요.

기초 규칙, RPG 레벨·SP, 조작, 공물, 기본 직업, 물리/마법·마나, 파티·길드, 재화, 룬 6종의 획득·보관·장착·효과, 갑옷, 공용 무기, 강화 위험·촉매·이전, 등급 합성, 던전 입장·시간·귀환·보상, 신전과 보호, 초기화 아이템, 일반 플레이 명령어를 정리했습니다.

관리자 명령과 히든 직업 전직 방법은 룰북에서 제외했습니다. 페이지는 한 장 최대 14줄·256자 미만, 전체 50쪽 이내로 나눠 모바일에서 읽기 쉽게 구성했습니다. Markdown판은 v0564_평화서버_종합룰북.md입니다.

## 사냥 구역과 밤 몬스터
현재 적용한 기준은 오버월드 X·Z 중 절댓값이 큰 값입니다. Y는 무관합니다. 경계값은 안쪽 구역에 포함됩니다.

| 구역 | 좌표 기준 | 밤에 자연 출현하는 RPG 몬스터 |
|---|---|---|
| 초반 | X·Z 모두 -1500~+1500 | 빨간 버섯·파란 버섯·초록 고블린 |
| 중반 | 초반 밖, X·Z 모두 -4000~+4000 | 빨간 고블린·황금 고블린·대장 고블린 |
| 후반 | 중반 밖, X·Z 모두 -10000~+10000 | 엘리트 버섯·고블린 6종 |
| 10000 바깥 | 후반 연장 | 후반 몬스터 유지 |

실제 생성 위치로 구역을 판정합니다. 예: X=-1500,Z=0은 초반, X=1501,Z=0은 중반, X=0,Z=-4001은 후반입니다. X=1500,Z=1500도 초반입니다. 기본 설정은 data/huntingZones.js의 HUNT_ZONE_SETTINGS에 있습니다.

기존 엔진의 어두움·표면·몹 수 제한·생물군계 판정을 유지하며, 자연 출현한 몹의 종류를 해당 구역 풀에 맞춥니다. 밤은 게임 시간 12000~23999로 제한합니다. 일반 숲 RPG 몬스터는 사막 생물군계에서 자연 출현하지 않게 했습니다. 던전 전투 몹과 수동 소환알은 구역 변환 대상에서 제외합니다.

## 바닐라 동굴·사막 예외
- 오버월드 바닐라 적대 몹의 자연 출현을 동굴로 제한합니다. 소·돼지 등 동물의 출현은 유지합니다.
- Bedrock 1.21.100.6 공식 규칙을 바탕으로 바닐라 14종의 표면 출현을 제거하고 기존 생물군계·난이도 조건을 보존했습니다. 네더·엔드의 기존 엔더맨 생태는 유지합니다.
- 자연 출현 이벤트에서도 지형으로 덮인 동굴인지 검사해 단순한 높이 제한이나 나뭇잎 아래를 동굴로 취급하지 않도록 보완했습니다. 스포너·수동 소환·변신·기존 몹 이동은 자연 출현 제한과 별개입니다.
- 사막 전갈·사마귀·데스웜과 각 엘리트, 총 6종은 기존 사막 생물군계·바닥·밀도 조건을 유지하며 밝기 0~15에서 출현합니다. 낮밤·사냥 좌표 제한은 없습니다.

## PvE 설정
RPG 플레이어 대상 공격을 끄고 바닐라 PvP 게임 규칙도 비활성화했습니다. 불면증에 의한 지상 팬텀 출현도 끕니다. 난이도를 Peaceful로 바꾸는 기능은 아니며 몬스터 전투는 유지합니다. PvP 비활성화 상태에서도 좌클릭 회복·아군 지원 기술을 사용할 수 있게 보완했습니다.

## 설치·검증
동봉 BP·명령어 BP·RP를 모두 0.5.64로 갱신·활성화하세요. UUID, 장비·강화·등급·전직 진행도, 기존 전직관·던전·신전 등록을 유지합니다. 이전 버전의 공용 무기 손 표시·구조물 보호·실패 정리·일반 상위 직업 분류 수정도 포함합니다.

자동 테스트 435개(JavaScript 430 + Python 5)를 통과했습니다. 통합 공물·복구·옛 명령 제거·서명 룰북·페이지 한계·PvE 회복·좌표 경계·밤/낮·던전/사막 예외·동굴 규칙·원본 도트·팩 무결성을 확인했습니다. 실제 모바일 Bedrock에서 자연 출현 빈도와 플레이는 실측하지 않았습니다.
