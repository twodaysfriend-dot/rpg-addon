# RPG v0.5.34 — 난이도 1~10 원형 동굴 던전

## 생성과 입장

관리자가 오버월드의 빈 지역에서 다음 명령어로 10개를 한 번에 생성합니다.

```mcfunction
/rpg:dungeoncreate all
```

난이도 하나만 만들려면 `/rpg:dungeoncreate 1`처럼 1~10을 입력합니다. 10개는 96칸 간격의 5×2 배치이며, 원형 동굴은 지름 약 65칸·최대 높이 약 28칸입니다. 자연석 외벽과 돔형 천장, 넓은 원형 바닥을 만듭니다. 시전자보다 약 64칸 위의 빈 공간에 생성하여 기존 땅이나 건축물을 파내지 않습니다. 월드 높이 상한 때문에 바닥 Y는 80~276 범위로 조정합니다.

기존 블록을 발견하면 해당 동굴 건설을 중단합니다. 생성은 차례로 진행하고 임시 tickingarea 하나씩으로 청크를 불러온 뒤 해제합니다. 월드의 tickingarea 여유가 있어야 하며 생성 완료 안내를 기다리세요. 중단된 건설은 같은 명령어로 재개할 수 있습니다. `/rpg:dungeonremove 1`은 등록을 해제하되 건축물은 보존합니다.

플레이어는 각자 원하는 난이도에 직접 참가합니다.

```mcfunction
/rpg:dungeon
/rpg:dungeon 1
/rpg:dungeonstart
/rpg:dungeonsolo 1
/rpg:dungeonleave
/rpg:dungeonloot
```

- `/rpg:dungeon`: 난이도 10개 목록, 현재 대기실 또는 전투 진행 상태.
- `/rpg:dungeon 1`: 본인만 1단계 대기실에 참가. 실제 RPG 파티에 속해 있어도 파티원을 자동 등록·이동시키지 않습니다.
- `/rpg:dungeonstart`: 대기실 첫 참가자가 현재 인원으로 출발. **1~4명**이면 시작할 수 있어 4명을 기다릴 필요가 없습니다. 각자 참가를 선택한 사람만 이동합니다. 대기실 첫 참가자가 나가면 다음 사람에게 시작 권한이 넘어갑니다.
- `/rpg:dungeonsolo 1`: 1단계에 혼자 바로 입장. 다른 플레이어가 대기·진행 중인 같은 던전은 혼자 차지할 수 없습니다.
- `/rpg:dungeonleave`: 대기 취소 또는 전투 퇴장·입장 위치 귀환.
- `/rpg:dungeonloot`: 가방 부족으로 저장된 보급품 수령.

각 난이도의 동시 정원은 4명이며 하나의 전투만 진행합니다. 서로 다른 난이도 10곳은 독립적으로 진행할 수 있습니다. 참가자는 생존·서바이벌 상태여야 하며 대기실은 실제 파티와 별개입니다. 처치 XP 공유는 기존 실제 파티·32칸 규칙을 유지하고, 클리어 보상은 생존한 던전 참가자에게 각각 지급합니다. 명령어 목록이 안 보이는 경우 기존 `!rpg dungeon 1`, `!rpg dungeonstart`, `!rpg dungeonsolo 1` 전달 경로도 지원합니다.

## 일반·엘리트 단계: 5분

**일반 몬스터 50마리와 엘리트 5마리를 모두 처치**해야 합니다.

처음부터 55마리를 한꺼번에 생성하지 않습니다. 일반 3마리로 시작하며, 기본적으로 6초마다 최대 2마리가 추가됩니다. 처치하면 다음 일반 몬스터 보충 시점을 약 1초 뒤로 당깁니다. 엘리트는 기본 40초 간격으로 한 마리씩 등장합니다. 늦게 등장해야 할 엘리트가 누적되어도 최소 5초 간격을 두며, 동시 생존 수는 일반·엘리트 합쳐 최대 12마리입니다. 공간이 차 있으면 처치하여 자리를 만들어야 다음 적이 나옵니다.

일반 생성 총량은 정확히 50, 엘리트는 정확히 5입니다. 실제 처치 이벤트만 진행도로 세며, 몬스터가 사라지거나 단순 제거된 것을 처치로 간주하지 않습니다. 한 마리의 사망 이벤트가 중복되어도 한 번만 셉니다.

목적지 청크를 불러오고 초기 적이 실제로 등장한 순간부터 **5:00**이 시작됩니다. 처치하거나 다음 적이 나타나도 이 5분은 갱신되지 않습니다. 5분이 되기 전에 55마리를 모두 잡지 못하면 참가자 전원을 원래 위치로 돌려보내고 몬스터를 정리하며, 클리어 보상은 지급하지 않습니다.

## 보스 단계: 새로 3분

일반 50마리와 엘리트 5마리를 전부 잡으면 **보스 1마리**가 등장합니다. 일부만 잡았거나 아직 생성되지 않은 몬스터가 남아 있으면 보스를 생성하지 않습니다.

보스가 실제 등장한 순간부터 별도의 **3:00**이 시작됩니다. 일반·엘리트 단계에서 남은 시간은 보스 단계에 합치지 않습니다. 보스를 3분 안에 잡으면 클리어하고, 3분이 되면 남은 참가자를 모두 퇴장시키며 클리어 보상은 지급하지 않습니다. 제한 시각과 정확히 같은 순간의 처치는 시간 초과로 처리합니다. 사망 이벤트에서도 시각을 검사하므로 주기 검사 사이의 늦은 막타로 보상을 받을 수 없습니다.

화면 액션바에 난이도·일반/엘리트 처치 수·남은 시간이 표시됩니다. 보스 단계에는 보스 제한 시간이 표시됩니다. 기존 숫자 체력과 선택 스킬 정보도 함께 유지합니다.

## 난이도 구성

기존 몬스터·보스를 사용하되 던전에서 생성할 때만 별도 체력·기본 근접 피해 배율을 적용합니다. 필드 몬스터 원본 수치를 바꾸지 않습니다. 보스의 특수 투사체·스크립트 패턴 피해까지 같은 배율로 증폭하는 방식은 아닙니다.

| 단계 | 이름 | 주요 일반 몬스터 | 보스 | 보스 HP | 체력 배율 |
|---:|---|---|---|---:|---:|
| 1 | 이끼 동굴 | 초록 고블린 | 바위 골렘 | 600 | 1.00 |
| 2 | 붉은 수정굴 | 초록·붉은 고블린 | 바위 골렘 | 750 | 1.25 |
| 3 | 균사의 동굴 | 붉은 고블린·푸른 버섯 | 바위 골렘 | 900 | 1.50 |
| 4 | 사마귀 둥지 | 사마귀·붉은 고블린 | 외눈 거인 | 1,530 | 1.80 |
| 5 | 전갈 소굴 | 전갈·사마귀 | 외눈 거인 | 1,785 | 2.10 |

엘리트도 난이도별 구성과 체력 배율을 적용합니다. 기본 근접 피해는 1단계 1배부터 단계마다 0.15씩 증가하여 10단계에서 2.35배입니다. 혼자 입장할 수 있지만 고난이도를 모든 직업·장비가 혼자 클리어할 수 있다고 보장하는 것은 아닙니다.

## 보상과 기존 데이터

기존 강화 재화·촉매·룬·제작 재료 보급을 유지합니다. 기본 클리어 보상은 골드 2,000·강화석 8·룬 가루 2이며, 상위 난이도는 단계마다 이 재화 보상을 10%씩 추가합니다. 촉매는 각자 4개·개인 누적 3회차마다 +1개, 룬은 매번 순환 1개, 최초 클리어 모험가 갑옷 4부위입니다. 가방 부족 보급품은 저장하고 보상 번호로 중복 지급을 막습니다. 실패 전 이미 처치한 몬스터의 기본 XP·재화는 회수하지 않습니다.

[풀강 비용과 약 20시간 목표](v0534-enhancement-costs.md)의 강화 위험·요금과 사냥 보상은 유지했습니다. 그 시간 모델의 던전 1회 10분은 전투 최대 8분에 입장·대기·정비 시간을 더한 가정이며 실제 클리어 시간 측정이나 고정 완성 보장이 아닙니다.

v0.5.33의 사각 방 던전은 새 난이도로 자동 개조하지 않습니다. 기존 건축물은 보존하고 이전 던전 등록은 이전 기록으로 옮깁니다. 새로 `/rpg:dungeoncreate all`을 실행해야 원형 동굴 10개가 만들어집니다. 이전 진행 중 전투는 종료하고 저장된 귀환 위치·미지급 보상·클리어 누적·강화 상태를 유지합니다. 재접속으로 스킬 쿨타임이 초기화되지 않습니다.

개별 사망·퇴장은 해당 참가자만 이탈시키고 나머지는 계속 진행합니다. 전원이 이탈하면 전투를 정리합니다. 서버 재시작 시 전투는 종료하고 귀환 위치를 복구하며 대기실은 비웁니다. 동굴 블록 설치·파괴·폭발 피해 보호도 유지합니다.

검증은 모의 API 자동 테스트와 팩 무결성 검사입니다. 실제 Bedrock 클라이언트의 동굴 외형·청크 로딩 속도·전투 난이도는 실기 테스트를 수행하지 못했습니다.
