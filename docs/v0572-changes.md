# RPG v0.5.72 — 무기 자세·플레이어 전투·결투·PK

## 손에 든 무기

이전 버전의 1인칭 arm guide 역변환과 별도 플레이어 팔 뼈대를 제거했습니다. Mojang bedrock-samples v1.21.100.6의 바닐라 삼지창과 같은 아이템 슬롯 바인딩, pole 피벗 및 1인칭·3인칭 기본 착용 애니메이션을 사용합니다. 원본 도트의 손잡이를 기준으로 실루엣 방향을 먼저 맞춘 뒤 이 좌표계에 배치합니다.

공용·직업 무기 중 보이는 39종의 표시 면은 기본 16단위에서 32단위로 확대했던 크기를 유지합니다. 원본 PNG, 인벤토리 아이콘은 변경하지 않았습니다. 투신 장갑의 본인 1인칭 전용 표시와 보이지 않는 격투 주먹도 유지합니다. 픽셀별 옆면 큐브는 추가하지 않습니다.

모델 구조·원본 도트 보존은 자동 검사했습니다. 실제 Bedrock 모바일 1인칭·3인칭 화면은 이 환경에서 실행하여 확인하지 못했습니다.

## 플레이어 전투와 결투

일반 플레이어 전투를 활성화했습니다. RPG 공격 스킬도 플레이어를 대상으로 사용할 수 있습니다. 기존 RPG 파티·길드 아군 판정은 유지하고, 동의한 결투 상대에게는 이를 해제합니다.

- `/rpg:pvp`: 가까운 플레이어 선택 / 받은 결투 수락·거절 / 진행 중 결투 항복 메뉴.
- `/rpg:pvp "플레이어 이름"`: 결투 신청.
- `/rpg:pvp accept`: 받은 신청 수락.
- `/rpg:pvp reject`: 거절.
- `/rpg:pvp surrender`: 항복.

Bedrock 스크립트 사용자 명령은 네임스페이스를 요구하므로 정식 명령은 `/rpg:pvp`입니다. `/pvp` 별칭 등록도 시도하지만 이를 거부하는 버전에서는 사용할 수 없습니다. 채팅 이벤트가 지원되는 환경에서는 `!pvp`도 같은 기능으로 연결됩니다.

신청은 같은 차원 32칸 이내의 생존 서바이벌 플레이어에게 보내며 30초간 유효합니다. 던전이나 다른 결투 진행 중에는 참가할 수 없습니다. 신청만으로는 회복되지 않습니다. 상대가 수락하면 둘 다 최대 HP로 회복하고, 3초 준비 후 다시 최대 HP로 맞춰 시작합니다. 마나·스킬 쿨타임은 초기화하지 않습니다.

결투 중에는 상대 이외의 플레이어·몹 피해를 차단합니다. 일반 공격·직접 HP 차감·처형 공격을 결투 판정에 연결했습니다. 플레이어 기본 정의에 임시 최소 HP 1 그룹을 추가하여 바닐라 치명타도 패배 직전에 종료하도록 구성했습니다. 종료 후 HP를 회복하고 3초간 추가 타격을 막은 뒤 이 그룹을 해제합니다. 결투에는 PK 표식이나 현상금이 적용되지 않습니다. 실제 최소 HP 적용 여부도 읽어 확인하며, 새 플레이어 정의가 적용되지 않은 경우에는 결투를 시작하지 않습니다.

항복·접속 종료·48칸 초과 이탈·차원 변경·5분 초과 등으로 종료됩니다. 접속 종료 시 남은 상대를 승자로 처리합니다. 월드 재시작·재접속 시 남은 임시 결투 보호도 정리합니다.

## PK 패널티와 현상금

합의된 결투 밖에서 일반 플레이어를 살해하면 붉은 `[PK]` 표식과 현상금 대상 상태가 저장됩니다. 재접속·월드 재시작·환경 사망으로 지워지지 않습니다. 다른 플레이어에게 처치되면 해제됩니다.

PK 상태 플레이어를 처치하면 **그 플레이어의 골드 지갑에서 최대 50,000골드**를 차감하여 처치자에게 지급합니다. 잔액이 적으면 있는 만큼만 이전하며 음수 지갑이나 추가 골드를 만들지 않습니다. 수령자의 지갑 상한도 넘기지 않습니다. 강화석·룬 가루는 차감하지 않습니다.

PK 대상 처치에는 새로운 PK 패널티를 부여하지 않습니다. 처치자에게 기존 PK 표식이 있었다면 그 표식은 유지됩니다. 결투에서 PK 대상을 이겨도 현상금을 받거나 상대 표식을 지우지 않습니다.

플레이어·소유 투사체·소유 소환수와 최근 10초 내 타격 후 간접 사망의 처치자를 추적합니다. 최근 공격자가 접속을 끊어도 PK를 기록하며, 현상금 수령자가 오프라인이면 차감액을 보관했다가 재접속 시 지급합니다. 중복 사망 이벤트의 중복 지급을 막고 지갑/PK 저장 실패 시 이전을 되돌립니다.

## 기존 기능·설치·검증

직업 기본 무기 36종의 등급 없는 +10 강화, 공용 무기의 등급·강화, 해의 후예 방사열선 틱 피해, 기존 던전·전직·룬·장비 기능을 유지합니다. 기존 팩 UUID와 캐릭터 레벨·카멜레온 기술·지갑·장비 저장 키도 유지합니다.

기존 팩을 비활성화하고 새 **RPG BP·RPG Commands BP·RPG RP 세 팩**을 함께 적용한 뒤 월드를 다시 여세요. `/rpg:rulebook`으로 PvP·PK 규칙이 반영된 새 룰북을 받을 수 있습니다.

자동 검사는 게임 API 모의 환경에서 실행하며 실제 Bedrock 모바일·Realm 실행 검증과는 구분됩니다. 플레이어 기본 정의의 원본·변경 범위는 `v0572_플레이어정의_출처.md`와 `vanilla_player_base.json`에 보관합니다.
