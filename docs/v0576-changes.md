# RPG v0.5.76 — 바닐라 검 기본 자세에 10° 추가

이번 버전의 기준은 **마크 기본 도구/검의 실제 잡는 자세 + 추가 가로 기울기 10°**입니다. 세로축에서 10°가 되는 자세를 새로 만드는 방식은 제거했습니다.

## 표시 방식

공용·직업 표시 아이템 39종의 별도 attachable 모델을 제거하여 `minecraft:hand_equipped` 기본 도구 렌더러로 표시합니다. 원본 아이콘 PNG를 엔진이 그대로 렌더링하고, 바닐라 플레이어의 잡기·휘두르기·걷기·교체 애니메이션을 유지합니다.

플레이어의 손 아이템 뼈대(`rightItem`)에만 작은 추가 회전을 적용합니다. 1인칭·3인칭의 기본 팔 자세를 보존한 상태에서 가로 방향으로 10°를 더 기울입니다. 기본 검 자세 자체를 취소하거나 화면의 세로 방향으로 고정하지 않습니다.

기존 2배 크기는 같은 손 아이템 뼈대의 배율 2로 유지합니다. 몸·팔·기본 마크 아이템은 확대하지 않습니다. RPG 39종을 주손에 들 때만 적용하며, 반대손·인벤토리 캐릭터 미리보기·지도 얼굴에는 적용하지 않습니다.

투신 장갑의 본인 1인칭 전용 표시와 보이지 않는 격투 주먹은 별도 모델을 유지하며 이번 추가 회전·배율 대상에서 제외합니다.

## 유지한 데이터

원본 PNG·아이콘·아이템 ID·공격력·강화·등급·제작·직업·스킬·PvP·PK·지갑·성장 저장 식별자는 유지했습니다. 팩 UUID도 동일합니다. 이번 수정은 클라이언트의 손 표시 방식입니다.

## 적용

**이전 버전 RP를 모두 비활성화**하고 새 BP·명령어 BP·RP 세 팩을 v0.5.76으로 적용한 뒤 월드를 다시 여세요. 이전 RP가 함께 활성화되면 이번에 제거한 별도 무기 모델이 그 팩에서 다시 적용될 수 있습니다.

## 검증

JavaScript 496개 + Python 5개, 총 501개 자동 검사를 통과했습니다. 원본 플레이어 정의 보존, 교체 무기 모델 제거, RPG 무기만 선택되는 조건, 원래 자세에 10°가 추가되는 행렬 합성, 2배 배율·원본 PNG·투신 표시 보존을 검사했습니다.
