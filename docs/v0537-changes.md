# v0.5.37 변경 사항

- 돌진의 안전한 바닥·절대 Y좌표·용암 지형 제한을 제거했습니다. 낮은 평지 월드와 공중에서도 사용할 수 있습니다. 실제 벽/블록과의 충돌 검사는 유지합니다.
- 수정 대상: 작골염양의 점프 돌진, 용의 질주, 무쌍돌격, 암살자 회전베기 및 그림자 이동의 도착 검사, 복수귀 영혼분리, 망나니·야수 3연베기. 기존 화염·냉기·작살 돌진 방식은 유지합니다.
- 흑섬의 표시 이름을 **천멸격**으로 바꿨습니다. 다음 유효 기본 근접 공격 한 번 ×10, MP 300, 쿨 90초는 같습니다. 저장된 쿨타임·준비 상태·카멜레온 학습 정보가 이어지도록 내부 ID와 저장 키는 유지합니다.
- 해커는 원본 v0.5.22의 로토 대화를 복구했습니다. **23회 대화 → C언어 포인터 퀴즈 → 월드 최초 정답자 1명 자동 전직**. 직업·레벨·엘리트 처치 조건은 없습니다. 이후 정답자는 **인챈트된 황금사과 1개**를 한 번 받습니다. 기존 대화 횟수·수령 기록·월드 최초 정답자 기록을 유지합니다.
- `/rpg:job 해커`로 퀴즈/최초 정답자 조건을 우회할 수 없습니다. 관리자의 `/rpg:force 해커`는 유지합니다.
- 흡수 룬은 기본 5%·최대 12% 흡혈 그대로입니다.

기존 월드에서 업데이트 시 이전 팩을 새 v0.5.37 팩으로 교체하세요. 세 팩의 UUID를 유지하므로 새 버전으로 가져올 수 있습니다. 실제 Bedrock 클라이언트에서의 작동은 실기 검증하지 못했습니다.
