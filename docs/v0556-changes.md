# RPG v0.5.56 — GPT 안내 NPC·근력/마력 정보

관리자 명령어 `/rpg:gptnpc`를 사용하면 바라보는 쪽 2.5칸 앞에 GPT 안내 NPC를 생성합니다. 빈 공간에서 사용하세요. 또는 관리자 `/summon rpg:gpt_guide`와 크리에이티브 생성 알을 사용할 수 있습니다. 일반 플레이어는 NPC를 만들 수 없지만 질문은 할 수 있습니다.

NPC 얼굴에는 초록색 패널과 흰색 **GPT** 픽셀 표시가 있습니다. 전용 128×128 PNG·로봇형 지오메트리·고개 돌리기 애니메이션을 추가했습니다. 서 있는 비전투 안내 NPC로, 저장 후에도 남습니다.

PC에서는 우클릭, 모바일에서는 상호작용의 **GPT에게 질문** 버튼으로 입력창을 엽니다. 질문을 제출하면 질문한 플레이어에게만 답변 창이 표시됩니다. 일반 채팅의 모든 말을 자동으로 읽지 않습니다. 기존 `/rpg:ask`와 같은 도감·선택 API 연결을 사용합니다. API가 없으면 지원하는 질문을 오프라인으로 답하고, API를 연결하면 기존 방식으로 관련 도감 자료를 선택합니다. 임의의 자유 대화 모델이나 범용 ChatGPT는 아닙니다.

질문 예시:

- 해커는 근력이야 마력이야?
- 풍압은 근력이야 마력이야?
- 폭멸타 마력이야?
- 피의 창은 근력 보정이야?
- 초승달 참격 피해 계열은?
- 혈인 근력이야 마력이야?
- 대미장식은 고정 피해야?
- 근력 직업 알려줘

직업의 기본 피해 계열과 스킬별 예외를 구분합니다. 풍압·용의 브레스는 마력, 달의 후예 공격은 근력, 메테오드라이브·혈인은 물리/마법 혼합, 대미장식·적섬 돌진은 고정 피해로 설명합니다. 피의 창의 마력 보정·힘 버프 제외, 카피의 복제 기술별 피해 방식도 안내합니다. 직접 공격하지 않는 버프·회복·제어기는 단순한 근력/마력 공격기로 분류하지 않습니다. 이 정보는 API 전송 후보 자료에도 포함됩니다. 보정 정보는 설명용이며 전투 계산을 변경하지 않습니다.

이전 버전의 제한은 동일합니다. 밸런스 평가·사기 여부·티어·우열은 답하지 않고, 전직 방법은 검사·마법사·궁수·무투가·성직자 5개 기본 직업만 안내합니다. 히든 직업의 전직 조건은 공개하지 않습니다.

NPC는 피해 면역이며 일반 스킬 대상·최근 공격 대상에서 제외합니다. XP·재화·룬 보상과 흡혈에 사용할 수 없습니다. 모바일 중복 상호작용과 원거리/다른 차원/사망 상태의 대화를 차단합니다.

세 팩을 함께 0.5.56으로 갱신하세요. 기존 UUID·월드 정보·스킬 ID·전투 수치는 유지합니다. BDS API 운영자는 새 자료로 전용 변형을 다시 만들고 브리지도 갱신하세요. 모바일 단독 일반 월드에서 외부 API가 활성화되지는 않습니다.

자동 검증 366개(JavaScript 361 + Python 5). NPC 관리자 권한·상호작용→질문→개인 답변·중복 입력·거리·면역·보상 제외·스킬 피해 계열·API 자료·안내 제한과 리소스 연결을 확인했습니다. 실제 Bedrock 클라이언트 렌더링 및 실제 외부 API 호출은 미검증입니다.
