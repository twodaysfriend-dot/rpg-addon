# RPG v0.5.75 — 세로 기준 10° 기울기

공용·직업 표시 아이템 39종의 기본 자세를 **세로에서 10°만 기울어진 방향**으로 맞췄습니다.

- 1인칭: 팔 회전을 보정한 뒤 카메라 기준 세로 10° 기울기. 무기를 앞으로 크게 눕히던 회전을 제거했습니다.
- 3인칭: 기본 정지 자세에서 세로 10° 기울기. 앞으로 55° 기울이던 회전을 제거했습니다.

회전은 기존 손잡이를 중심으로 적용합니다. 원본 PNG·2배 크기·모델·UV·손잡이 좌표·회전 중심은 v0.5.74와 동일합니다. 투신 전용 표시·보이지 않는 주먹·전투·PvP·PK·강화·스킬 수치도 유지합니다.

관련 모델 검사 7개를 통과했습니다. 실제 내보낸 모델의 앞뒷면을 읽어 39종 모두에서 기본 축이 세로와 10°를 이루는지, 1인칭 팔 회전이 보정되는지, 손잡이가 손에 유지되는지 확인했습니다. 실제 Bedrock 모바일·Realm 화면은 직접 실행 검증하지 못했습니다. 카메라 방향·시점과 기본 공격·이동에 따른 팔 움직임은 기존 동작을 따릅니다.

기존 팩을 비활성화하고 **RPG BP·RPG Commands BP·RPG RP 모두 v0.5.75**로 적용한 뒤 월드를 다시 여세요. 기존 팩 UUID와 성장·카멜레온 기술·장비·지갑·PK 저장 식별자는 유지합니다.
