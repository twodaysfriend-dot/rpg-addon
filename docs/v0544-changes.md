# RPG v0.5.44 — 힘 버프를 물리 스킬에 적용

버프 스킬로 얻은 힘 상태 효과가 공통 물리 스킬 피해 계산에 반영됩니다. 불굴의 검·광분화·강자의 자세 등에서 얻은 현재 힘 효과를 읽으며, 카멜레온의 빌린 물리 기술에도 적용됩니다. 효과 종료/제거·단계 변경은 다음 피해 계산부터 반영합니다.

| 힘 효과 | 물리 스킬 기본 피해 증가 |
|---|---:|
| 힘 I | +3 |
| 힘 II | +6 |
| 힘 III | +9 |
| 힘 IV | +12 |

계산 순서: **(기본 물리 피해 + 힘 효과 단계 × 3) × 근력 보정 × 장비·룬 보정**. 힘 1단계는 API amplifier 0입니다. 이미 활성화된 힘 효과 한 개의 현재 단계만 읽으며, 여러 버프의 시전 횟수를 합하지 않습니다. 물약·명령어로 얻은 동일한 힘 상태 효과도 같은 규칙을 따릅니다.

예: 근력 5·공격 장비 없음 기준, 검성 360도 휘두르기는 기본 20에서 힘 II를 받으면 26입니다. 검사·타락검성·카멜레온의 해당 기술은 기본 10에서 16입니다. 검성의 기존 직업 전용 피해 배율을 먼저 정한 뒤 힘 증가분을 더합니다.

일반 다단 공격은 피해를 입히는 각 타격에 더합니다. 예: 힘 II 중 투신 난참은 10+6씩 6타, 합계 96입니다. 시전 후 힘 효과가 사라지면 이후 타격은 기본 피해로 돌아옵니다. 복수귀 찢어내기의 물리 출혈도 각 회차에 반영됩니다.

무투가 기술은 기존 힘 계산을 공통 함수로 통합하되 중복 증가를 막았습니다. 스매쉬는 `(16+6)×강펀치 2배=44`, 난타는 `(20+6)×2=52`를 10타로 나누는 기존 계산을 유지합니다. 두 기술의 힘 증가분은 기존처럼 시전 시 계산합니다. 일반 근접 평타는 엔진이 힘을 계산하고, 강펀치·참수·투신의 다음 평타 10배는 그 결과를 증폭하므로 추가 힘을 다시 더하지 않습니다.

힘은 물리 공격용 상태 효과로 적용합니다. 풍압 등 마법 피해·명시적 고정 피해·반사/이미 입힌 피해의 배수는 기존 판정을 유지합니다. 피해 0인 효과가 힘만으로 피해를 주지도 않습니다. 마나·쿨타임·힘 버프의 단계와 지속시간은 그대로입니다.

## 포함된 이전 변경

월룡륜미 전방위 초승달·복수귀 딥 피어스/찢어내기와 기술 순서·검성 피해 상향·던전 완성 검사/복구/이탈 방지/즉시 증원·방어구 및 버프 HUD 숨김 등 v0.5.43까지의 변경을 포함합니다.

## 설치와 검증

기존 행동팩·명령어팩·리소스팩을 모두 **0.5.44**로 갱신하세요. 팩 UUID와 플레이어 저장 속성은 유지합니다. 구버전 팩과 새 버전을 동시에 활성화하지 마세요.

JavaScript 시나리오 257개와 Python 검증 5개, 총 262개 통과. 이번 변경은 아군 버프 수신, 카멜레온·근력/갑옷/룬 복합 보정, 효과 제거/변경, 직접 피해 경로, 다단 타격, 마법·고정 피해 제외, 무투가 중복 방지, 평타 2배 및 10배를 모의 API로 검증했습니다. 실제 Bedrock 클라이언트에서의 전투는 실기 검증하지 못했습니다.
