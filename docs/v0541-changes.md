# RPG v0.5.41 — HUD 정리·던전 완성 검사·이탈 방지·즉시 증원

## 화면 정리

화면의 바닐라 **방어구 게이지와 상태효과 아이콘**을 숨겼습니다. 실제 갑옷 착용·방어력·버프·디버프 효과는 유지합니다. 기존 HP/MP·무기·선택 스킬·던전 타이머는 유지합니다. 사망 후 부활하거나 재접속해도 숨김을 다시 적용합니다.

## 원형 동굴 생성과 복구

- 반지름 32칸인 동굴의 전체 footprint를 포함하는 **사각 청크 로드 영역**을 사용합니다. 임시 청크 로드 영역은 기존처럼 하나씩 사용하고 끝나면 해제합니다.
- 새 동굴은 빈 공간 검사 → 생성 → 전체 완성 검사 순서로 처리합니다. 모든 바닥·외벽·천장을 확인하기 전에는 입장 가능한 `ready` 상태로 바꾸지 않습니다.
- 청크를 일시적으로 읽지 못하면 해당 좌표를 건너뛰지 않고 같은 좌표부터 자동 재시도합니다. 30초간 계속 진행할 수 없으면 미완성 상태로 보관하며 완성됐다고 표시하지 않습니다.
- v0.5.40 이전에 등록된 동굴은 업데이트 후 자동으로 바닥·벽·천장 누락을 검사하고 복구합니다. 검사 중에는 입장할 수 없습니다.
- 이미 생성된 동굴도 관리자가 `/rpg:dungeoncreate 1` 또는 `/rpg:dungeoncreate all`로 등록 위치에서 다시 검사·복구할 수 있습니다. 새 위치로 던전을 이동하는 명령이 아닙니다. 전투·대기·생성이 진행 중인 던전은 건너뛰거나 단독 요청을 거절합니다.
- 기존의 다른 블록을 강제로 덮어쓰지 않습니다. 필요한 외벽 위치에 예상과 다른 블록이 있으면 해당 블록을 보존하고 복구를 중단합니다. 내부의 별도 블록은 보존합니다.

블록은 여러 틱에 나누어 설치하므로 건설 도중에는 일부만 보일 수 있습니다. 완성 검사 전에는 개방하지 않는 것이 이번 수정의 핵심입니다. 새 생성은 여전히 오버월드의 충분한 빈 공간과 tickingarea 여유가 필요합니다.

## 던전 전투 중 이탈 방지

전투가 시작된 뒤에는 **살아 있는 참가자가 `/rpg:dungeonleave`로 자진 퇴장할 수 없습니다.** 대기실 참가 취소는 기존대로 가능합니다.

직업 돌진·순간이동이 던전의 벽 밖이나 천장·바닥 밖으로 향하면 이동을 막습니다. 이 검사는 던전 전투 중에만 적용하며 필드의 기존 이동 기술은 유지합니다. 다른 이동이나 차원 이동으로 밖으로 나간 경우에는 마지막 정상 내부 위치 또는 내부 시작 위치로 복귀시킵니다. 살아 있는 플레이어를 외부 이탈 때문에 참가자 명단에서 지우지 않습니다.

로그아웃해도 진행 중 참가 상태와 제한 시간은 유지합니다. 해당 전투가 끝나기 전에 재접속하면 던전 내부로 복귀합니다. 타이머가 새로 시작하지 않습니다. 사망하면 해당 참가자만 탈락하고 부활 후 입장 전 위치로 돌아갑니다.

**클리어·기존 시간 초과·생성 오류에 따른 전투 종료**의 정상 귀환은 유지합니다. 서버 재시작 시 진행 중 전투를 취소하고 기존 귀환 지점을 복구하는 규칙도 유지합니다. 일반/엘리트 5분·보스 등장 후 3분 제한은 같습니다.

## 몬스터가 없으면 다음 증원 앞당김

던전에 살아 있는 진행 몬스터가 하나도 없으면, 아직 등장하지 않은 일반/엘리트의 다음 증원을 즉시 앞당깁니다. 일반 50마리를 다 잡았다면 남은 엘리트를 한 마리씩 바로 이어서 상대할 수 있습니다. 마지막 일반/엘리트를 실제로 처치하면 다음 몬스터가 이어져 고정 시각까지 기다릴 필요가 없습니다.

한꺼번에 남은 50마리를 모두 소환하는 방식은 아닙니다. 기존 일반 증원 묶음과 최대 동시 12마리 제한, **일반 50 + 엘리트 5 실제 처치 후 보스 1마리** 규칙은 유지합니다. 아직 전장에 적이 남아 있으면 원래 증원 간격을 유지합니다.

비정상 제거로 사라진 몬스터는 처치로 인정하지 않고 같은 진행 슬롯에 다시 소환합니다. 밖으로 나간 진행 몬스터도 내부로 복귀시켜 벽 밖의 적 때문에 진행이 막히는 것을 줄였습니다.

## 알림과 이전 기능

자동 복귀·대기 없는 증원에는 채팅 알림을 보내지 않습니다. 던전의 기존 자동 안내도 채팅 대신 간단한 HUD 알림을 사용합니다. 플레이어가 직접 실행한 잘못된 명령의 오류 응답은 유지합니다.

상위 던전 보상·기여 파티원 전직 처치·천사 회복 보상·초기화 주문서·전직 포기각서·바닐라 몹 XP 10/30/5 등 v0.5.40 변경은 유지합니다. 첫 접속 계열 선택창 자동 표시는 계속 제거 상태입니다.

## 검증

JavaScript 시나리오 231개 + Python 5개, **총 236개**를 통과했습니다. 네 방향 전체 바닥/천장 검사, 반쪽 영역 청크 로드 지연·블록 쓰기 누락 복구, 기존 동굴 자동/수동 복구, 실제 돌진 경계 차단, 차원 이탈·재접속 복귀, 정확한 50/5/1 수량과 타이머, 빈 전장 즉시 증원·무채팅 처리, 방어구/버프 효과를 보존한 HUD 숨김을 검사했습니다.

실제 Minecraft Bedrock 클라이언트에서의 화면 표시·청크 로딩·전투는 실기 검증하지 못했습니다. 행동팩·명령어팩·리소스팩을 모두 0.5.41로 갱신하세요.
