# v0.5.66 공용 무기·해의 도끼 표시 수정

공용 무기 7종과 해의 한손 도끼를 손에 결합되는 모델로 변경했습니다.
원본 128×128 PNG는 바이트 단위로 보존하며 인벤토리 아이콘도 유지합니다.
손잡이를 잡고 칼날·도끼날이 손 바깥으로 향하게 맞췄고, 플레이어의 손 움직임과 평타 모션을 따릅니다.

일반 검·적월선은 모델의 텍스처 면을 24단위, 대검·마수의 도끼·해의 도끼는 28단위로 설정했습니다.
1인칭은 0.9배, 3인칭은 1배로 표시합니다. 무기의 두께는 0.6단위이며 투명 영역은 가립니다.
메시의 앞·뒤에는 원본 이미지를, 가장자리에는 원본 픽셀 색을 사용합니다.

공격력·내구도·제작법·강화·등급·스킬은 이전 버전과 같습니다.
실제 Bedrock 모바일 클라이언트의 화면과 기기별 FOV는 이 환경에서 직접 확인하지 못했습니다.

## 공용 무기 제작법

전부 조합대에서 재료를 위치에 상관없이 넣는 무정형 조합입니다. 완성품은 1개입니다.
게임 안에서는 `/rpg:craft` 제작 안내에서도 확인할 수 있습니다.

| 무기 | 재료 |
|---|---|
| 적월선 | 철괴 2개, 금괴 2개, 레드스톤 가루 2개, 자수정 조각 1개, 다이아몬드 1개, 막대기 1개 |
| 마공학 검 | 철괴 3개, 구리 주괴 2개, 레드스톤 가루 1개, 자수정 조각 1개, 막대기 1개 |
| 마공학 대검 | 철괴 4개, 구리 주괴 2개, 레드스톤 가루 1개, 다이아몬드 1개, 막대기 1개 |
| 정예기사의 대검 | 철괴 4개, 다이아몬드 2개, 네더라이트 주괴 1개, 막대기 1개 |
| 빙설의 대검 | 다이아몬드 검 1개, 꽁꽁 언 얼음 3개, 다이아몬드 2개, 자수정 조각 2개 |
| 화염의 대검 | 다이아몬드 검 1개, 블레이즈 가루 3개, 마그마 크림 2개, 다이아몬드 2개 |
| 마수의 도끼 | 다이아몬드 도끼 1개, 금괴 2개, 네더라이트 주괴 1개, 뼈 2개, 에메랄드 1개 |

해의 한손 도끼는 공용 무기가 아닌 해의 후예 전용 아이템입니다. 이번 변경은 손 표시만 바꿉니다.

## 설치

이전 버전의 팩을 비활성화하고 v0.5.66의 RPG BP·Commands BP·RP를 적용합니다.
기존 아이템에도 새 리소스팩의 모델이 적용되므로 다시 제작할 필요는 없습니다.

## 검증

8종 모델과 텍스처·애니메이션 연결, 손 결합 높이 보정, 모델 크기, 원본 공용 무기 PNG 해시를 검사합니다.
해의 도끼 PNG와 두 행동 팩의 게임플레이 파일이 이전 버전과 같음을 확인했습니다(버전 표기 제외).
