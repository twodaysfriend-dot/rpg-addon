# v0.5.77 — 네더라이트 검 기준 3인칭 방향 보정

3인칭에서 아래를 향하던 마공학 대검 등 역방향 도트 무기는 손을 중심으로 방향을 반전했습니다. 바닐라 검과 같은 방향의 도트는 기본 자세를 그대로 사용합니다. 3인칭의 추가 10° 기울기는 제거했습니다.

1인칭 애니메이션은 v0.5.76과 바이트 단위로 동일합니다. 원본 PNG·2배 배율·전투·강화·저장 데이터 식별자는 유지합니다. 투신과 보이지 않는 주먹도 유지합니다.

모델 검사로 3인칭 방향 반전, 일반 방향 무기의 기본 자세 유지, 1인칭 보존을 확인했습니다. 실제 모바일 화면은 직접 검증하지 못했습니다.

이전 RP를 모두 끄고 BP·명령어 BP·RP 모두 v0.5.77로 적용하세요.
