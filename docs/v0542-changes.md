# RPG v0.5.42 — 검성 스킬 피해 상향

실제 플레이어 직업이 **검성**일 때 다음 직접 스킬 피해를 상향했습니다.

| 스킬 | 변경 전 | 변경 후 | 배율 |
|---|---:|---:|---:|
| 작골염양 | 18 | 27 | 1.5배 |
| 검기 방출 | 14 | 21 | 1.5배 |
| 러쉬 | 4 × 8 = 32 | 6 × 8 = 48 | 1.5배 |
| 360도 휘두르기 | 10 | 20 | 2배 |

위 수치는 근력·갑옷·룬 보정 전 기본 직접 피해입니다. 기존 물리 피해 보정은 변경된 기본 피해에 한 번만 적용합니다. 작골염양의 화상 지속 시간, 스킬별 마나·쿨타임·범위·타수는 유지합니다. 검사·타락검성·카멜레온 등 다른 직업의 기존 피해량은 유지합니다. 카멜레온이 검성의 실행 컨텍스트를 사용하는 기술도 실제 플레이어 직업을 기준으로 검사하여 검성 보너스를 받지 않습니다.

게임 내 `/rpg:skillguide`와 명령어 책, 134개 스킬 도감에 직업별 피해량을 반영했습니다. 던전 완성 검사·누락 복구·전투 중 이탈 방지·빈 전장 즉시 증원, 방어구/버프 HUD 숨김 등 이전 수정도 포함합니다.

실제 피해 경로 검사에서 네 스킬 모두 검성 상향·다른 사용 직업의 기존 피해·근력 보정 1회 적용을 확인했습니다. 전체 자동 검사 240개(JavaScript 235개 + Python 5개)를 통과했습니다. 실제 Bedrock 클라이언트 전투는 실기 검증하지 못했습니다.
