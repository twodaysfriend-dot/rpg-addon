# RPG v0.5.55 정보 안내 변경

`/rpg:ask`에서 API 없이도 효과별 질문을 처리합니다. 예: “데미지 버프 주는 기술은 뭐야?”, “피해량 올려주는 스킬 알려줘”, “힐 주는 기술”, “보호막 주는 스킬”, “기절 기술 목록”. 실제 스킬·직업 데이터와 도감에 근거해 목록을 표시하며, 기술명을 입력하면 개별 설명을 안내합니다. 공격 강화는 힘 효과·평타/후속 타격 강화·적의 받는 피해 증가를 나누어 보여주고, 적에게 힘을 주는 계약은 예외로 표시합니다.

밸런스 평가·사기 여부·강함/약함·직업 추천·티어·순위·너프/상향 의견 질문은 API 연결 여부와 관계없이 답하지 않습니다. “사기인 직업은 어떤 거고 어떻게 전직해?”처럼 다른 질문과 섞여 있어도 전체를 거절합니다. 객관적 기술 효과·피해 수치·쿨타임·마나·기본 전직 조건은 안내합니다. 질문 예시는 지원하는 표현이며 모든 한국어 문장을 이해하는 범용 AI는 아닙니다.

전직 안내는 검사·마법사·궁수·무투가·성직자 5개 기본 직업만 공개합니다. 그 외 직업의 전직 방법·조건은 안내하지 않습니다. 히든 직업 설명 및 신전 정보에 포함되어 있던 전직 조건도 검색·API 전송용 도감에서 제거했습니다. 전직 질문과 다른 질문을 혼합해도 해당 제한을 적용합니다. 히든 직업의 기술 효과·피해 계열 등 전직과 무관한 공개 정보는 안내할 수 있습니다.

이 제한은 `/rpg:ask` 정보 안내와 선택 API 연결에 적용됩니다. 실제 전직 조건·직업 메뉴·관리자 명령어·게임 규칙은 변경하지 않습니다. 소스/전체 스킬 도감 파일을 비밀 자료로 만드는 기능은 아닙니다.

API 연결을 사용하더라도 제한 질문은 외부 요청 전에 차단합니다. BDS 어댑터 및 API 브리지에도 같은 정책을 적용했습니다. 효과별 목록은 오프라인에서 직접 처리하므로 API 비용이 들지 않습니다. 기존 API 연동 운영자는 BDS 전용 변형을 재생성하고 어댑터·브리지 파일을 함께 갱신해야 합니다.

세 팩 모두 0.5.55로 갱신하세요. 기존 UUID·내부 스킬 ID·월드 저장 상태·전투 밸런스는 유지합니다. 실제 Bedrock 화면·외부 API 연결은 별도 확인이 필요합니다.
