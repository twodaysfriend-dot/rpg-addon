# RPG v0.5.74 — 무기 1인칭·3인칭 각도 조정

손에 드는 공용·직업 아이템 39종의 카메라별 회전 각도를 조정했습니다.

- 3인칭: 무기가 상체 위로 거의 수직으로 서 있던 자세를 손 앞쪽으로 기울였습니다. native Euler 회전은 (10, 0, -10)에서 (55, 0, -15)로 변경했습니다.
- 1인칭: 무기 윗부분이 화면 바깥 오른쪽으로 기울던 방향을 중앙 쪽으로 조정했습니다. 카메라 기준 회전은 (60, -20, -15)에서 (55, -10, -30)으로 변경했습니다. 실제 파일에는 팔 회전을 보정한 native Euler (32.997842809, -31.580676147, 144.461571840)를 기록합니다.

원본 PNG, 모델·UV·손잡이 위치·회전 중심·2배 크기는 v0.5.73과 동일합니다. 투신 전용 표시·보이지 않는 격투 주먹, 전투·PvP·PK·강화·장비 수치도 유지합니다.

관련 모델 검사 7개를 통과했습니다. 회전 후에도 39종 앞뒷면의 손잡이가 손 위치에 붙는지, 팔 회전을 따라오는지, 각 카메라에서 의도한 방향으로 기울어지는지 검사합니다. 실제 Bedrock 모바일·Realm 화면은 이 환경에서 직접 실행 검증하지 못했습니다.

기존 팩을 비활성화하고 **RPG BP·RPG Commands BP·RPG RP 모두 v0.5.74**로 적용한 뒤 월드를 다시 여세요. 기존 팩 UUID와 성장·장비·지갑·카멜레온 기술·PK 저장 식별자는 유지합니다.
