# RPG v0.5.49 — 성장 보완·장비·밸런스

## 적용된 변경

- 좀벌레: XP 5 유지, 골드 114 → 2, 강화석 2 → 0, 룬 가루 확률 15% → 0, 룬 드롭 1% → 0.1%. 다른 일반 몬스터의 기존 보상은 유지합니다.
- 힘 버프: 물리·마법 스킬 피해에 단계당 +5%(힘 I +5%, II +10%, IV +20%). 단타·연타 전체에 같은 비율을 적용합니다. 근력·마력·장비 보정과 함께 곱하며 고정 피해는 유지합니다. 무투가에 중복 적용하지 않습니다. 기본 평타의 힘 효과는 엔진 규칙입니다.
- 보스 CC: RPG 보스 4종·드래곤·위더·워든의 기절·빙결·둔화·속박 1회 지속시간 50%, 넉백/밀기와 끌어당김 시간 또는 이동 강도 50%. 화상·독·직접 피해는 CC 감소 대상이 아닙니다. 장판에서 CC를 재적용하는 동작은 유지하며 면역을 주는 방식은 아닙니다. 낙하 의존 기술은 띄우는 높이가 낮아져 실제 피해도 줄 수 있습니다.
- 솔로 보너스: 처음부터 1명으로 출발한 던전은 클리어 골드·강화석·룬 가루·촉매를 1.5배(올림) 지급합니다. 룬 개수·일반 보급품·처치 보상·XP는 그대로입니다. 파티원이 사망/접속 종료해 혼자 남은 경우는 솔로 보너스를 주지 않습니다. 보상 저장/재접속/중복 방지에도 솔로 여부를 보관합니다.

난이도 1 솔로 클리어는 골드 3,000·강화석 12·룬 가루 3·촉매 6개, 난이도 10은 골드 46,500·강화석 186·룬 가루 47·촉매 30개입니다. 매 3회 클리어 추가 촉매 1개는 별도입니다. 기존 20시간 성장 추정은 강화 운·실제 사냥 속도·이번 솔로 보너스와 새 재료 수집에 따라 달라집니다.

## 갑옷 강화 이전

`/rpg:transfer` 또는 `/rpg:upgrade`의 ‘갑옷 강화 이전’을 사용합니다.

1. **제작 전에** 강화된 RPG 갑옷에서 강화 단계를 이전서로 추출합니다. 단계당 골드 500, +10은 5,000골드입니다. 원래 갑옷은 +0으로 남으며 이전서를 받을 빈 칸이 필요합니다.
2. 원래 갑옷을 재료로 상위 갑옷을 제작합니다.
3. 이전서와 같은 부위인 새 RPG 갑옷을 선택해 적용합니다. 성공률 100%, 이전서 1개 소모입니다.

강화 수치는 합산하지 않고 교체합니다. 대상보다 높은 이전서만 쓸 수 있습니다. 인챈트·이름·내구도는 대상 장비 것을 유지하며, 룬 보관함은 변경하지 않습니다. 같은 부위면 다른 RPG 세트에도 적용합니다. 이미 제작으로 소비된 과거 갑옷의 강화를 소급 복구하는 기능은 아닙니다. 선택 후 장비가 바뀌면 취소하며, 저장 오류에는 장비/이전서/골드를 복구합니다. 기본 이전서는 추출을 통해서만 유효한 정보가 담깁니다.

## 심연 수호자 갑옷

| 부위 | 기본 방어 | 내구도 | 네더라이트 내구도 |
|---|---:|---:|---:|
| 투구 | 3 | 550 | 407 |
| 흉갑 | 8 | 800 | 592 |
| 각반 | 6 | 750 | 555 |
| 장화 | 3 | 650 | 481 |

기본 방어 합계 20으로 네더라이트와 같고 내구도는 모든 부위에서 더 높습니다. **4세트: 최대 HP +16, 물리·마법 스킬 피해 +8%, 저항 I 유지**로 RPG 전투에서 추가 성능을 얻습니다. 저항은 더 강한 기존 효과를 덮지 않으며 중첩해 더하지 않습니다. 부위별 +10 강화와 강화 이전을 지원합니다. 네더라이트의 모든 속성을 그대로 복제한 갑옷이라는 뜻은 아닙니다.

부위별 제작: 해당 **숲 수호자 갑옷 1 + 네더라이트 주괴 1 + 네더의 별 1 + 다이아몬드 2 + 자수정 조각 4**, 작업대 자유 배치. 재료 갑옷에 강화가 있다면 먼저 추출하세요. 외형/아이콘은 기존 수호자 리소스를 바탕으로 발광 효과를 사용합니다.

## 누구나 제작하는 공용 전투 무기

| 무기 | 피해 설정 | 내구도 | 재료 |
|---|---:|---:|---|
| 모험가 전투검 | 7 | 800 | 철 주괴 2·구리 주괴 1·막대기 1·레드스톤 1 |
| 별빛 전투창 | 9 | 1,200 | 모험가 전투검 1·다이아몬드 2·자수정 조각 2·철 주괴 2 |

작업대 자유 배치, 인챈트/철 주괴 수리 지원, 직업 제한 없음. **평타용 공용 무기**이며 기존 직업 기술은 원래 법서·코어·전용 무기로 사용합니다. 기존 직업 무기를 대체하거나 잠금 슬롯에 강제로 넣지 않습니다. 실제 기본 공격은 엔진의 피해·인챈트·방어 보정을 받습니다. 기존 검/창 리소스를 사용합니다.

## 초반에 약하거나 운용이 까다로운 능력

초반 솔로 사냥 기준이며 파티 지원 가치와 실전 명중률은 별도로 봐야 합니다. 이번에는 아래 기술 수치를 별도 상향하지 않았습니다.

| 능력 | 이유 |
|---|---|
| 성직자 솔로 사냥 | 기본 보유 기술이 회복·지원 위주라 직접 공격 스킬이 부족함. 공용 전투 무기로 평타 사냥을 보완할 수 있음 |
| 무투가 ‘난타’ | MP 80·쿨 15초에 기본 총 피해 20. 10타 각각 20이 아니라 전체 합계 20이라 초반 화력 대비 비용이 큼 |
| 마법사 ‘라이트닝’ | 기본 피해 8·MP 40·쿨 3초. 파이어볼 6·MP 15·쿨 1초에 비해 명목 피해/마나 효율이 낮음 |
| 망나니 ‘내려찍기’ | 직접 피해 없이 낙하 피해 의존. 낮은 천장·낙하 내성 적·보스에게 특히 불리함 |
| 권골 ‘안면강타’ | MP 100·쿨 20초·직접 피해 0. 사냥 딜기로는 약하고 몰이/연계용으로 써야 함 |
| 마공학사 초반 | 표식 준비가 필요. 광선(MP 90) 후 구체(MP 70)만 해도 MP 160이라 마나 성장 전 운용 부담이 큼 |
| 해·달의 후예 던전 진입 | 실내에서는 자연 빛 조건을 충족하기 어려워 저장 빛을 준비해야 함. 준비 없이 들어가면 기술 연계가 막힐 수 있음 |

## 던전별 핵심 기믹 구상 — 미구현

아래는 구상만 제안합니다. 이번 던전 실행 코드에는 새 장판·패턴·장치·몬스터를 추가하지 않았습니다. 큰 원형 동굴, 일반 50·엘리트 5·보스 1, 일반/엘리트 5분·보스 3분 구조를 유지합니다. 모든 기믹은 한 명으로도 처리 가능하게 설계하고, 패턴 예고는 바닥 표시/이펙트로 전달합니다.

| 난이도·던전 | 핵심 기믹 구상 |
|---|---|
| 1 이끼 동굴 | 골렘의 돌진을 기둥으로 유도하면 갑주가 깨져 잠시 공격 기회가 생김. 회피와 유도를 가르치는 입문 패턴 |
| 2 붉은 수정굴 | 보스와 연결된 빛나는 수정 하나를 찾아 깨면 보호막이 해제됨. 오답 수정에는 작은 장판 예고 |
| 3 균사의 동굴 | 포자 장판이 퍼지고 일정 시간 후 빈 공간으로 바뀜. 포자 확산 방향을 보고 안전한 경로로 이동 |
| 4 사마귀 둥지 | 직선 3연 돌진을 표시한 뒤 마지막에 넓게 베기. 횡이동 후 마지막 공격을 피하면 후딜 발생 |
| 5 전갈 소굴 | 꼬리 공격이 남긴 독 구역을 바깥쪽에 유도. 중앙 통로를 남기는 공간 관리가 핵심 |
| 6 정예의 동굴 | 보스가 ‘방어 자세/공격 자세’를 교대. 방어 중 약점 표식을 공략하고 공격 자세의 큰 동작 뒤에 집중 공격 |
| 7 히드라의 둥지 | 머리 세 개의 발광 순서를 기억하고 해당 순서로 약점을 공략. 한 명도 순차 처리 가능 |
| 8 심연의 동굴 | 독 안개와 냉기 장판이 번갈아 켜지고 안전 구역이 이동. 서로 다른 색/모양으로 다음 구역을 예고 |
| 9 마공학 폐광 | 바닥 회로가 켜지면 표시된 전원 장치를 순서대로 차단. 차단 성공 시 과열된 골렘이 잠시 멈춤 |
| 10 종말의 심연 | 체력 구간별로 돌진 유도·이동 안전지대·회로 차단을 조합. 강제 무적을 짧게 하고 성공 시 충분한 공격 기회를 보장 |

## 설치와 검증

세 팩을 모두 0.5.49로 갱신하세요. UUID·플레이어 저장 데이터·기존 전직·파티 XP 75%·강화 실패/강등/파괴 확률은 유지합니다. 실제 Bedrock 클라이언트의 새 아이템·갑옷 외형과 전투는 실기 검증하지 못했습니다. 외부 AI API 연결도 기존처럼 별도 서버 설정이 필요합니다.
