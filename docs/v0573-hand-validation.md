# v0.5.73 무기 손잡이 좌표 검증

## 확인한 원인

v0.5.72 모델은 다음 세 오류가 겹쳐 있었습니다.

1. 바인딩된 모델에 엔진이 적용하는 -24 Y 오프셋을 손잡이 정점에 보상하지 않았습니다. 루트 pivot만 24에 놓고 실제 손잡이는 Y=0에 남겨 두었습니다.
2. Bedrock 모델의 X 반전과 앞뒷면 UV 방향을 함께 고려하지 않아, 원본 손잡이가 이미지 중심에 있지 않은 무기마다 실제 손잡이 X 좌표가 다르게 벗어났습니다.
3. 실루엣 전체에서 주축을 추정했습니다. 활의 중앙 손잡이, 비대칭 도끼의 자루, 낫의 자루, 날개·코어 같은 아이콘의 파지점을 찾는 방법으로 적합하지 않았습니다. 여기에 다른 모델의 회전·이동값까지 적용했습니다.

## 새 좌표 규칙

- `weapon_hand_profiles.json`에 보이는 공용·직업 아이템 39종의 실제 파지 픽셀과 방향 기준점을 직접 기록했습니다. 그림 크기·파일 해시도 기록하여 텍스처가 바뀌면 재검토 없이 생성되지 않게 했습니다.
- 검·도끼·낫·창·지팡이는 자루, 활은 중앙 그립, 법서·코어는 하단 파지점을 사용합니다. 날개 아이콘을 옆으로 눕히던 자동 주축 회전을 제거했습니다.
- 손잡이 픽셀의 중심이 `[0,24,0]`에 오도록 앞뒷면 UV를 역산합니다. 음수 north UV와 모델 X 반전을 포함하여 큐브 X 시작점은 `(gripX - imageWidth) × 단위크기`입니다.
- 손 바인딩 루트와 방향 보정 자식의 pivot을 모두 `[0,24,0]`으로 맞춥니다. 루트를 회전해도 손잡이는 움직이지 않습니다.
- 삼지창의 1·3인칭 이동값을 제거했습니다. 3인칭은 손잡이를 중심으로 작은 기울기만 적용합니다.
- 1인칭은 바인딩 가이드의 팔 회전을 Bedrock의 X/Y 부호·ZYX 회전 순서로 계산하여 보정합니다. 큰 무기가 카메라와 평행하게 과도하게 확대되지 않도록 끝부분이 앞을 향하는 자세를 사용합니다.
- 일반 표시 면 16→32단위의 2배 모델, 원본 PNG, 투신의 본인 1인칭 전용 장갑과 보이지 않는 격투 주먹은 유지합니다.

## 검증 범위

내보낸 모델의 큐브·UV·뼈대·애니메이션을 독립적으로 읽어 실제 손잡이 위치를 계산합니다. 단순히 예상 회전값이 파일에 적혔는지만 검사하는 방법을 대체했습니다.

- 39종 × 앞뒷면의 파지점 일치.
- 1·3인칭 회전 전후 파지점 유지.
- 팔의 정지·걷기·공격 회전에서 파지점이 손을 따라감.
- 검·자루·활 윗부분의 방향 일치.
- 원본 PNG 해시, 표시 면 크기, 슬롯 바인딩, 각 아이템과 모델 연결.
- 투신 전용 표시와 보이지 않는 주먹 모델 보존.

`review/weapon_hand_verification.json`에는 이전 모델과 새 모델을 같은 실제 파지점으로 비교한 결과가 있습니다. 화염 대검의 손잡이 오차는 약 41.10 모델 단위, 해의 도끼는 약 39.00 단위였으며 새 모델은 계산상 0입니다. 1 모델 단위는 블록의 1/16입니다.

`review/measured_grips_*.png`는 원본 도트 위에 기록한 파지점·방향선을 보여 줍니다. `review/held_models_projection.png`는 내보낸 좌표를 고정 카메라로 투영한 진단 그림입니다. Minecraft 화면을 촬영한 이미지가 아닙니다. 실제 Bedrock 모바일·Realm 화면은 이 환경에서 실행 검증하지 못했습니다.
