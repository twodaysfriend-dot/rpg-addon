# v0.5.71 무기 자세·2배 크기·직업 무기 강화

## 손에 든 무기

두 번째 참고 사진처럼 칼날이 위로 서고 오른쪽으로 약간 기울도록 1인칭 모델을 구성했습니다.
아이콘의 실루엣 주축과 손잡이 위치를 구해 서로 반대 방향으로 그려진 무기도 착용 모델에서 방향을 맞춥니다.
이전의 바인딩 +24 보정 방식 대신 플레이어 root→waist→body→rightArm→rightItem 뼈대와 실제 손 좌표(-6,15,1)를 사용합니다.
1인칭 arm guide(95,-45,115)를 보정하여 무기가 화면에서 위/오른쪽을 향하고 옆면으로 눕지 않도록 설정합니다.

표시 모델의 기본 면 크기는 16→32단위로 2배입니다. 공용·직업 무기 중 보이는 39종을 적용합니다.
투신 장갑은 별도 본인 1인칭 전용 표시를 유지하며 8→16단위로 키웁니다. 원래 보이지 않는 격투 주먹 3종은 보이지 않는 상태를 유지합니다.
크기 변경은 손에 든 모델에 적용하며 인벤토리 아이콘과 아이템 바닥 표시를 확대하지 않습니다.
원본 PNG는 읽기만 하고 수정하지 않습니다. 검은 줄이 생기던 픽셀별 모서리 큐브는 만들지 않습니다.
기기 FOV·화면비·카메라 원근 때문에 실제 화면 픽셀 길이가 정확히 2배인 것을 보장하는 설정은 아닙니다.

## 직업 기본 무기 강화

직업·견습 기본 무기 36종을 /rpg:upgrade에서 +10까지 강화합니다. 카멜레온의 두 형태도 포함합니다.
무기를 손에 든 뒤 강화 메뉴에서 선택합니다. 등급은 부여하지 않고 승급 합성 대상에도 포함하지 않습니다.

강화 단계당:
- 근접 평타 피해 +1
- 그 직업 무기를 들고 사용하는 물리·마법 스킬 피해 +2%

+10 기준 근접 피해 +10·물리/마법 스킬 피해 +20%입니다.
고정 피해·회복량·버프 수치에는 이 추가 스킬 배율을 적용하지 않습니다.
공용 무기는 기존 등급·강화 효과를 사용하고 이 직업 무기 스킬 배율은 받지 않습니다.

비용·실패·강등·파괴 확률·촉매 조건은 기존 공용 무기와 같습니다. 촉매는 +5부터 최대 5개, 개당 성공률 +9%p·파괴 -3%p입니다.
직업 무기가 파괴되면 해당 강화 단계는 사라집니다. 기본 무기 재지급은 기존 기능대로 동작합니다.
저장 오류 시 장비·재화·촉매를 복구합니다.

## 강화 정보 유지

같은 직업 무기를 다시 지급할 때는 기존 스택의 강화·이름·아이템 정보를 우선 보존합니다.
상위 직업이나 다른 직업의 무기로 바뀌는 giveWeapon 경로에서는 이전 직업 무기의 강화 단계를 이어받습니다.
카멜레온은 흑염 대검↔백월의 낫을 전환해도 강화 단계가 유지됩니다.
전직 포기·관리자 초기화처럼 기존 아이템을 명시적으로 없애는 다른 기능 전체를 보존 기능으로 바꾸지는 않았습니다.
캐릭터 레벨·카멜레온 습득 기술·화폐·기존 장비 저장 키와 팩 UUID는 유지합니다.

## 적용·검증

기존 BP·명령어 BP·RP를 비활성화하고 v0.5.71 세 팩만 적용한 뒤 월드를 다시 여세요.
새 무기 모델과 직업 무기 강화는 새 RP·BP를 함께 적용해야 합니다.
손 뼈대·손잡이 좌표·화면 상 칼날 방향 계산·2배 모델 크기·원본 PNG·36종 강화·+10 상한·등급 제외·스킬 배율·전환/재지급/전직 보존·오류 복구를 자동 검사합니다.
실제 Bedrock 모바일의 화면과 서버 플레이는 이 실행 환경에서 직접 검증하지 못했습니다.
