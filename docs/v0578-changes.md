# v0.5.78 — 손잡이 정렬과 네더라이트 검 기준 1인칭

전체 아이템을 돌리던 180° 반전과 추가 10° 회전을 제거했습니다. 1·3인칭은 바닐라 도구의 기본 자세를 사용합니다.

공용 무기와 검·도끼·창·지팡이류 24종은 원본 도트의 손잡이 위치가 바닐라 검과 달랐습니다. 원본 PNG 파일을 보존하고 표시용 복사본에서 좌우 방향과 여백을 정렬했습니다. 기준은 16×16 네더라이트 검의 손잡이 중심 (3.5,12.5)입니다. 적월선의 표시 손잡이는 이 기준점에 일치시켰습니다.

복사본은 픽셀을 정확히 2×2로 복제하고 필요 시 좌우 반전·정수 이동만 합니다. 재채색·보간·잘림은 없으며 원본의 보이는 RGBA 픽셀이 모두 4회씩 보존되는지 검사합니다. 표시용 복사본을 쓰므로 인벤토리 아이콘의 방향과 여백 정렬도 함께 적용됩니다. 원본 도트 파일과 게임 내 2배 배율은 유지합니다.

원본 그림 전체를 잘라내지 않기 위해 일부 긴 자루·장식은 기준점에서 최대 1 모델 단위 이내의 여유를 둡니다. 이는 실제 엔진의 손 접촉을 측정한 값이 아니라 아이콘 좌표를 기준으로 계산한 오차입니다.

전투·강화·등급·재료·직업·스킬·PvP·PK·지갑·성장 저장 키는 유지합니다. 투신의 별도 표시와 보이지 않는 주먹도 유지합니다.

자동 검사 502개와 24종 표시용 픽셀 보존 검증을 통과했습니다. 실제 모바일 화면은 이 환경에서 직접 확인하지 못했습니다.
