# RPG v0.5.60 — 원본 도트·장비 강화·합성

사용자가 올린 RPG_v0557_modified.mcaddon을 기반으로 한 v0.5.59에 적용했습니다. 수정 파일의 전직·진행 조건을 유지합니다. v0.5.58의 다른 변경을 자동으로 덧씌우지 않았습니다.

## 사용
- `/rpg:upgrade`: 착용 RPG 갑옷, 손에 든 공용 무기, 전용 보관함 룬 강화.
- `/rpg:fuse`: +10 장비 두 개로 등급 합성. 강화 메뉴에서도 진입 가능합니다.
- `/rpg:runes`: 룬 보관·장착·강화. 승급한 룬은 전용 보관함에서 관리합니다.

## 적용 대상과 규칙
룬 6종, RPG 갑옷 4세트의 16부위, 공용 무기 7종 모두 종류와 관계없이 일반~신화 7등급이 있습니다. 직업 전용 시전 아이템·바닐라 장비에는 적용하지 않습니다. 기존 및 새로 제작·드롭된 대상 장비는 일반에서 시작합니다.

공용 무기: 적월선, 마공학 검, 마공학 대검, 정예기사의 대검, 빙설의 대검, 화염의 대검, 마수의 도끼. PNG는 weapon_icons_128x128.zip의 원본 바이트를 그대로 사용했습니다. 매핑과 SHA-256은 original_weapon_texture_mapping.json에 기록했습니다.

같은 종류(ID)·같은 등급·각각 +10인 별개의 장비 2개를 합성합니다. 갑옷은 세트와 부위까지 같아야 합니다.
- 성공: 재료 1개 소모, 주장비 다음 등급 +0.
- 실패: 재료 1개만 소모, 주장비 기존 등급 +10 유지.
- 신화는 최종 등급. 촉매·지갑 재화의 별도 합성 비용은 없습니다.
- 주장비 인챈트·이름·내구도와 기타 속성은 보존합니다. 재료의 부가 속성은 합쳐지지 않습니다.
- 성공 시 +0 초기화 때문에 즉시 능력치가 낮아질 수 있습니다. 확인창에 안내합니다.

## +10 강화와 이전
갑옷 +10·단계당 HP +1 유지. 공용 무기는 +10·단계당 근접 피해 +1. 무기 강화 추가분에는 등급 배율을 다시 곱하지 않습니다. 실제 평타의 방어·저항·치명타·인챈트·힘 효과에 비례해 피해를 보정합니다. 스킬·고정 피해에는 공용 무기의 등급·강화 보정을 적용하지 않습니다.

룬 최대 강화는 +5에서 +10으로 확대했습니다. 기존 보관함의 +1~+5는 +2~+10으로 한 번만 이전하며, 기존 효과를 유지합니다. 수호 룬의 저항 단계는 등급 배율로 증폭하지 않습니다. 룬의 수치형 보너스에만 등급 배율을 적용합니다. 예: 일반 +10 힘 +30%, 신화 +10 힘 +60%; 일반 +10 생명 HP +24, 신화 +10 HP +48. 실제 최대 HP는 기존 엔진 효과의 4 HP 단위 근사를 따릅니다.

승급 룬 및 강화 룬은 보관함에서만 관리합니다. 일반 +0 룬만 물리 아이템으로 꺼낼 수 있어 등급 손실·아이템 겹침을 막습니다. 장착 슬롯·중복 정책은 사용자가 올린 수정 파일 기준(3슬롯·동일 종류 1개)을 유지했습니다.

모든 강화에는 기존과 같이 성공·유지 실패·강등·파괴가 있습니다. 촉매 최대 5개, 개당 성공 +5%p·파괴 -3%p. 갑옷·무기는 현재 +5부터, 룬은 +2부터 사용합니다. 최종 확률을 확인창에 표시합니다. 강화 이전서는 강화 단계만 옮기고 장비 등급은 옮기지 않습니다.

## 재화와 시간
갑옷·공용 무기 다음 단계 n의 강화 비용은 골드 40×n²·강화석 2n. 룬은 골드 반올림(2.5×n²)·룬 가루 1개입니다. 룬 +10 확장으로 늘어난 반복 비용을 낮췄습니다.
던전별 기본 촉매 보상을 7/8/9/10/12/14/16/19/22/26개로 조정했습니다. 기존 솔플 보상 배율과 3회마다 촉매 보너스는 유지합니다.

약 20시간 모델은 일반 등급 갑옷 4부위와 룬 6종을 +10으로 만드는 강화 재화 수급 목표입니다. 공용 무기·합성 승급·신화 완성 시간은 포함하지 않습니다. 일반만으로 신화 하나를 만들 때 실패가 없어도 최소 64개가 필요하며, 실제로는 강화·합성 실패와 파괴로 더 많이 필요합니다. 자세한 가정과 계산은 v0560_풀강_비용과_시간.md를 참고하세요.

## 설치·검증 범위
Bedrock 1.21.100 이상, 동봉 BP·명령어 BP·RP 3개를 모두 활성화하세요. 기존 팩 UUID를 유지하고 버전을 0.5.60으로 올렸습니다.
자동 검증은 스크립트 구문·로컬 import·팩 JSON·제작/드롭·모의 Bedrock API 시나리오 및 ZIP 무결성을 검사합니다. 실제 모바일 Bedrock에서의 화면·런타임 실측은 수행하지 않았습니다.
