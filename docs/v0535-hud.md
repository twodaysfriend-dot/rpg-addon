# v0.5.35 HUD 간소화

RPG 정보는 화면 왼쪽 아래에 0.75배 글씨로 표시하도록 리소스팩 UI를 추가했습니다. 큰 검은 배경과 중앙의 긴 정보 줄은 제거했습니다.

평소에는 무기명 / 선택 스킬·쿨타임 / HP·MP의 최대 3줄이며, 던전에서는 `D1 일반 1/50 E0/5 4:49` 같은 짧은 한 줄을 추가합니다. 숫자 HP는 기존처럼 최대 체력 60 초과에서만 표시하며, 제한 횟수 스킬은 남은 횟수를 유지합니다. 레벨·직업명 반복·다음 스킬·슬롯 번호는 숨겼습니다. 자세한 정보는 `/rpg:status`, 스킬 목록은 `/rpg:skills`에서 봅니다.

재화는 그대로 지급하고 지갑에 저장하지만 매 처치마다 획득 채팅을 보내지 않습니다. 최초 지갑 안내만 한 번 표시합니다. 무기를 내려놓으면 무기 정보도 사라집니다. RPG 전용 표식이 있는 액션바만 이동하며 일반 액션바 메시지는 기본 배치를 유지합니다.

행동팩·명령어팩·리소스팩을 모두 0.5.35로 업데이트하고, 이 리소스팩을 다른 HUD 변경 팩보다 위에 적용하세요. 표시 위치는 왼쪽 끝에서 8 GUI 픽셀, 화면 아래에서 38 GUI 픽셀 위이며 터치 이동 버튼 아래 공간을 목표로 잡았습니다. GUI 배율·기종·조작 배치에 따라 달라질 수 있습니다. 실제 모바일 클라이언트에서 렌더링·버튼 겹침은 검증하지 못했습니다. 리소스팩을 적용하지 못하는 환경에서도 간소화된 문구는 나오지만 왼쪽 아래 이동은 적용되지 않습니다.

UI 구현은 공개 Bedrock 기본 HUD 정의의 액션바 팩토리와 `$actionbar_text` 구조를 확인하여 작성했습니다. 참고: https://github.com/ZtechNetwork/MCBVanillaResourcePack/blob/master/ui/hud_screen.json
