# RPG v0.5.62 — 공용 무기 손 표시

적월선·마공학 검·마공학 대검·정예기사의 대검·빙설의 대검·화염의 대검·마수의 도끼 7종의 손 표시 설정을 수정했습니다.

- BP와 RP에서 minecraft:hand_equipped를 활성화해 엔진의 검·도끼 도구 표시를 사용합니다.
- 기존 RP의 main_hand.first_person.scale=[0.11,0.11,0.11] 크기 보정을 제거했습니다. 별도 위치·회전·크기 재정의나 커스텀 손 모델 없이 엔진 기본 표시를 따릅니다.
- 원본 PNG 7개와 아이콘 연결은 유지했습니다. PNG 바이트·크기·투명도를 바꾸지 않았습니다.
- 기존 아이템 ID·개별 강화·등급·내구도·인챈트를 유지합니다. 새 무기로 다시 지급받을 필요가 없습니다.
- v0.5.61의 전직관 소환알, 던전·신전 보호, 실패 몹 정리도 포함합니다.

직업 데이터 등록 순서의 히든 직업 25개는 v0562_히든직업_목록.md에 정리했습니다. 전직 방법·조건은 제외했습니다.

설치: 기존 팩 UUID를 유지하고 세 팩을 모두 0.5.62로 올렸습니다. 동봉된 BP·명령어 BP·RP를 모두 갱신·활성화하세요.

검증: 자동 테스트 417개(JavaScript 412 + Python 5), JSON·스크립트·import·소환알·원본 PNG 동일성·팩 무결성을 확인합니다. 실제 모바일 Bedrock에서 1/3인칭 크기·각도·손 위치는 미검증입니다.
