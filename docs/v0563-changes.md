# RPG v0.5.63 — 일반 상위 직업 분류 정정

다음 8개 직업을 히든에서 일반 상위 직업으로 수정했습니다.
검성, 타락검성, 현자, 천궁, 천사, 미카엘, 타락천사, 권골.

견습을 제외한 분류는 일반 13개(기본 5개 + 상위 8개), 히든 17개입니다. 직업 메뉴·전직관의 [일반]/[히든] 표시와 명령어 안내를 수정했습니다.

히든 직업은 현재 데이터 등록 순서로 다음과 같습니다.
투신, 망나니, 야수, 냉기 능력자, 화염술사, 용기사, 악마, 마법공학사, 해커, 혈술사, 암살자, 그림자 암살자, 작살꾼, 복수귀, 해의 후예, 달의 후예, 카멜레온.

직업의 전직 조건·직전 직업·스킬·능력치는 바꾸지 않았습니다. 변경 전후 직업 데이터를 비교해 hidden 필드만 바뀐 것을 확인했습니다. 기본 직업 ID 목록은 5개로 유지하여 기존 진행도·학습 시스템에 영향을 주지 않습니다.

GPT NPC의 전직 안내 공개 범위도 기존 요청대로 기본 5개 직업만 유지했습니다. 일반 상위 직업의 전직 안내를 거절할 때 해당 직업을 히든으로 잘못 표현하지 않도록 문구를 수정했습니다.

v0.5.62의 공용 무기 기본 도구 손 표시와 원본 도트, v0.5.61의 전직관 소환알·구조물 보호·실패 몹 정리를 포함합니다. 세 팩 모두 0.5.63으로 갱신·활성화하세요. 기존 팩 UUID·아이템·저장 데이터는 유지합니다.

자동 테스트 417개(JavaScript 412 + Python 5), 스크립트 구문·import·팩 JSON·원본 도트·설치 파일 무결성을 검증합니다. 실제 모바일 Bedrock 실행은 미검증입니다.
