# RPG v0.5.56 직업 기본 아이템 근접 피해 설정

아이템의 추가 근접 피해 설정 기준입니다. 설정이 없다고 공격 자체가 불가능한 것은 아니며, 맨손 수준의 엔진 기본 피해나 인챈트·힘 효과는 별도로 작동할 수 있습니다. 활의 화살 피해와 스킬 피해도 별도입니다.

추가 근접 피해 설정 없음: **8개 전직 직업**.

| 직업 | 기본 아이템 |
|---|---|
| 마법사 | 마법사의 마법서 |
| 현자 | 현자의 지팡이 |
| 궁수 | 궁수 활 |
| 천궁 | 천궁 활 |
| 성직자 | 성직자의 성십자 |
| 천사 | 천사의 기도 |
| 미카엘 | 미카엘의 날개 |
| 타락천사 | 타락천사의 날개 |

견습은 고정 기본 아이템이 없고 선택한 시작 장비를 사용합니다. 견습 시작 장비 중 추가 근접 피해 설정이 없는 것은 견습의 마법책·견습의 십자가·견습 활입니다.
