# v0.5.67 던전 보상·공동 전리품·방어구·승급 변경

## 엘리트 다이아

던전의 추적 중인 엘리트 1마리당 한 번 추첨합니다.
- 다이아몬드 1개: 40%
- 다이아몬드 3개: 10%
- 없음: 50%

서로 배타적인 결과입니다. 기대값은 1마리당 0.7개, 엘리트 5마리당 3.5개입니다.
일반·보스·야생 엘리트에는 이 추가 추첨을 적용하지 않습니다. 실패 정리·중복 사망 이벤트로 재추첨하지 않습니다.
처음에는 바닥 공동 전리품으로 나오고 종료 때 남아 있다면 기여도 분배에 포함됩니다.

## 네더라이트 주괴

6~10단계를 클리어한 생존 보상 참여자마다 주괴 1개를 독립 추첨합니다.

| 단계 | 주괴 1개 확률 |
|---|---:|
| 1~5 | 0% |
| 6 | 10% |
| 7 | 15% |
| 8 | 20% |
| 9 | 25% |
| 10 | 30% |

기존 클리어 보상에 더해 지급합니다. 추첨 결과를 영수증에 저장하여 재접속·저장 재시도·중복 수령으로 재추첨하지 않습니다.
가방이 가득 차면 기존 던전 보급함에 남습니다. 솔로 재화 1.5배가 주괴 수량·추첨 확률을 늘리지는 않습니다.

## 촉매

룬·RPG 갑옷·공용 무기 모두 개당 성공률 +9%p, 파괴 확률 -3%p입니다.
한 번에 최대 5개, 갑옷·무기 현재 +5 / 룬 현재 +2부터 사용합니다.
5개 사용 시 성공률 최대 +45%p·파괴 확률 최대 -15%p입니다.
기존 강등 확률과 남은 파괴 확률을 제외한 범위까지 성공률 상한을 적용합니다. 확률 합은 100%이고 파괴 확률은 0% 미만으로 내려가지 않습니다.
예: +9→+10에 촉매 5개를 쓰면 성공 60%·유지 실패 5%·강등 32%·파괴 3%입니다.

## 던전 종료 공동 정산

기본 분배 기준은 준 실제 피해 + 전투 중 아군에게 준 유효 회복 HP입니다. 자가 회복·가득 찬 HP 회복·중복 피해 집계는 점수를 만들지 않습니다.
생존자뿐 아니라 해당 탐험에 참가했던 사망·오프라인 플레이어도 기여한 몫을 보관합니다. 기여가 모두 0이면 참가자에게 균등 분배합니다.
클리어와 실패 모두, 종료 시 던전 안에 남아 있는 아이템과 몬스터의 마크 XP를 정산합니다. 이미 주워 간 아이템을 회수하지는 않습니다.
같은 아이템을 합산하고 비율대로 정수 수량을 나누며 남은 수량은 소수점 몫과 이전 묶음의 미배분 몫을 반영해 배분합니다. 낱개 아이템도 여러 묶음에 걸쳐 기여 비율을 따르며, 동률은 순환합니다.

마인크래프트 기본 경험치 구슬은 그 값을 읽는 안정적인 Script API가 없으므로, 던전 몬스터의 기존 구슬 XP 값을 별도로 기록합니다.
던전 이벤트에서만 기본 구슬 생성을 0으로 바꾸고 원래 XP를 자동 보관하여 종료 때 분배합니다. 일반 필드 몬스터의 구슬 경험치는 유지합니다.
RPG 레벨 경험치와 기존 파티 처치당 75% 경험치는 유지합니다. 마크 인챈트용 XP 정산과 RPG 레벨 XP는 별개입니다.
경험치 병·플레이어 사망 등 몬스터 처치 외 원인으로 생긴 구슬은 이 별도 기록에 포함하지 않습니다.

아이템은 이름·인챈트·내구도·강화·등급·룬·책·포션 데이터를 바꾸지 않도록 원본 ItemStack을 영속 보관함 엔티티에 저장합니다.
가방 부족·접속 종료·사망 시 해당 몫을 보관하고 `/rpg:dungeonloot` 또는 부활·재접속 시 다시 지급을 시도합니다.
첫 번째 RPG 무기 예약 슬롯은 사용하지 않습니다. 보관함 청크가 내려가 있으면 잠시 불러온 뒤 수령합니다.
기존 클리어 재화·룬·촉매·네더라이트 보너스는 각자 받는 기존 클리어 보상으로, 바닥 전리품 분배와 별개입니다.

## 갑옷 착용 디자인

모험가·숲 수호자·별빛 술사·심연 수호자 4세트 16부위에 전용 착용 모델을 적용했습니다.
작은 그림이 반복되던 UV 대신 기존 색상에서 뽑은 판금·테두리·장식 면을 사용합니다.
투구는 얼굴이 보이는 바이저 형태, 흉갑은 어깨판과 가슴 장식, 각반은 무릎 보호대, 장화는 테두리와 밑창으로 구성했습니다.
플레이어의 머리·몸통·양팔·양다리 뼈대를 따라 움직입니다. 원본 아이콘·PNG와 방어 수치는 유지합니다.

## 승급 추가 재료

- RPG 갑옷: 보호 IV 효과부여 책 1권
- 공용 무기 7종: 날카로움 V 효과부여 책 1권
- 룬: 책 필요 없음

해당 인챈트가 정확한 레벨로 든 실제 효과부여 책이어야 합니다. 이름만 바꾼 책은 인정하지 않습니다.
같은 종류·등급의 +10 두 개 조건과 승급 확률은 유지합니다. 성공·실패 모두 재료 장비와 필요한 책 1권을 소모합니다.
성공하면 다음 등급 +0, 실패하면 주장비 +10을 유지합니다. 저장 오류 시 이미 차감한 책과 장비를 복구합니다.
메뉴·룰북·GPT NPC 지식도 갱신했습니다.
