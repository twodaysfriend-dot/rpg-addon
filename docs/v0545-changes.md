# RPG v0.5.45 — 월룡륜미 180도·힘 마법 보정·정보 안내

## 월룡륜미

360도 전방위에서 **시전 시 바라본 방향의 전방 180도**로 변경했습니다. 뒤쪽 적은 피해를 받지 않으며 큰 청록색 초승달과 작은 보랏빛 달의 이펙트도 앞쪽 반원 안에서만 퍼집니다. 시전 후 고개를 돌려도 기준 방향은 바뀌지 않습니다.

반경 12칸·기본 피해 28·MP 70·쿨 9초·지속 0.6초·높이 차 3칸은 유지합니다. 대상별 한 번 타격, 벽 가림과 아군 제외도 유지합니다. 카멜레온이 배운 월룡륜미에도 동일합니다.

## 힘 버프

힘 상태 효과는 **물리·마법 스킬**의 기본 피해에 단계당 +3을 더합니다. 힘 I +3·II +6·III +9·IV +12. 물리 스킬은 이후 근력과 물리 장비, 마법 스킬은 마력과 마법 장비 보정을 받습니다. **고정 피해는 변경하지 않습니다.**

예: 기본 피해 20인 마법은 힘 II 상태에서 26을 기준으로 마력·장비를 계산합니다. 마력 105·장비 없음이면 26×1.7=44.2입니다. 고정 피해 60은 힘·스탯·장비와 관계없이 그대로 60입니다. 실제 피격 방어 등은 기존 규칙입니다.

힘 효과가 종료·제거·단계 변경되면 다음 일반 타격부터 반영합니다. 무투가의 기존 힘 보정·강펀치·평타 배수에는 중복 적용하지 않으며 난타 총합 분할도 유지합니다. 버프 단계·지속시간·마나·쿨타임은 유지합니다.

## RPG 정보 질문

- `/rpg:ask` — 질문 입력창을 엽니다.
- `/rpg:ask "월룡륜미 범위"` — 입력한 질문에 본인에게만 채팅으로 안내합니다.
- `!rpg ask 해커 전직 조건` — 채팅 별칭입니다. 일반 채팅 대화를 자동으로 읽지 않습니다.

예: 해커 근력이야 마력이야 / 생명의 룬 / 샌드백 제작법 / 던전 10 보상 / 카멜레온 분해 / 강화 촉매 / 힘 버프 마법 피해.

구현된 스킬 136개·30개 전직 직업과 견습·룬·갑옷·제작법·던전·성장 규칙을 같은 설정 데이터에서 읽습니다. 피해는 기본 수치와 스탯/장비 보정 전임을 구분합니다. 알려진 이름·키워드로 관련 도감 항목을 찾아 보여주므로 자유 대화형 AI와는 다릅니다. 자료가 없는 질문은 추측하지 않습니다. 다른 주제의 문장은 생성하지 않고 RPG 자료만 보여줍니다. 캐릭터 레벨·직업·스킬·재화를 변경하는 기능은 없습니다.

질문은 200자 이내·2초 간격입니다. 본인의 질문에만 응답하고, 다른 플레이어에게 알림을 보내지 않습니다. 기본 파일은 키·인터넷·외부 API 없이 작동합니다.

## 외부 AI API 연결

BDS에서는 선택 연결 코드와 서버 브리지를 제공합니다. API는 관련 자료 ID만 고르고 게임이 실제 도감 자료를 표시하므로, 외부 응답에 잘못된 설명이나 다른 주제의 문장이 있어도 그대로 보여주지 않습니다. 일반 월드·친구 초대·Realm은 HTTP API 모듈을 지원하지 않아 이 연결을 실행할 수 없습니다.

API 키와 실제 BDS 서버 정보가 제공되지 않아 실서버 연결을 활성화하지 않았습니다. [서버 설정과 변형 생성 안내](v0545-api.md)를 참고하세요. 사용자용 기본 애드온은 그대로 설치하면 내장 안내를 사용할 수 있습니다.

## 설치·이전 기능

행동팩·명령어팩·리소스팩을 모두 0.5.45로 갱신하세요. UUID와 플레이어 저장 속성을 유지합니다. 복수귀 신규 기술·검성 피해 상향·던전 수정·HUD 숨김 등 이전 기능을 포함합니다.

검증은 자동 시나리오와 모의 Bedrock/API 실행입니다. 실제 Bedrock 클라이언트와 외부 API 서버에서의 실행은 검증하지 못했습니다.

자동 검증: JavaScript 281개 + Python 5개, 총 286개 통과.
