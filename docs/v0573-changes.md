# RPG v0.5.73 — 무기별 파지점·1인칭·3인칭 교정

보이는 공용·직업 아이템 39종의 손잡이 위치와 방향을 원본 도트에서 직접 지정했습니다. 검·도끼·창·낫·지팡이는 자루, 활은 중앙 그립, 법서·코어는 하단을 기준으로 잡습니다. 실루엣 자동 추정은 제거했습니다.

엔진의 손 바인딩 -24 Y 오프셋과 앞뒷면 UV의 X 반전을 포함하여 좌표를 계산하도록 수정했습니다. 삼지창 모델의 이동값을 제거하고, 손잡이를 회전 중심으로 사용합니다. 1인칭 팔 회전도 Bedrock의 실제 축·회전 순서로 보정합니다. 무기마다 머리 쪽이나 손 아래로 따로 벗어나던 좌표 오류를 교정했습니다.

2배 표시 모델 크기와 원본 PNG는 유지합니다. 투신의 본인 1인칭 전용 장갑과 보이지 않는 격투 주먹도 유지합니다. 전투·결투·PK·강화·등급·스킬 수치는 바꾸지 않았습니다.

내보낸 39종 모델의 앞뒷면에서 실제 손잡이 픽셀이 손 위치에 놓이는지, 팔·카메라 회전 후에도 손을 따라오는지 검사합니다. 자세한 원인과 검증 자료는 `v0573_무기_좌표_검증.md`와 `review/`에 있습니다. 실제 Bedrock 모바일·Realm 화면은 직접 실행 검증하지 못했습니다.

v0.5.72 팩을 비활성화하고 **RPG BP·RPG Commands BP·RPG RP 세 팩을 모두 v0.5.73으로 적용**한 뒤 월드를 다시 여세요. 팩 UUID와 기존 레벨·카멜레온 기술·장비·지갑·PK 저장 키는 유지했습니다.
