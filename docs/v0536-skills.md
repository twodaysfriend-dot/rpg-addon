# RPG v0.5.36 직업 계열별 스킬 상세 도감

게임에서는 `/rpg:skillguide`로 같은 설명을 볼 수 있습니다. 구현된 30개 전직 직업과 견습의 액티브 **134개**, 19계열의 고유 기능을 정리했습니다. 미구현 직업과 사용하지 않는 과거 스킬은 제외했습니다.

피해는 HP 단위(하트 한 칸=HP 2), 마나·피해는 지능·스탯·갑옷·룬 보정 전 기본 값입니다. 쿨타임은 초입니다. 다단 피해는 모든 타격을 넣은 명목 합계이며, 실제 피격 무적·방어·이동·벽·화염 면역으로 달라집니다. ‘고정’으로 적은 피해는 일반 스탯 피해 증가와 구분합니다.

천궁 마나 화살의 발당 MP 20은 고정 비용으로 지능 할인 대상이 아닙니다. 초신성 최대 55와 메테오 중심 58은 기본 피해이며 일반 스탯·장비 보정 후에는 달라집니다. 재부팅과 계약은 이번 요청대로 유지했습니다.

## 카멜레온 학습 전 확인

v0.5.36에서 직업·무기 검사로 막혔던 작골염양·검호 난도 후속타·광분화·용의 질주·용의 브레스·삼조격·3연베기·야수 화염방사·대폭발·참수·강펀치·축복의 구슬을 카멜레온 학습자에게 연결했습니다. 차크람 분열은 활성화 시 즉시 투척하고 버프 중 같은 기술 재사용으로 반복 투척합니다(0.75초 간격, 추가 MP·학습 횟수 없음). 마법 기술은 원래 계열처럼 마력 보정을 받습니다. 천궁 마나 화살·날개·용기사 3타 회복 등 고유 패시브는 자동 승계되지 않습니다. 빛 충전·조준 대상 등 각 기술의 조건은 충족해야 합니다.

검증은 코드 검토와 모의 API 실행입니다. 실제 Bedrock 클라이언트의 명중률·피격 무적·렌더링·PvP 승률을 측정한 결과는 아닙니다.
