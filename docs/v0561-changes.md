# RPG v0.5.61 — 전직관 소환알·구조물 보호·실패 정리

## 전직관 소환알
- 관리자 `/rpg:hito`: 전직관 소환알 선택 메뉴.
- 관리자 `/rpg:hito 검사`, `/rpg:hito 마법사`, `/rpg:hito 투신`, `/rpg:hito 해커`: 해당 전직관 소환알 1개를 지급합니다. 해커 소환알로는 기존 로토가 배치됩니다.
- 관리자 `/rpg:egg`의 전직관 그룹에서도 받을 수 있습니다. 크리에이티브 인벤토리에도 네이티브 소환알이 표시됩니다.
- 18종: 검·마법·궁수·성직·격투·투신·암살·작살·광전사·천체·마법공학·혈술·로토·악마·카멜레온·냉기·화염·용.
- 소환알을 원하는 바닥에 사용하면 NPC를 그 위치에 배치합니다. 기존 전직관의 이동 정지·넉백 방지·지속 유지·상담 기능은 유지합니다. 투신은 별도의 전직관이며 기존 격투 전직관 외형 리소스를 사용합니다.
- `/rpg:hito` 명령은 앞에 NPC를 즉시 생성하던 동작에서 소환알 지급으로 바뀌었습니다. 명령의 관리자 권한은 그대로입니다. 기존에 배치된 전직관은 유지됩니다.
- 인벤토리가 가득 차면 덮어쓰지 않고 지급을 중단합니다. 직업 무기용 첫 칸도 보존합니다.

## 던전·신전 보호
- 등록된 던전과 천체 신전의 채굴을 일반 플레이어·크리에이티브·관리자 모두 차단합니다. 신전의 관리자 직접 파괴 예외를 제거했습니다.
- TNT·크리퍼 등 폭발에서 해당 구조물 블록을 제외합니다. 바깥의 다른 블록은 기존 폭발 판정을 유지합니다.
- 보호 영역에 블록을 놓거나 양동이·부싯돌·뼛가루·도구로 변형하는 상호작용도 차단합니다. 보호 경계 밖에서 안쪽 면에 블록을 놓는 동작도 검사합니다.
- 경계를 밀고 당길 수 있는 거리의 피스톤 설치를 차단합니다. 이 보호는 플레이어 설치·상호작용·채굴과 폭발 이벤트를 대상으로 하며, 운영자가 실행하는 `/fill`, `/setblock` 등 직접 명령을 차단하는 기능은 아닙니다.
- 신전 제단 상호작용과 NPC 소환알 배치는 유지합니다. 등록을 명시적으로 해제하는 기존 운영 명령은 유지하며, 등록 해제한 건물은 이 보호의 대상에서 제외됩니다.
- 기존에 등록된 던전·신전도 새 버전에서 보호됩니다. 새로 지을 필요가 없습니다.

## 던전 실패 시 몹 정리
- 일반·엘리트 5분 또는 보스 3분 초과, 전원 사망, 입장 실패 등 실패 종료 시 해당 던전 내부의 살아 있는 몹을 모두 제거합니다.
- 태그가 없는 바닐라 몹·추가 소환된 몹도 검사합니다. 해당 전투에서 추적 중이던 몹과 해당 던전 태그가 붙은 이탈 몹도 정리합니다.
- 단순 처치 이벤트 대신 제거로 처리해 실패 정리에서 경험치·전리품·전직 처치·클리어 보상을 얻지 못하게 했습니다.
- 플레이어, 전직관, GPT NPC, 갑옷 거치대, 바닥 아이템·경험치 구슬은 보존합니다. 다른 던전과 구조물 아래 지상·밖의 몹은 일괄 정리하지 않습니다.
- 청크가 나중에 로드되는 잔여 몹은 실패 상태를 저장해 로드 시 정리합니다. 다음 전투의 첫 몹을 생성하기 전에도 이전 실패 잔여 몹을 검사합니다.
- 서버 재시작으로 중단된 전투도 같은 실패 정리 경로를 사용합니다.

## 설치와 검증
v0.5.60을 기반으로 세 팩의 UUID를 유지하고 버전을 0.5.61로 올렸습니다. 기존 장비 등급·강화·합성·원본 무기 도트는 유지합니다. 동봉된 BP·명령어 BP·RP를 모두 0.5.61로 갱신·활성화하세요.

자동 테스트 417개(JavaScript 412 + Python 5)를 통과했습니다. 소환알 정의·메뉴·권한·인벤토리 보호·NPC 이름·일반/관리자 구조물 보호·폭발·양동이·경계 설치·실패/재로드 정리를 확인했습니다. 실제 모바일 Bedrock 플레이 실측은 수행하지 않았습니다.
