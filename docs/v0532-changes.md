# RPG v0.5.32 최신 수정 안내

## 이번 요청 반영

- 히드라: RPG XP 900, 마공학 골렘: RPG XP 850. 같은 파티는 기존 규칙대로 근처 4명까지 각자 75%로 받으므로 각각 675 / 637.5 XP입니다. RPG 레벨 경험치이며 바닐라 경험치 구슬 수치가 아닙니다.
- 샌드백 소환 아이템: 작업대 9칸을 건초 더미로 채워 1개 제작. `/rpg:craft`의 샌드백 제작법에도 표시했습니다. 소환 후 파괴하여 무투가·권골 전직 진행을 쌓습니다.
- 성직자 계열 광역 보호·힘·회복·축복 영역: 자신과 같은 파티·길드·팀 플레이어에게만 지원합니다. 적 플레이어에게 회복·재생·저항 등 지원 효과를 주지 않습니다. 적에게 적용되는 영역 둔화는 유지합니다.
- 생명 룬: +0~+5에서 최대 HP +4 / +8 / +12 / +16 / +20 / +24. 강화마다 실제 HP 4씩 증가합니다. 전체 HP가 엔진 효과 상한(+1,024)에 도달한 특수 캐릭터는 예외입니다. 강화비용은 동일합니다. 기존 룬도 저장된 강화 단계를 그대로 읽어 새 수치를 적용합니다.
- 지능: 기본 5, 상한 50은 유지. 기본 5 초과 투자분을 기준으로 최대 마나 소비 40% 절약(기존 67.5%). 추가 1점당 약 0.889%p이며 최종 소비량은 올림합니다. 지능 50의 메테오는 MP 700→420, 섬멸 MP 40→24입니다. 최대 마나 자체를 40%로 제한한 것이 아닙니다. 천궁의 마나 화살은 기존대로 발당 MP 20 고정입니다.
- 재접속 쿨타임: 공통 스킬·기본 공격·미카엘 불사 대기시간의 만료 시각을 플레이어 동적 속성에 저장합니다. 재접속·월드 재시작 후에도 남은 시간부터 이어집니다. 오프라인으로 보낸 실제 시간도 대기시간에 포함하므로, 남은 60초 중 10초 뒤 재접속하면 약 50초가 남습니다. 서버 정지·심한 틱 지연 때에는 온라인 틱과 실제 시각의 차이가 있을 수 있습니다. 업데이트 전 버전이 이미 잃어버린 메모리 쿨타임은 복원할 수 없습니다.
- 카멜레온 스킬 분해 후 이미 부여된 버프를 별도로 지우는 기능은 추가하지 않았습니다. 스킬북 기술 SP 환급도 유지합니다. 재부팅과 계약의 기존 효과·재부팅 제외 목록은 유지합니다.

## 카멜레온 기술 호환

원래 직업이 아니라는 이유로 배운 기술이 취소되거나 후속 효과가 끊기는 경로를 수정했습니다.

| 기술 | 수정한 동작 |
|---|---|
| 작골염양 | 카멜레온 전용 무기로 회전·점프 돌진 진행 |
| 검호 난도 | 첫 타격 뒤의 2·3번째 참격까지 진행 |
| 타락검성 광분화 | 날개 강제 장착 없이 흡혈 효과 사용 |
| 용의 질주·용의 브레스 | 발동·이동·지속 투사체 판정 허용 |
| 삼조격 | 다음 3타 추가 피해와 마지막 기절 적용 |
| 3연베기·야수 화염방사·대폭발 | 원래 직업 검사로 취소하지 않고 연속·지연 공격 진행 |
| 참수 | 카멜레온 전용 무기의 다음 기본 근접 공격에 4배 강화 적용 |
| 강펀치 | 기본 근접 공격에서도 배운 강화 효과 소비·적용 |
| 축복의 구슬 | 배운 카멜레온도 아군에게 부착·유지 |
| 차크람 분열 | 활성화 시 즉시 투척. 버프 중 이 기술을 다시 사용하면 추가 투척. 0.75초 간격, 반복 투척에 추가 MP·학습 횟수 소비 없음 |
| 마법사·혈술·성직·냉기·화염·해커·마공학·악마 계열 마법 피해 | 카멜레온도 원래 계열처럼 마력·비전 룬 보정을 사용. 명시된 물리 공격은 근력·힘 룬 보정 유지 |

빛 저장/충전, 적 조준, 아군 거리 등 각 기술 고유 조건은 필요합니다. 천궁의 마나 화살·날개 비행·용기사 기본 3타 회복 등 새로운 고유 패시브 승계는 추가하지 않습니다. 기존에 야수 광분화를 배운 카멜레온이 얻던 처치 버프는 유지합니다. 실제 야수만 얻는 광분화의 흡수 IV도 기존 규칙 그대로입니다. 직업을 타락검성·용기사 등으로 바꿔 흉내 내는 방식은 사용하지 않습니다.

## 아군 피해 차단과 레벨 방어란?

**아군 피해 차단**은 같은 파티·길드·`rpg_team_*` 팀 플레이어 사이의 피해를 막으려는 기능입니다. RPG 기술의 대상 선정과 피해 함수에서는 아군을 걸러냅니다. 일반 근접·바닐라 화살까지 최종 피해를 취소하는 별도 처리도 있지만, 현재 사용 중인 안정판 API에서 지원하지 않는 `world.beforeEvents.entityHurt`에 연결되어 있어 전역 차단은 보장되지 않습니다. 성직자 광역 지원 대상 수정과는 별개입니다.

**레벨 방어**는 방어구 종류와 별도로 RPG 레벨당 받는 피해를 0.35% 줄이는 설계입니다. 레벨 10→3.5%, 50→17.5%, 100→35%, 상한 45%입니다. 자연 성장 최대 레벨 100에서는 35%이며 관리자 레벨 129 이상부터 45%에 도달합니다. 하지만 이 수치도 같은 미지원 피해 전 이벤트에서 최종 피해를 바꾸므로, 메뉴에 나오는 수치만으로 실제 감소가 적용됐다고 볼 수 없습니다. 이 두 전역 시스템은 이번 요청에서는 의미와 현황을 설명했으며 따로 구현 교체하지 않았습니다. 용기사 표식·영역 외부 투사체 차단 등 같은 이벤트를 쓰는 일부 효과도 API 제한이 남습니다.

## 강화 비용과 다운로드 파일

[풀강 비용·시간 비교](v0532-enhancement-costs.md)에 실패·강등·파괴 후 재강화까지 계산했습니다. 강화 확률·가격은 이번에 바꾸지 않았습니다. 계산용 원본 수치는 `강화비용_계산결과.json`, 재현 도구는 `tools/compare_enhancement_costs.mjs`입니다.

`dist/RPG_v0532.mcaddon`은 행동팩·명령어팩·리소스팩 3개를 포함합니다. 기존 UUID를 유지하고 팩 버전을 0.5.32로 올렸습니다. 월드를 복사한 뒤 업데이트하고 세 팩이 모두 0.5.32인지 확인하세요. Bedrock 클라이언트 실기 테스트는 수행하지 못했으며 모의 API 테스트와 패키지 무결성을 검사했습니다.
