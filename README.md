# RPG 애드온 v0.5.64 — 통합 공물·평화 서버 룰북·사냥 구역

[설치용 애드온 다운로드](downloads/RPG_v0564.mcaddon?raw=true) · [소스와 안내](downloads/RPG_v0564_source_and_notes.zip?raw=true)

- `/rpg:offer`: 검과 책을 바칩니다. 이전 `/rpg:book`·`/rpg:sword` 명령과 실행 경로를 제거했습니다. 별도 비공개 공물 안내 버튼도 제거했습니다.
- `/rpg:rulebook`: 41쪽의 서명된 평화 서버 종합 룰북을 받습니다. 기초 지식·서바이벌 명령·룬·장비·강화·합성·파티·던전·신전·사냥 구역을 정리했습니다. 관리자 명령·히든 전직 방법은 제외했습니다.
- PvE 서버 설정: RPG 플레이어 대상 공격과 바닐라 PvP를 끄고, 회복·아군 지원과 몬스터 전투를 유지합니다.

오버월드 X·Z 중 절댓값이 큰 값으로 사냥 구역을 나눴습니다. Y는 무관하고 경계는 안쪽 구역에 포함합니다.

| 구역 | 범위 | 밤 몬스터 |
|---|---|---|
| 초반 | ±1,500 이내 | 버섯·초록 고블린 |
| 중반 | 초반 밖, ±4,000 이내 | 빨강·황금·대장 고블린 |
| 후반 | 중반 밖, ±10,000 이내 | 엘리트 버섯·고블린 |
| 10,000 밖 | 후반 유지 | 후반 몬스터 |

바닐라 적대 몹은 오버월드 동굴에서 자연 출현하도록 변경했습니다. 동물은 기존대로 유지합니다. 사막 몬스터 6종은 사막에서 낮밤·좌표 제한 없이 출현합니다. 던전 전투 몹·수동 소환·네더/엔드 생태는 별도로 유지합니다.

BP·명령어 BP·RP를 모두 0.5.64로 갱신·활성화하세요. 기존 UUID·장비·진행도·등록된 구조물을 유지합니다. 룰북은 `/rpg:rulebook`으로 새로 받으세요.
