# RPG 애드온 v0.5.52 — 스킬 밸런스·저주의 구슬 개편

[설치용 애드온 다운로드](downloads/RPG_v0552.mcaddon?raw=true) · [소스와 전체 안내](downloads/RPG_v0552_source_and_notes.zip?raw=true)

초구체·블랙홀 피해를 1.3배로 올리고, 스매쉬·파멸의 검·화염방사·회전베기·영혼작살·피의 창·더미데이터의 요청 수치를 반영했습니다. 축복 영역은 재생 최소 V·쿨타임 150초, 저주의 방패는 저항 III입니다. 힐을 제외한 성직자 계열 지원 효과는 아군만 받습니다.

저주의 구슬은 좌클릭 부착·우클릭 원거리 발사를 지원합니다. 시듦 III 10초, 부착 중 받는 피해 +35%, 타천과 30칸 이상 떨어지면 해제됩니다. 시전자당 대상 하나이며 피해 증가는 중첩하지 않습니다. 망나니 계열 내려찍기는 폭발 피해 18 후 띄우기, 참수는 기존 평타 4배에 HP 15% 미만 처형을 추가했습니다. 야수 광분화에는 흡혈 15%를 추가했습니다.

피의 창은 힘 버프를 제외한 기본 마법 피해 14로 무적 시간을 무시합니다. 혁린약동•재는 활성화 1분 뒤 시듦 V를 부여합니다. 자세한 수치와 적용 기준은 변경 안내에서 확인하세요.
