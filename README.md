# RPG v0.6.32 다운로드

[설치 파일 다운로드](downloads/RPG_v0632.mcaddon?raw=true) · [ZIP 다운로드](downloads/RPG_v0632_download.zip?raw=true)

Bedrock 1.21.100 이상. `.mcaddon`을 가져온 뒤 RPG BP·Commands BP·RP 세 팩을 모두 v0.6.32로 활성화하고 월드를 다시 여세요.

- **부동산 공동 건축**: 구매자 또는 구매자와 현재 같은 길드·파티인 플레이어가 해당 청크를 수정할 수 있습니다. 둘 중 하나만 같아도 허용하며 구매자가 오프라인이어도 적용합니다.
- **즉시 권한 반영**: 실제 가입 명단을 사용합니다. 탈퇴·추방·해산으로 같은 그룹이 아니게 되면 권한을 회수합니다. 소유권은 구매자에게 유지됩니다.
- **바닥·지하 보호 유지**: 구매자와 길드원·파티원 모두 마을 바닥과 그 아래를 파괴할 수 없습니다. 허용된 사용자는 바닥 위에 건축할 수 있습니다.
- 기존 구매 청크를 다시 살 필요가 없습니다. 구매권 안내와 청크 미리보기에 공동 수정 권한을 표시합니다.
- 다이아몬드 5개당 마을 1청크, 마법사 마나 절반·선택 평타 1초/피해 0.8배, 상태창 분류, 날개 속도·마나 공물 등 이전 기능을 유지합니다.
