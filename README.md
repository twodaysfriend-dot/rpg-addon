# RPG 애드온 v0.5.41 — 화면 정리·던전 생성 복구·이탈 방지·즉시 증원

[설치용 애드온 다운로드](downloads/RPG_v0541.mcaddon?raw=true) · [소스와 전체 안내](downloads/RPG_v0541_source_and_notes.zip?raw=true)

- **방어구 게이지·상태효과 아이콘 숨김**. 실제 갑옷 방어력·버프/디버프 효과는 유지합니다.
- **던전 생성 완성 검사**. 전체 바닥·벽·천장을 검사하고 청크 지연이나 누락 좌표를 재시도한 뒤 개방합니다. 기존 등록 동굴의 누락도 자동 검사·복구합니다.
- **전투 중 이탈 방지**. 살아 있는 참가자는 자진 퇴장할 수 없고, 돌진/순간이동으로 경계를 넘지 못하게 합니다. 외부 이동·차원 이동·진행 중 재접속은 내부로 복귀시키며 참가 상태와 제한 시간을 유지합니다. 사망·클리어·시간 초과의 정상 종료는 유지합니다.
- **빈 전장 즉시 증원**. 남아 있는 진행 몬스터가 없으면 다음 일반/엘리트 증원을 앞당깁니다. 일반 50 + 엘리트 5 실제 처치 후 보스 1, 일반/엘리트 5분 + 보스 3분 규칙은 유지합니다. 자동 복귀와 증원은 채팅으로 알리지 않습니다.

[전체 변경·동작·제한 안내](docs/v0541-changes.md) · [SHA-256](downloads/SHA256SUMS_v0541.txt)

기존 동굴도 관리자가 `/rpg:dungeoncreate 1` 또는 `/rpg:dungeoncreate all`로 등록 위치에서 재검사·누락 복구할 수 있습니다. 진행 중이거나 대기자가 있는 던전은 제외합니다. 다른 블록을 강제로 덮어쓰지 않으며, 생성 도중에는 일부만 보일 수 있지만 전체 완성 검사를 통과하기 전에는 입장할 수 없습니다.

던전의 자동 안내는 채팅 대신 간단한 HUD 알림을 사용합니다. 잘못된 직접 명령의 오류 응답은 유지합니다. 대기실 참가 취소는 계속 가능하며 서버 재시작은 기존처럼 진행 중 전투를 취소하고 귀환 지점을 복구합니다.

이전 상위 던전 보상, 기여 파티원 전직 처치, 천사 회복 보상, 초기화 주문서·전직 포기각서, 바닐라 XP 10/30/5, 투신·흡수 룬·해커 변경은 포함합니다. 행동팩·명령어팩·리소스팩을 모두 0.5.41로 갱신하세요.

검증: JavaScript 시나리오 231개와 Python 5개, 총 236개 통과. JSON 442개·JS 129개 구문·모듈 경로·128px 이미지·ZIP 무결성을 검사했습니다. 실제 Bedrock 클라이언트의 화면·청크 로딩·전투는 실기 검증하지 못했습니다.
