# RPG 애드온 v0.5.58 — 룬 10개 중복 장착·히드라 브레스

[설치용 애드온 다운로드](downloads/RPG_v0558.mcaddon?raw=true) · [소스와 전체 안내](downloads/RPG_v0558_source_and_notes.zip?raw=true)

룬 슬롯을 최대 10개로 늘리고 같은 종류 중복 장착을 허용했습니다. 이전 3슬롯은 기존 룬·강화·장착 순서를 보존해 10슬롯으로 이전합니다. 같은 개체 UID는 여러 칸에 복제할 수 없습니다. 피해 증가율·HP·MP 재생·흡혈은 합산하며, 저항 같은 상태 효과 단계는 기존처럼 최고 단계 하나를 적용합니다. 힘 +5 룬 10개는 물리 피해 +300%(룬 배율 4배)입니다. 보관함 30칸·강화 비용·확률·사냥 보상은 유지합니다.

히드라는 1초 예고 후 세 머리에서 3초간 브레스를 발사합니다. 사거리 24칸, 0.5초마다 기본 화염 피해 6·최대 6회와 2초 화상. 같은 순간 세 줄기가 겹쳐도 직접 피해는 한 번이며 발사 방향은 고정되어 옆으로 회피할 수 있습니다. 지형에서 막히고 블록 파괴·바닥 발화는 없습니다. 시작 시점부터 최소 10초 간격으로 사용합니다. 전용 모션도 추가했습니다.

현재 공용 평타 무기는 **모험가 전투검**(추가 피해 설정 7·내구 800)과 **별빛 전투창**(추가 피해 설정 9·내구 1200)입니다. 누구나 작업대에서 제작하며 직업 스킬은 전용 시전 아이템을 사용합니다. 자세한 재료는 변경 안내와 /rpg:craft에서 확인하세요.

이전 골렘 확대·보스 모션·GPT NPC·안내 정책 등 기능을 포함합니다. 세 팩을 함께 0.5.58로 갱신하세요. 기존 UUID와 저장 정보를 유지합니다. 이전 20시간 강화 지표는 갑옷 4부위 + 룬 6종 각 1개 기준이며 10개 장착 풀강과는 다릅니다.

자동 검증 379개 통과(JavaScript 374 + Python 5). 룬 이전·중복·UID 이동·효과 합산·10번 슬롯 UI와 브레스 예고·횟수·중복 피해 방지·지형 차단·회피·중단, 팩 무결성을 검사했습니다. 실제 Bedrock 전투·렌더링은 미검증입니다.
