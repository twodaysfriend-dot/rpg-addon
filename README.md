# RPG 애드온 v0.5.46 — 작골염양 3회 베기·검호 난도 초승달 연출

[설치용 애드온 다운로드](downloads/RPG_v0546.mcaddon?raw=true) · [소스와 전체 안내](downloads/RPG_v0546_source_and_notes.zip?raw=true)

**작골염양**을 기존 대상당 1회에서 **0.5초 간격, 최대 3회 베기**로 변경했습니다. 타격당 기본 피해는 검성 27·검사/타락검성/카멜레온 18을 유지하며 전부 맞으면 기본 합계 81·54입니다. MP 50·쿨 8초·반경 3.4칸·4초 화상은 유지합니다. 7칸 돌진을 마쳐도 남은 베기를 이어갑니다. 적이 범위를 벗어나거나 벽에 막히면 전부 맞지 않을 수 있습니다. 시전자 사망·무기 해제·차원 이동 시 남은 공격은 멈춥니다.

**검호 난도**는 매 타격에 큰 청록 초승달 3개와 작은 보랏빛 참격 12개가 전방에서 교차하도록 연출을 강화했습니다. 기존 궤적·소리도 함께 표시합니다. 피해는 기존 12×3=36, 사거리 5.5칸·MP 65·쿨 11초를 유지합니다. 카멜레온이 배운 기술도 동일하게 반영합니다.

[변경·설치 안내](docs/v0546-changes.md) · [현재 136개 스킬 도감](docs/v0546-skills.md) · [SHA-256](downloads/SHA256SUMS_v0546.txt)

월룡륜미 전방 180도·힘 버프의 물리/마법 보정·고정 피해 유지·/rpg:ask 내장 안내·복수귀·던전·HUD 등 이전 기능을 포함합니다. 행동팩·명령어팩·리소스팩을 모두 0.5.46으로 갱신하세요. UUID와 플레이어 저장 정보는 유지합니다.
