# RPG v0.6.16 다운로드

[설치 파일 다운로드](downloads/RPG_v0616.mcaddon?raw=true) · [ZIP 다운로드](downloads/RPG_v0616_download.zip?raw=true)

`.mcaddon`을 가져온 뒤 RPG BP·Commands BP·RP 세 팩을 모두 v0.6.16으로 활성화하세요. ZIP은 압축을 풀고 안의 `.mcaddon`을 여세요.

- 마을 계단 지붕·처마·용마루, 석재·이끼 바닥 문양, 벤치·시장 차양·나무·화단
- 기존 250×250 마을은 같은 위치에서 장식 자동 갱신
- 마을 자연 몬스터 정리, 동물·주민·전직관·직접 소환한 몹 보존
- 경험치 상점: 주민 소환알 1개 30레벨 / 좀비 소환알 1개 50레벨
- `/rpg:runebatch`: 선택한 종류·등급의 룬을 각각 1회 일괄 강화
- `/rpg:creativefunds` 또는 크리에이티브 무한 재화 지급권: 골드·강화석·룬 가루 반복 충전
- 혈술사 카드·스킨, 더 월드 숙련도·흡혈, 10단계 던전 등 이전 기능 포함

명령어: `/rpg:citycreate` · `/rpg:citystatus` · `/rpg:wallet` · `/rpg:runebatch` · `/rpg:creativefunds`
