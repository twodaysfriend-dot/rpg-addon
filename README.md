# RPG v0.6.48 다운로드

[설치 파일 다운로드](downloads/RPG_v0648.mcaddon?raw=true) · [ZIP 다운로드](downloads/RPG_v0648_download.zip?raw=true) · [전체 소스·테스트](downloads/RPG_v0648_source.zip?raw=true)

Bedrock 1.21.100 이상. BP·Commands BP·RP 모두 v0.6.48로 활성화하고 월드를 다시 여세요.

**감옥 설치:** 관리자가 오버월드의 넓고 빈 평지에서 `/rpg:jailcreate`를 실행하세요. 내부 1×1 감옥 10칸과 대기/출구 발판을 생성합니다. 기존 블록과 겹치면 중단합니다.

- 비합의 PK 1회당 스택 +1, 3회마다 수감하고 스택0. 합의된 결투/기존 유예·정당한 현상금 처치는 제외합니다.
- 형기 **5분→10분→20분→40분…**, 실제 감옥 안 게임 틱만 차감. 1칸 이탈·다른 차원·사망·미접속·빈 칸 대기는 차감하지 않습니다.
- TPA 양방향·수락 직전 재검사, 스킬·던전·결투 이동 차단. 이탈 시 원래 칸으로 복귀합니다.
- 관리자 `/rpg:jailrelease 이름`으로 즉시 석방, `/rpg:jailreset 이름`으로 PK 스택/형기 배율 초기화(수감 중이면 남은5분, 다음 수감도5분), `/rpg:jailstatus [이름]`으로 관리합니다. 일반 플레이어는 `/rpg:jail`로 자신의 상태를 봅니다.
- 기록은 재접속/월드 재시작 후 유지합니다. 10칸이 모두 차면 처분을 보관하고 빈 칸이 생길 때 배정합니다. 오프라인 석방은 다음 접속 때 출구로 이동합니다.
- 기존 용기사·던전 밸런스·미사용 데이터 정리는 유지합니다.
