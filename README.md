# RPG 애드온 v0.5.69 — 스킬 피해·솔로 시간·승급 개편

[설치용 애드온 다운로드](downloads/RPG_v0569.mcaddon?raw=true) · [소스와 안내](downloads/RPG_v0569_source_and_notes.zip?raw=true)

- 심판 기본 피해 65, 블랙홀 지속 합계 50, 초구체 50, 번개 3회 합계 25.
- 혼자 출발한 던전의 일반·엘리트 제한 7분 30초, 보스 4분 30초. 파티는 기존 5분·3분 유지.
- 같은 종류·등급의 +5 이상 두 개로 승급 가능. 둘 다 +10이면 확정 승급하며 +10/+5 조합은 확정이 아닙니다.
- 성공하면 다음 등급 +0, 재료 장비 1개 소모. 실패하면 룬·갑옷·무기 두 개 모두 보존하며 50% 확률로 주장비만 -1강됩니다.
- 갑옷 보호 IV 책·공용 무기 날카로움 V 책은 성공·실패 모두 기존처럼 1권 소모하며 룬은 책이 필요 없습니다.

[상세 변경 안내](docs/v0569-changes.md) · [SHA-256](downloads/SHA256SUMS_v0569.txt)

BP·명령어 BP·RP 모두 새 버전으로 적용하세요. 팩 UUID와 기존 레벨·카멜레온·장비·재화 저장 키를 유지합니다. 종합 룰북은 `/rpg:rulebook`으로 새로 받습니다.

자동 검사 471개(JavaScript 466 + Python 5)와 JSON·스크립트·리소스·팩 무결성을 확인했습니다. 실제 모바일·렐름 플레이는 직접 검증하지 못했습니다.
