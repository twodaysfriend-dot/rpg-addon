# RPG v0.6.17 다운로드

[설치 파일 다운로드](downloads/RPG_v0617.mcaddon?raw=true) · [ZIP 다운로드](downloads/RPG_v0617_download.zip?raw=true)

`.mcaddon`을 가져온 뒤 RPG BP·Commands BP·RP 세 팩을 모두 v0.6.17으로 활성화하세요. ZIP은 압축을 풀고 안의 `.mcaddon`을 여세요.

- 스킬 도감·스킬 설정·전직 상세에 직업별 추천 근력·마력 표시
- 카멜레온은 **복합**으로 표시하며 학습창에서도 확인 가능
- **`/rpg:setgrade 신화`**: 손에 든 RPG 장비 등급 지정 (관리자)
- **`/rpg:setgrade 전설 head`**: 착용 투구 등급 지정
- **`/rpg:setgrade 6 rune1`**: 장착 룬 1번 등급 지정
- 일반~신화 또는 0~6, 강화 단계와 기존 옵션 유지
- RPG 갑옷·공통 무기·보관 룬 지원. 직업 전용 무기는 기존 강화 전용 규칙 유지
- v0.6.16 마을·상점·룬 일괄 강화·크리에이티브 재화와 이전 기능 포함
