# RPG 애드온 v0.5.45 — 월룡륜미 180도·힘 마법 보정·정보 안내

[설치용 애드온 다운로드](downloads/RPG_v0545.mcaddon?raw=true) · [소스와 전체 안내](downloads/RPG_v0545_source_and_notes.zip?raw=true)

월룡륜미의 피해 판정과 초승달 이펙트를 **시전 방향의 전방 180도**로 변경했습니다. 시전 후 고개를 돌려도 방향이 바뀌지 않습니다. 반경 12칸·기본 피해 28·MP 70·쿨 9초와 벽 가림·아군 제외·적마다 1회 타격은 유지합니다.

힘 버프는 이제 **물리·마법 스킬** 모두에 단계당 +3을 더합니다. 이후 물리는 근력·물리 장비, 마법은 마력·마법 장비 보정을 받습니다. 고정 피해는 그대로이며 무투가의 기존 힘 계산과 평타 배수에는 중복 적용하지 않습니다.

**RPG 정보 안내**를 추가했습니다. `/rpg:ask`로 입력창을 열거나 `/rpg:ask "해커 전직 조건"`, `!rpg ask 샌드백 제작법`을 사용하세요. 본인에게만 답하며 실제 직업·스킬·룬·갑옷·제작·던전 데이터에서 관련 도감 항목을 보여줍니다. 다른 주제·없는 정보는 추측하지 않습니다. 기본판은 API 키 없이 일반 월드·친구 초대·Realm에서 내장 도감을 검색합니다.

외부 AI API 연결은 **BDS 전용 선택 코드**로 제공합니다. 실제 서버와 API 키가 제공되지 않아 실서버 연결은 활성화하지 않았습니다. 외부 AI는 관련 자료 ID만 고르고 실제 설명은 애드온 도감에서 표시하여 범위를 제한합니다. 서버 오류 시 내장 도감으로 대체합니다. [서버용 연결 자료 다운로드](downloads/RPG_v0545_API_server.zip?raw=true) · [설정 안내](docs/v0545-api.md)

복수귀 딥 피어스·찢어내기/기술 순서, 검성 피해 상향, 던전 완성 검사/복구·이탈 방지·즉시 증원, 방어구/버프 HUD 숨김 등 이전 기능을 포함합니다. 행동팩·명령어팩·리소스팩을 모두 0.5.45로 갱신하세요. UUID와 플레이어 저장 정보는 유지합니다.
