# RPG 애드온 v0.5.55 — 오프라인 효과 검색·전직 공개 범위

[설치용 애드온 다운로드](downloads/RPG_v0555.mcaddon?raw=true) · [소스와 전체 안내](downloads/RPG_v0555_source_and_notes.zip?raw=true)

`/rpg:ask "데미지 버프 주는 기술은 뭐야?"`처럼 기술명을 몰라도 효과별 목록을 API 없이 안내합니다. 공격 강화·회복/흡혈·방어/보호·적 제어의 정해진 질문 유형을 지원합니다. 실제 기술 도감에서 목록과 사용 직업을 표시하고, 기술명을 입력하면 상세 설명을 안내합니다.

밸런스 평가·사기 여부·티어·순위·우열·직업 추천은 API 연결 여부와 관계없이 답하지 않습니다. 다른 질문과 섞여 있어도 전체를 거절합니다. 객관적 기술 수치와 효과는 안내합니다.

전직 방법은 **검사·마법사·궁수·무투가·성직자 5개 기본 직업만** 공개합니다. 나머지 직업의 전직 조건은 정보 검색 및 API 전송용 도감에서 제거했습니다. 어댑터·API 브리지에서도 제한 질문을 외부 요청 전에 차단합니다. 히든 직업의 공개 기술 효과·피해 계열은 안내할 수 있습니다.

이 제한은 `/rpg:ask`와 선택 API 연결에 적용됩니다. 실제 전직 조건·게임 메뉴·전투 밸런스는 변경하지 않습니다. 파일에 포함된 전체 개발/스킬 자료까지 비밀로 만드는 기능은 아닙니다.

자동 검증 359개 통과(JavaScript 354 + Python 5). 효과별 오프라인 응답, 혼합 밸런스 질문 차단, 모든 비공개 직업 전직 질문 차단, 기본 5종 공개, API 후보 정보 제거 및 어댑터/브리지의 네트워크 호출 차단을 검사했습니다. 실제 Bedrock 화면·외부 API 연결은 미검증입니다.
