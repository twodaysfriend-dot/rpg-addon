# RPG 애드온 v0.5.72 — 무기 자세·결투·PK

[설치용 애드온 다운로드](downloads/RPG_v0572.mcaddon?raw=true) · [소스와 안내](downloads/RPG_v0572_source_and_notes.zip?raw=true)

무기 모델을 바닐라 삼지창의 아이템 슬롯·손잡이 좌표와 1인칭·3인칭 착용 애니메이션에 맞춰 다시 구성했습니다. 보이는 공용·직업 무기 39종의 2배 모델 크기와 원본 PNG는 유지합니다. 실제 모바일 화면은 직접 실행하여 검증하지 못했습니다.

일반 PvP를 활성화했습니다. `/rpg:pvp`로 상대를 선택해 신청하고 수락하면 양쪽 최대 HP 회복 → 3초 준비 → 결투를 시작합니다. 결투는 패배 직전 비살상 종료하며 PK·현상금이 없습니다. 마나·쿨타임은 초기화하지 않습니다. `/rpg:pvp accept`, `/rpg:pvp surrender`도 사용할 수 있습니다.

결투 밖에서 플레이어를 살해하면 붉은 PK 표식이 저장됩니다. PK 플레이어를 처치하면 상대의 골드 지갑에서 최대 50,000골드를 차감하여 받으며 새로운 PK 패널티가 생기지 않습니다. 잔액이 부족하면 있는 만큼만 지급합니다. PK는 다른 플레이어에게 처치되면 해제되며 재접속·환경 사망으로 지워지지 않습니다.

Bedrock 사용자 명령의 네임스페이스 제한 때문에 정식 명령은 **`/rpg:pvp`**입니다. `/pvp` 별칭은 런타임이 허용하는 경우만 등록됩니다. 채팅 이벤트 지원 환경에서는 `!pvp`도 연결됩니다.

[변경 사항·결투 규칙 상세](docs/v0572-changes.md) · [SHA-256](downloads/SHA256SUMS_v0572.txt)

기존 팩을 비활성화하고 **RPG BP·RPG Commands BP·RPG RP 모두 v0.5.72만 활성화한 뒤 월드를 다시 여세요.** 기존 팩 UUID와 성장 데이터 저장 키는 유지했습니다. `/rpg:rulebook`으로 최신 규칙이 담긴 책을 받을 수 있습니다.

자동 검사 497개(JavaScript 492 + Python 5)를 통과했습니다. 원본 도트 보존, 모델 구조, 스크립트·팩 무결성과 결투·PK·현상금 처리를 모의 게임 API에서 검사했습니다. 실제 Bedrock 모바일·Realm 플레이 검증과는 구분됩니다.
