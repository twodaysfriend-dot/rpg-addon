# RPG 애드온 v0.5.48 — 투신 독립 히든·청백색 충격파

[설치용 애드온 다운로드](downloads/RPG_v0548.mcaddon?raw=true) · [소스와 안내](downloads/RPG_v0548_source_and_notes.zip?raw=true)

투신은 **무투가·권골과 별개 계열의 독립 히든 직업**입니다. 권골 조건을 제거하고, 아무 2차 이상 직업에서 레벨 40·적 150마리·보스 5마리 처치로 전직합니다. 기존 공통 누적 처치를 사용합니다. 기존 투신의 직업 ID·스킬·아이템·저장 정보를 유지하며, 무투가 기술과 패시브를 자동으로 승계하지 않습니다.

첨부 이미지의 청백색 충격파·상향 발차기·연속 폭발·방사형 섬광을 참고해 기술별 전용 파티클과 궤적을 구성했습니다.

| 기술 | 연출 |
|---|---|
| 폭멸타 | 전방 부채꼴 충격파·타격 섬광 |
| 난참 | 연타마다 청백색 충격파·폭발 반복 |
| 폭열권 | 아래에서 위로 솟는 발차기 궤적 |
| 파황각 | 좌우 교차 발차기 궤적·연속 폭발 |
| 풍신열각 | 강화 평타 적중점의 큰 섬광·8방향 충격파 |

피해량·타수·마나·쿨타임은 유지하며, 연출로 주변 적에게 추가 피해를 주지 않습니다. 캐릭터 자세 애니메이션을 새로 추가한 것은 아닙니다. 시전자 사망/차원 이동 시 후속 피해와 연출이 중단됩니다. /rpg:jobs·/rpg:skillguide·/rpg:ask의 설명도 갱신했습니다.

[변경·설치 안내](docs/v0548-changes.md) · [현재 136개 스킬 도감](docs/v0548-skills.md) · [SHA-256](downloads/SHA256SUMS_v0548.txt)
