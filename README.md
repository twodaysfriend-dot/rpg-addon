# RPG 애드온 v0.5.70 — 무기 표시·방사열선 틱 피해 수정

[설치용 애드온 다운로드](downloads/RPG_v0570.mcaddon?raw=true) · [소스와 안내](downloads/RPG_v0570_source_and_notes.zip?raw=true)

공용 무기 7종과 해의 한손 도끼의 확대 attachable·손 결합 모델·1/3인칭 회전 애니메이션을 제거했습니다. 화면을 덮는 별도 모델 대신 바닐라 hand_equipped 도구 렌더링과 기본 크기를 사용합니다. 원본 PNG·아이콘·공격력·강화·등급은 유지합니다. 투신 전용 장갑의 본인 표시 모델도 유지합니다.

방사열선은 발사 중 매 틱 기본 마법 피해 1을 적용합니다. 정상 20 TPS 기준 5초 동안 최대 100회이며 피격 무적 시간을 우회합니다. 반복 타격을 엔진이 거부하면 공통 직접 HP 처리로 대체하며 시전자가 사망하면 중단합니다. 준비 시간·MP·쿨타임·사거리·햇빛 비용과 실시간 시선 추적은 유지합니다.

**이전 BP·명령어 BP·RP를 비활성화하고 v0.5.70 세 팩만 켠 뒤 월드를 다시 여세요.** 이전 RP가 함께 활성화돼 있으면 제거한 모델이 이전 팩에서 다시 적용될 수 있습니다.
