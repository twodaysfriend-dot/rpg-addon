# RPG 애드온 v0.5.44 — 힘 버프의 물리 스킬 피해 적용

[설치용 애드온 다운로드](downloads/RPG_v0544.mcaddon?raw=true) · [소스와 전체 안내](downloads/RPG_v0544_source_and_notes.zip?raw=true)

불굴의 검·광분화·강자의 자세 등에서 얻은 **힘 상태 효과를 물리 스킬 피해에도 적용**합니다. 힘 I +3·II +6·III +9·IV +12를 기본 피해에 더한 뒤 근력과 갑옷·룬 보정을 받습니다. 카멜레온이 배운 물리 기술에도 동일하게 적용합니다. 힘 효과 종료·제거·단계 변경은 다음 피해 계산부터 반영됩니다.

예를 들어 근력 5·장비 보정 없음 기준, 검성 360도 휘두르기는 힘 II 중 **20 → 26**, 검사·타락검성·카멜레온은 **10 → 16**입니다. 일반 다단 공격은 각 타격에 반영됩니다.

무투가의 기존 힘 계산과 강펀치 배율 순서는 유지하며 힘을 두 번 더하지 않습니다. 난타는 기존처럼 힘 증가분을 포함한 총합을 10타로 나눕니다. 평타 2배·4배·10배 역시 엔진이 힘을 계산한 평타 피해를 증폭합니다. 마법·고정 피해는 기존 판정을 유지합니다.
