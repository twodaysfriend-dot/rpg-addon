Bedrock 1.21.100 이상. BP·Commands BP·RP를 모두 v0.6.51로 활성화하고 월드를 다시 여세요.

- **갑옷 능력치 표시·효과 복구:** 심연 수호자 부위당 내구성(방어 강인함) +4·밀치기 저항 +2(20%)를 제작 화면과 기존 아이템 설명에 표시합니다. 유실된 장착 태그를 복구하고 네이티브 밀치기 저항을 재동기화합니다. 기존 강화·등급·이름·인챈트·남은 내구도는 보존합니다.
- **수선 회복 2배:** 수선이 붙은 손/보조 손/장착 갑옷의 기본 회복을 감지해 같은 양을 추가 회복합니다. 최대 내구도에서 멈추며, 추가 경험치 지급·차감은 없습니다. RPG·바닐라 장비 모두 적용합니다.
- **보스 가까운 적 재선택:** 보스 5종의 피격자 우선 고정을 제거하고, 보이고 접근 가능한 가장 가까운 플레이어를 10틱마다 재탐색하도록 설정했습니다. 먼 대상이 숨어도 가까운 적을 공격할 수 있도록 바꿨습니다. 야생과 던전 1~10층에 적용합니다.
- 이전 룬 선택 메뉴·자유 조향 질주·재귀 룬 제작·송금·상점 기능은 유지합니다.
