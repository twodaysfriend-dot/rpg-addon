# RPG 애드온 v0.5.50 — 천체 신전·투신 무기 표시

[설치용 애드온 다운로드](downloads/RPG_v0550.mcaddon?raw=true) · [소스와 전체 안내](downloads/RPG_v0550_source_and_notes.zip?raw=true)

투신 건틀릿에 1인칭 전용 렌더 조건을 추가해 상대 화면과 3인칭에서 손의 무기 그림을 숨기고, 본인 인벤토리 아이콘·1인칭은 유지하도록 설정했습니다. 피해 설정 18과 기술은 그대로입니다. 실제 두 클라이언트의 렌더링은 미검증입니다.

**천체 신전**은 지름 27칸·최대 높이 15칸의 원형 신전으로 해·달 제단, 기둥·아치·해와 달 문양을 갖춥니다. 제단 위는 하늘이 열려 있습니다. 게임 낮에는 해, 밤에는 달 제단이 활성화됩니다.

- 관리자 `/rpg:templecreate`: 앞쪽 약 22칸의 빈 공간에 생성. 기존 블록 검사·분할 건축·청크 대기·완성 검사 후 개방합니다.
- `/rpg:temple`: 위치·활성 제단·전직 메뉴. 제단과 상호작용해도 열립니다.
- 관리자 `/rpg:templeremove`: 등록·보호·전직 기능만 해제하고 건물은 보존합니다.

해·달의 후예는 **활성 신전 제단 주변 4칸에서만 전직**합니다. 아무 2차 이상 직업·레벨20·해당 낮/밤 적60 처치 조건도 유지합니다. 일반 전직 명령어·메뉴·NPC에서도 같은 조건을 검사합니다. 기존 후예는 유지하며 기술 사용 장소를 제한하지 않습니다. 일반 플레이어의 신전 블록 파괴·설치와 폭발을 막고 관리자는 편집할 수 있습니다.

추가 근접 피해 설정이 없는 기본 아이템 직업은 **마법사·현자·궁수·천궁·성직자·천사·미카엘·타락천사** 8개입니다. 맨손 수준의 엔진 기본 피해·힘·인챈트와 화살/스킬 피해는 별도이므로, 공격이 무조건 0이라는 뜻은 아닙니다.
