# RPG 애드온 v0.5.51 — 졸트라크 명중 폭 10칸

[설치용 애드온 다운로드](downloads/RPG_v0551.mcaddon?raw=true) · [소스와 전체 안내](downloads/RPG_v0551_source_and_notes.zip?raw=true)

졸트라크의 명중 반경을 2.5 → 5칸으로 넓혔습니다. **전체 명중 폭 10칸(좌우 5칸)**입니다. 높이 방향도 같은 반경을 사용합니다. 기존 구체형 경로 판정과 대상별 한 번 타격을 유지합니다.

기본 피해96·사거리50·MP1000·쿨30초·준비1초 및 광선 이펙트는 유지합니다. 카멜레온이 배운 기술에도 반영하며 게임 내 /rpg:skillguide·/rpg:ask 설명을 갱신했습니다.

[변경 안내](docs/v0551-changes.md) · [현재 스킬 도감](docs/v0551-skills.md) · [기본 아이템 피해 목록](docs/v0551-melee.md) · [SHA-256](downloads/SHA256SUMS_v0551.txt)

천체 신전·투신 표시·성장/장비 등 이전 기능을 포함합니다. 세 팩을 모두 0.5.51로 갱신하세요. UUID와 기존 저장 정보를 유지합니다.

[선택 BDS API 자료](downloads/RPG_v0551_API_server.zip?raw=true) · [서버 설정](docs/v0551-api.md).

자동 검증 326개 통과(JavaScript 321 + Python 5). 경계 명중·범위 밖 제외·1회 타격·준비 후 피해·JSON/JS/리소스/ZIP 무결성을 확인했습니다. 실제 Bedrock 전투는 미검증입니다.
