# RPG 애드온 v0.5.35 — 작은 왼쪽 아래 HUD

[애드온 다운로드](downloads/RPG_v0535.mcaddon?raw=true) · [소스와 안내](downloads/RPG_v0535_source_and_notes.zip?raw=true)

중앙의 긴 RPG 정보 대신 작은 왼쪽 아래 표시를 사용하도록 리소스팩 UI를 추가했습니다.

```text
검성의 검
360도 휘두르기 준비
HP 25/100  MP 20k
```

던전 안에서만 짧은 진행 표시 한 줄을 추가합니다. 레벨·직업 반복·다음 스킬·슬롯 번호는 숨겼으며 반복 재화 획득 채팅도 줄였습니다. 보상 지급·던전 규칙·스킬 수치는 유지합니다.

행동팩·명령어팩·리소스팩을 모두 0.5.35로 갱신하세요. 위치 변경에는 리소스팩 적용이 필수이며 다른 HUD 팩보다 위에 적용해야 합니다. 미적용 시 간소화된 문구만 중앙에 표시될 수 있습니다. 원래 월드와 플레이어 데이터를 보존하는 업데이트입니다.

[세부 표시·위치·호환 설명](docs/v0535-hud.md) · [SHA-256](downloads/SHA256SUMS_v0535.txt)

모의 시나리오 177개와 Python 검증 5개 통과. UI JSON·팩 구문·의존성·압축 무결성 확인. 실제 모바일 렌더링과 조작 버튼 겹침은 실기 검증하지 못했습니다.

기존 던전 생성·진행 명령어는 이전과 동일합니다. 이전 파일: [v0.5.34](downloads/RPG_v0534.mcaddon?raw=true).
