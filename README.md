# RPG 애드온 v0.5.49 — 성장 보완·강화 이전·상위 갑옷·공용 무기

[설치용 애드온 다운로드](downloads/RPG_v0549.mcaddon?raw=true) · [소스와 전체 안내](downloads/RPG_v0549_source_and_notes.zip?raw=true)

좀벌레 보상을 XP 5·골드 2·강화석/룬 가루 0·룬 드롭 0.1%로 조정했습니다. 힘은 물리/마법 스킬에 단계당 +5%를 곱하여 단타와 연타 총합의 증가율을 같게 합니다. 고정 피해와 기본 평타의 엔진 규칙은 유지합니다. 보스의 CC 1회 지속시간과 넉백/밀기는 절반이며, 장판에서 재적용하는 동작은 유지합니다.

**갑옷 강화 이전**: /rpg:transfer 또는 강화 메뉴에서 제작 전에 강화 단계를 이전서로 추출하세요(단계당 골드 500). 원래 갑옷은 +0으로 남습니다. 새 RPG 갑옷을 만든 뒤 같은 부위에 성공률 100%로 적용합니다. 이전서는 소모하며 단계는 합산하지 않습니다. 인챈트/내구도는 대상 장비 것을 유지합니다. 저장 실패 복구·중복 사용·장비 변경 검사를 포함합니다.

**심연 수호자 갑옷**: 기본 방어 합계 20으로 네더라이트와 같고 모든 부위 내구도가 더 높습니다. 4세트는 HP +16·물리/마법 피해 +8%·저항 I 유지입니다. 부위별 숲 수호자 갑옷 1·네더라이트 주괴 1·네더의 별 1·다이아몬드 2·자수정 조각 4로 제작합니다. 기존 수호자 리소스와 발광 효과를 사용합니다.

**공용 평타 무기**: 모험가 전투검(피해 설정 7·내구도 800), 별빛 전투창(9·1,200)을 누구나 작업대에서 제작할 수 있습니다. 직업 기술은 기존 시전 아이템을 사용하세요. 기존 검/창 리소스를 사용합니다.

**솔로 클리어 보너스**: 처음부터 1명으로 출발하면 골드·강화석·룬 가루·촉매를 1.5배(올림) 지급합니다. 룬·일반 보급품·처치 보상·XP는 그대로입니다. 파티원이 사망/접속 종료해 한 명이 남은 경우는 적용하지 않습니다.
