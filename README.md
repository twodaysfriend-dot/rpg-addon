# RPG v0.6.28 다운로드

[설치 파일 다운로드](downloads/RPG_v0628.mcaddon?raw=true) · [ZIP 다운로드](downloads/RPG_v0628_download.zip?raw=true)

Bedrock 1.21.100 이상. `.mcaddon`을 가져온 뒤 RPG BP·Commands BP·RP 세 팩을 모두 v0.6.28로 활성화하세요.

- 천사·미카엘 `/wings 1|2|3`: 기본·2배·5배. `/rpg:wings 1|2|3`도 지원. 인자 없이는 기존 날개 전환.
- 상태창 → 전직 방법: 시련 조건 2개 이상 완료 시 해당 히든 전직의 남은 조건·진행도 공개. 실제 전직 요건 유지.
- 성직자·천사·미카엘: 실제 아군 회복 누적 300 HP마다 축복의 빛 1개. 초과분 이월·가방이 가득 차면 보관.
- 상태창 → 스폰으로 이동. 길드 탭 → 길드 기지로 이동 및 길드장의 현재 위치 기지 설정.
- 공통 무기를 손에 들지 않고 가방 슬롯에서 골라 강화.
- v0.6.27의 스탯 조정·더 월드 해금 조건과 모든 이전 기능 포함.
