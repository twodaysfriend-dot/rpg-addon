# RPG 애드온 v0.5.56 — GPT 안내 NPC

[설치용 애드온 다운로드](downloads/RPG_v0556.mcaddon?raw=true) · [소스와 전체 안내](downloads/RPG_v0556_source_and_notes.zip?raw=true)

관리자는 `/rpg:gptnpc`로 앞쪽 빈 공간에 GPT 안내 NPC를 생성합니다. 얼굴에 초록색 패널과 흰색 GPT 픽셀 표시가 있는 전용 128×128 텍스처와 로봇형 모델을 추가했습니다. 일반 플레이어는 우클릭 또는 모바일 **GPT에게 질문** 버튼으로 질문하고 개인 답변 창을 받습니다.

기존 오프라인 도감과 선택 BDS API 연결을 함께 사용합니다. “해커는 근력이야 마력이야?”, “풍압 근력이야?”, “피의 창 마력?”, “혈인 피해 계열”, “근력 직업 알려줘”처럼 질문할 수 있습니다. 직업 기본 계열과 개별 스킬의 근력·마력·혼합·고정·비공격 예외를 구분하고 API 후보 자료에도 포함합니다. 전투 피해 계산은 변경하지 않습니다.

NPC는 피해 면역이며 공격 타깃·최근 타격 대상·흡혈·XP·재화·룬 획득용으로 사용할 수 없습니다. 관리자 생성 권한과 모바일 중복 입력을 검사합니다.

밸런스 평가·사기 여부·티어·우열과 히든 전직 방법은 계속 안내하지 않습니다. 전직 안내는 검사·마법사·궁수·무투가·성직자 5종만 공개합니다. NPC는 이 애드온 정보 안내용이며 범용 자유 대화 ChatGPT가 아닙니다.

[전체 변경 안내](docs/v0556-changes.md) · [현재 스킬 도감](docs/v0556-skills.md) · [기본 아이템 피해 목록](docs/v0556-melee.md) · [GPT 128px 텍스처](downloads/GPT_NPC_128px.png) · [SHA-256](downloads/SHA256SUMS_v0556.txt)

이전 기능을 모두 포함합니다. 세 팩을 함께 0.5.56으로 갱신하세요. UUID와 기존 저장 정보를 유지합니다.

자동 검증 366개 통과(JavaScript 361 + Python 5). NPC 생성·권한·상호작용→개인 질문/답변·중복 입력·대상 및 보상 제외·피해 계열·API 도감·정보 제한 및 팩 리소스를 확인했습니다. 실제 Bedrock 렌더링과 외부 API 호출은 미검증입니다.

[선택 BDS API 자료](downloads/RPG_v0556_API_server.zip?raw=true) · [서버 설정](docs/v0556-api.md). 기존 API 운영자는 새 BDS 전용 팩을 생성하고 브리지도 함께 갱신하세요.
