- **던전 2단계부터 강화**: 근력 40·레어 힘의 룬 +10·무기 +6을 2단계 솔로 공격력 기준으로 조정. 방어구·회복 준비 필요.
- 3~10단계 체력·공격력·방어 증가. 이전 마을 보호·황금 주먹 무다무다·스탯 입력 수정 포함.
