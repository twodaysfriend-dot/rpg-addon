# RPG 애드온 v0.5.59 — 사용자 수정본에 공용 무기 7종

[설치용 애드온 다운로드](downloads/RPG_v0559.mcaddon?raw=true) · [소스와 전체 안내](downloads/RPG_v0559_source_and_notes.zip?raw=true)

사용자가 보낸 **RPG_v0557_modified.mcaddon**의 세 팩을 기준으로 만들었습니다. 해당 파일의 전직·시련·진행 설정을 유지하고 공용 무기를 교체·추가했습니다. v0.5.58의 변경을 별도로 덮어쓰지 않았습니다.

첨부 외형을 참고한 128×128 투명 아이콘·아이템·내구도·제작법을 연결했습니다. 모두 공용 평타 무기로 직업 제한 없이 제작합니다. 직업 기술은 전용 시전 아이템을 사용합니다.

| 무기 | 추가 근접 피해 설정 | 내구도 |
|---|---:|---:|
| 적월선 | 11 | 1,600 |
| 마공학 검 | 9 | 1,400 |
| 마공학 대검 | 12 | 1,800 |
| 정예기사의 대검 | 12 | 2,000 |
| 빙설의 대검 | 13 | 2,000 |
| 화염의 대검 | 13 | 2,000 |
| 마수의 도끼 | 14 | 2,200 |

기존 모험가 전투검은 마공학 검, 별빛 전투창은 정예기사의 대검으로 교체됩니다. 내부 아이템 ID를 유지하여 이미 보유한 개체도 새 이름·외형·성능으로 표시하고 인챈트·현재 내구도·개별 저장 속성을 보존합니다. `/rpg:craft`와 GPT 정보 도감도 새 7종을 안내합니다. 얼음·화염 등은 외형이며 별도의 속성 공격은 추가하지 않았습니다.
