# RPG 애드온 v0.5.74 — 1인칭·3인칭 무기 각도 조정

[설치용 애드온 다운로드](downloads/RPG_v0574.mcaddon?raw=true) · [소스와 안내](downloads/RPG_v0574_source_and_notes.zip?raw=true)

공용·직업 무기 39종의 각도를 조정했습니다. 3인칭은 손 앞쪽으로 기울이고, 1인칭은 무기 윗부분이 화면 중앙 쪽을 향하게 수정했습니다.

원본 도트·2배 크기·손잡이 좌표·UV·회전 중심은 유지합니다. 투신 전용 표시·격투 주먹·전투·PvP·PK·강화·스킬 수치도 유지합니다.

[변경 사항·각도 상세](docs/v0574-changes.md) · [SHA-256](downloads/SHA256SUMS_v0574.txt)

관련 모델 검사 7개와 리소스·스크립트·팩 검증을 수행했습니다. 모델에서 손잡이를 중심으로 회전하며 카메라·팔 회전 후에도 손을 따라오는지 확인합니다. 실제 Bedrock 모바일·Realm 화면은 직접 실행 검증하지 못했습니다.

기존 팩을 비활성화하고 **RPG BP·RPG Commands BP·RPG RP 모두 v0.5.74로 적용한 뒤 월드를 다시 여세요.** 기존 팩 UUID와 저장 데이터 식별자는 유지합니다.
