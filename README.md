# RPG 애드온 v0.5.39 — 첫 접속 계열 선택창 제거·진행 점검

[설치용 애드온 다운로드](downloads/RPG_v0539.mcaddon?raw=true) · [소스와 전체 안내](downloads/RPG_v0539_source_and_notes.zip?raw=true)

첫 접속·재접속·스크립트 시작 시 계열 선택창이 자동으로 열리지 않도록 수정했습니다. 필요할 때 `/rpg:guide`를 직접 실행하면 시작 장비 선택과 첫 사냥 보상을 이용할 수 있습니다. 기존 직업·장비·첫 사냥 기록을 유지합니다.

[게임 진행에서 막히는 지점과 개선 우선순위](docs/v0539-progression-audit.md) · [계산과 모의 사망 이벤트 결과](docs/v0539-progression-audit-data.json) · [변경 상세](docs/v0539-changes.md) · [SHA-256](downloads/SHA256SUMS_v0539.txt)

진행 점검에서 확인한 주요 문제:

- 첫 전직 재료의 RPG 전용 공급 경로가 부족합니다. 특히 자원·구조물·지급처 없는 평지맵의 다이아 검 5개·효과부여 책 10권이 장벽입니다.
- 던전은 관리자가 먼저 생성해야 입장할 수 있습니다. 첫 클리어 이전 장비 동선도 보충이 필요합니다.
- 파티 경험치는 공유하지만 전직 처치 시련은 막타를 친 사람만 진행합니다.
- 미카엘 빛 192개는 천사 혼자 기도만으로 모으면 96일, 수면 없이 자연 시간으로 약 32시간입니다.
- 모든 처치 골드를 받은 1회 기준 던전 1단계 13,100·10단계 14,900으로 전체 골드 차이가 약 13.7%입니다. 고난도 전용 보상이 부족합니다.
- 일반 적·엘리트·닭이 모두 20 XP를 주지만 동물은 전직 처치 수와 재화를 주지 않습니다.
- 일반 플레이어용 스탯 재분배 기능이 없어 전직·카멜레온 학습에서 SP 부담이 생깁니다.

분석의 개선 제안은 자동 적용하지 않았습니다. 이번 플레이 동작 변경은 시작창 자동 표시 제거입니다. 기존 투신 기술명·흡혈 룬·돌진·해커·던전·강화 규칙은 유지합니다.

행동팩·명령어팩·리소스팩을 모두 0.5.39로 갱신하세요. 던전을 아직 만들지 않았다면 관리자가 `/rpg:dungeoncreate all`을 실행해야 합니다.

검증: 모의 JavaScript 시나리오 197개 + Python 5개 통과. JSON 438개·JS 122개 구문·모듈 경로·128px 이미지·ZIP 무결성 검사. 점검 수치는 코드와 모의 API 기준이며 실제 Bedrock 플레이 시간/난이도를 실측한 결과는 아닙니다.
