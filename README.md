# RPG v0.6.15 다운로드

[설치 파일 다운로드](downloads/RPG_v0615.mcaddon?raw=true) · [ZIP 다운로드](downloads/RPG_v0615_download.zip?raw=true)

`.mcaddon`을 가져온 뒤 RPG BP·Commands BP·RP 세 팩을 모두 v0.6.15로 활성화하세요. ZIP은 압축을 풀고 안의 `.mcaddon`을 여세요.

- 혈술사 전직관: 첨부 이미지 기반 금발·검정/금색 의상 스킨
- 크리에이티브 전용 **혈술사 전직 카드**를 손에 들면 전직 가능
- 흡혈 우클릭: 주변 6칸에서 시간 연장 대상 몹 우선 자동 선택
- 시간 정지: 첫 1초, 성공 사용마다 다음 시간 +0.1초, 50회 숙련 후 최대 6초
- 지정 몬스터 흡혈 강화: 현재 정지 시간 +50% (1초→1.5초, 6초→9초)
- 250×250 자동 스폰 마을·지역 버프·카멜레온 학습 등 이전 기능 유지

명령어: `/rpg:citycreate` · `/rpg:skillbook` · `/rpg:dungeoncreate 10` · `/rpg:status`
