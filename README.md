## 난이도 10개의 큰 원형 동굴

업데이트 후 관리자가 오버월드 빈 지역에서 실행합니다.

```mcfunction
/rpg:dungeoncreate all
```

지름 약 65칸의 원형 동굴 10개를 96칸 간격으로 생성합니다. 기존 블록은 덮어쓰지 않습니다. 임시 청크 로드 영역을 한 번에 하나씩 쓰며 차례로 생성하므로 완료 메시지를 기다리세요. 이전 사각 던전 건축물은 보존하고 새로운 원형 동굴은 별도로 생성합니다.

```mcfunction
/rpg:dungeon
/rpg:dungeon 1
/rpg:dungeonstart
/rpg:dungeonsolo 1
/rpg:dungeonleave
/rpg:dungeonloot
```

각자 원하는 난이도의 대기실에 직접 참가합니다. 대기실 첫 참가자가 1~4명으로 출발할 수 있으며, 혼자 시작도 지원합니다. RPG 파티원을 자동으로 이동시키지 않습니다. 던전당 최대 4명, 난이도마다 독립적인 전투 하나를 진행합니다.

일반 몬스터 50마리와 엘리트 5마리는 시간 경과와 처치에 따라 조금씩 등장합니다. 이 55마리를 5분 안에 모두 잡으면 보스 1마리가 나오며, 실제 보스 등장부터 새로 3분을 줍니다. 어느 제한이든 넘기면 전원 귀환하고 클리어 보상은 없습니다. 처치 수와 타이머를 액션바에 표시합니다. 난이도에 따라 몬스터 구성·HP·기본 근접 피해를 올렸습니다.

기존 룬·갑옷·강화 위험과 요금, 재접속 쿨타임 유지, 촉매·룬·제작 재료 보급을 포함합니다. 상위 난이도는 클리어 재화 보상을 단계마다 10% 추가합니다. 약 20시간 풀강 모델은 기존대로 실제 속도와 강화 운에 따라 달라지는 평균 목표입니다.
