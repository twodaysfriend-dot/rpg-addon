# RPG 애드온 v0.5.67 — 던전 전리품·광물 보상·착용 갑옷·승급

[설치용 애드온 다운로드](downloads/RPG_v0567.mcaddon?raw=true) · [소스와 안내](downloads/RPG_v0567_source_and_notes.zip?raw=true)

- 던전 종료 시 남은 바닥 아이템과 던전 몬스터의 마크 XP를 실제 피해+전투 중 아군 유효 회복 기여도로 나눕니다. RPG 레벨 처치 XP는 유지합니다.
- 아이템 원본을 영속 보관함에 넣어 이름·인챈트·내구도·강화·등급을 보존합니다. 가방 부족·사망·오프라인 몫은 `/rpg:dungeonloot`와 부활·재접속 시 수령을 시도합니다.
- 던전 엘리트 다이아는 1개 40% / 3개 10% / 없음 50%의 배타 추첨입니다. 남아 있는 다이아도 종료 분배에 포함합니다.
- 6~10단계 클리어 참여자마다 네더라이트 주괴 1개를 10/15/20/25/30%로 추첨하며 결과를 저장합니다.
- 강화 촉매는 개당 성공 +9%p·파괴 -3%p, 한 번에 최대 5개입니다. 기존 확률 상한과 사용 단계 조건을 유지합니다.
- 갑옷 승급에는 보호 IV 책 1권, 공용 무기 승급에는 날카로움 V 책 1권이 추가됩니다. 성공·실패 모두 책과 재료 장비를 소모하며 룬은 책이 필요 없습니다.
- 4세트 16부위의 착용 모델을 판금·테두리·장식 형태로 정리했습니다. 원본 PNG·무기 도트·방어 수치는 유지합니다.

[변경사항과 상세 분배 규칙](docs/v0567-changes.md) · [SHA-256](downloads/SHA256SUMS_v0567.txt)

BP·명령어 BP·RP 모두 v0.5.67로 갱신하세요. 진행 중인 던전은 업데이트 후 다시 시작하고, 종합 룰북은 `/rpg:rulebook`으로 새로 받으세요.

자동 검사 457개(JavaScript 452 + Python 5) 통과. JSON 528개·JS 160개·import 596개와 원본 PNG·모델·팩 무결성을 검사했습니다. 실제 모바일 착용 화면과 청크 수령 동작은 직접 플레이 검증하지 못했습니다.

마크 경험치 구슬의 값을 읽는 안정적인 Script API가 없어, 던전 몬스터의 기존 구슬 XP를 자동 보관하는 방식으로 처리합니다. 경험치 병·플레이어 사망 등 몬스터 외 원인의 구슬은 별도입니다.
