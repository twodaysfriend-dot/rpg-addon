# RPG 애드온 v0.5.65 — 견습 5계열 자유 체험

[설치용 애드온 다운로드](downloads/RPG_v0565.mcaddon?raw=true) · [소스와 안내](downloads/RPG_v0565_source_and_notes.zip?raw=true)

견습은 시작 계열과 관계없이 검·마법·활·격투·회복 견습 장비를 자유롭게 체험할 수 있습니다.

`/rpg:guide` → **견습 5계열 체험** → 장비 선택 후 손에 드세요. OP 권한은 필요 없습니다. 기존에 한 계열을 선택한 견습도 사용할 수 있습니다.

- 가방에 없는 견습 장비만 보충합니다. 이미 가진 장비는 중복 지급하지 않습니다.
- 빵 16개·화살 64개는 각각 한 번만 지급하며 첫 사냥 진행도·보상 수령 여부를 유지합니다.
- 검·격투 견습은 기본 공격, 마법은 파이어볼·라이트닝, 회복은 힐, 활은 에어워크·연사를 체험합니다. 정식 전직 직업의 전체 스킬을 지급하지는 않습니다.
- 전직 후 기존 직업의 장비·스킬 제한은 유지합니다.

[상세 변경 안내](docs/v0565-changes.md) · [SHA-256](downloads/SHA256SUMS_v0565.txt)

BP·명령어 BP·RP를 모두 0.5.65로 갱신·활성화하세요. 기존 UUID·저장 데이터와 이전 버전의 통합 공물·평화 서버·사냥 구역·전직관·장비 기능을 유지합니다. 종합 룰북의 체험 안내도 갱신했습니다.

자동 테스트 441개(JavaScript 436 + Python 5) 통과. JSON·스크립트 구문·import·원본 무기 도트·팩 무결성을 확인했습니다. 실제 모바일 Bedrock 플레이는 미검증입니다.

[선택 BDS API 자료](downloads/RPG_v0565_API_server.zip?raw=true). 일반 설치는 위 mcaddon 파일을 사용하세요.
