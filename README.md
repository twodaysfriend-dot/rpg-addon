# RPG 애드온 v0.5.37 — 돌진 조건 수정·천멸격·해커 복구

[설치용 애드온 다운로드](downloads/RPG_v0537.mcaddon?raw=true) · [소스와 전체 안내](downloads/RPG_v0537_source_and_notes.zip?raw=true)

돌진의 안전한 바닥·절대 Y좌표·용암 지형 제한을 제거했습니다. 음수 Y의 평지 월드와 공중에서도 사용할 수 있습니다. 실제 벽 충돌 검사는 유지합니다. 작골염양 돌진·용의 질주·무쌍돌격·암살자 회전베기와 그림자 이동의 도착 검사·영혼분리·망나니/야수 3연베기를 수정했습니다.

투신 궁극기 이름을 **천멸격**으로 변경했습니다. 다음 평타 한 번 피해 ×10, MP 300·쿨 90초입니다. 내부 스킬 ID·저장 키를 유지하므로 기존 학습·쿨타임·준비 상태를 이어받습니다.

해커 전직은 원본으로 복구했습니다. **로토와 23회 대화 → C언어 퀴즈 정답 → 월드 최초 1명 자동 전직**입니다. 직업·레벨·엘리트 처치 조건은 없습니다. 이후 정답자는 인챈트된 황금사과 1개를 한 번 받습니다. 일반 전직 명령어로 우회할 수 없으며 기존 최초 정답자와 보상 기록은 유지합니다.

[변경 상세](docs/v0537-changes.md) · [134개 스킬 도감](docs/v0537-skills.md) · [SHA-256](downloads/SHA256SUMS_v0537.txt)

흡수 룬 5~12% 흡혈, 투신과 전용 128×128 건틀릿, 10개 원형 던전·5분+3분 제한, 왼쪽 아래 HUD를 포함합니다. 행동팩·명령어팩·리소스팩을 모두 0.5.37로 갱신하세요.
