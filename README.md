# RPG 애드온 v0.5.38 — 투신 기술명 변경

[설치용 애드온 다운로드](downloads/RPG_v0538.mcaddon?raw=true) · [소스와 전체 안내](downloads/RPG_v0538_source_and_notes.zip?raw=true)

투신의 기존 다섯 기술을 요청한 순서대로 변경했습니다.

| 순서 | 기술명 | 기본 효과 | MP / 쿨 |
|---|---|---|---|
| 1 | 폭멸타 | 피해 40 | 60 / 6초 |
| 2 | 난참 | 피해 10 × 6회 | 120 / 10초 |
| 3 | 폭열권 | 피해 48 + 밀치기·둔화 | 90 / 8초 |
| 4 | 파황각 | 피해 18 × 4회 | 160 / 16초 |
| 5 | 풍신열각 (궁극기) | 다음 평타 한 번 피해 ×10 | 300 / 90초 |

HUD·메뉴·도감·시전 알림에 반영했습니다. 이름만 변경하여 효과·마나·쿨타임·기존 학습 및 저장 기록을 유지합니다.

v0.5.37의 낮은 평지맵/공중 돌진 수정과 원본 해커 전직(로토 23회 대화, 최초 정답자 1명)을 포함합니다. 흡수 룬은 5~12% 흡혈입니다.
