# RPG 애드온 v0.5.53 — 카피·유도탄·천체 스킬 개편

[설치용 애드온 다운로드](downloads/RPG_v0553.mcaddon?raw=true) · [소스와 전체 안내](downloads/RPG_v0553_source_and_notes.zip?raw=true)

해커 카피는 등록된 공격·제어 궁극기 17종에서 실행 가능한 기술을 무작위로 발동합니다. 순수 버프 궁극기는 제외하고, 공격과 버프를 함께 주는 궁극기는 포함합니다. 빙주난사는 기존 발당 피해 7을 유지하는 유도탄 5발로 변경했습니다.

마공학 감옥은 사거리 안의 표식 적을 우선하고, 없으면 가장 가까운 적에게 설치합니다. 마공학 광선은 10초 표식을 부착합니다. 흡혈은 반경 10칸 모든 적에게 영혼 빨대를 연결하고 기존 피해·재생 계산을 유지합니다.

햇빛·달빛은 각각 최대 500을 저장하고 기존 수동 +35·자연 초당 +4를 유지합니다. 일륜참은 다음 기본 타격 4배·둔화 III 1초, 방사열선은 발사 중 현재 시선의 좌우·상하 방향을 따라갑니다. 달의 후예 공격은 근력·물리 장비 보정으로 통일했습니다.

|---|---:|

자동 검증 352개 통과(JavaScript 347 + Python 5). 카피 실제 입력·지연 타격, 유도탄 이동 추적·벽 충돌, 표식 우선 조준, 흡혈 연결, 빛 상한·충전량, 시선에 따른 광선 피해·이펙트, 달 계열 근력 보정 및 팩 무결성을 확인했습니다. 실제 Bedrock 전투·렌더링은 미검증입니다.
