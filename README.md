# RPG v0.6.31 다운로드

[설치 파일 다운로드](downloads/RPG_v0631.mcaddon?raw=true) · [ZIP 다운로드](downloads/RPG_v0631_download.zip?raw=true)

Bedrock 1.21.100 이상. `.mcaddon`을 가져온 뒤 RPG BP·Commands BP·RP 세 팩을 모두 v0.6.31로 활성화하고 월드를 다시 여세요.

- **마을 부동산**: 상태창 → 지갑·상점·부동산 → 경험치 상점에서 다이아몬드 5개로 구매권 1개. 구매권을 들면 청크 테두리가 보이며, 사용·확인하면 현재 마을 1청크(16×16)를 소유합니다.
- **건축 권한**: 구매자만 마을 바닥 Y보다 위에서 건축·파괴 가능. 바닥과 지하는 계속 보호합니다. 다른 사람·미구매 청크는 건축할 수 없습니다. 마을에 완전히 들어오는 청크만 구매할 수 있습니다.
- **마법사 마나 절반**: 마법사·현자 계열 스킬의 기본 마나 소모 ×0.5. 지능 할인·정수 올림은 이후 적용합니다.
- **마법사 평타 선택**: 상태창 → 내 캐릭터에서 파이어볼·번개·그래비티·봄바예 중 1개 선택. 좌클릭/휘두르기 평타에 공유 쿨타임 1초·기존 피해 ×0.8 적용. 우클릭 일반 기술의 피해·쿨타임은 유지합니다.
- **상태창 분류**: 첫 화면 21개 → 9개 버튼. 파티·길드, 던전·PvP, 이동·TPA, 장비·강화 등으로 묶고 기존 기능을 유지합니다.
- v0.6.30의 본체 날개 속도 명령어, 책 +50/다이아 블록 +200 마나 공물과 이전 기능·데이터를 포함합니다.
