# RPG 애드온 v0.5.71 — 무기 자세·2배 크기·직업 무기 강화

[설치용 애드온 다운로드](downloads/RPG_v0571.mcaddon?raw=true) · [소스와 안내](downloads/RPG_v0571_source_and_notes.zip?raw=true)

참고 사진처럼 칼날이 위로 서도록 원본 스프라이트의 방향을 모델에서 통일했습니다. 39종 공용·직업 무기를 실제 손 뼈대에 붙이고 면 크기를 16→32단위로 2배 설정했습니다. 투신 장갑도 본인 표시를 유지하며 2배로 키웠고 원래 보이지 않던 격투 주먹 3종은 숨김을 유지합니다. 원본 PNG·인벤토리 아이콘은 수정하지 않습니다.

직업·견습 무기 36종을 `/rpg:upgrade`에서 +10까지 강화할 수 있습니다. 등급·승급은 없습니다. 단계당 근접 피해 +1, 그 무기로 쓰는 물리·마법 스킬 피해 +2%(+10은 +20%). 고정 피해·회복량은 유지합니다. 비용·실패·강등·파괴·촉매는 기존 공용 무기 규칙을 사용합니다.

카멜레온 무기 전환, 같은 무기 재지급, giveWeapon 경로의 전직 무기 교체 시 강화 단계를 보존합니다. 클래스 초기화·파괴처럼 아이템을 명시적으로 없애는 동작까지 보존하는 기능은 아닙니다.

[자세·강화·보존 범위 상세](docs/v0571-changes.md) · [SHA-256](downloads/SHA256SUMS_v0571.txt)

**기존 팩을 비활성화하고 BP·명령어 BP·RP 모두 v0.5.71만 활성화한 뒤 월드를 다시 여세요.** 팩 UUID와 기존 성장 데이터 저장 키는 유지합니다.

자동 검사 480개(JavaScript 475 + Python 5)와 리소스·스크립트·팩 무결성을 검사했습니다. 2배는 모델 단위의 크기이며 FOV·원근에 따른 화면 픽셀 길이까지 고정하지는 않습니다. 실제 모바일·렐름 화면의 자세는 직접 검증하지 못했습니다.
