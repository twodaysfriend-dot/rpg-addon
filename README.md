# RPG v0.6.33 다운로드

[설치 파일 다운로드](downloads/RPG_v0633.mcaddon?raw=true) · [ZIP 다운로드](downloads/RPG_v0633_download.zip?raw=true)

Bedrock 1.21.100 이상. `.mcaddon`을 가져온 뒤 RPG BP·Commands BP·RP 세 팩을 모두 v0.6.33으로 활성화하고 월드를 다시 여세요.

- **피스톤 설치 수정**: 사방 13칸 검사를 없애고 추정 설치 방향과 필요한 공간만 검사합니다. 편집 가능한 개인 토지·공용 집에서 수평 일반/끈끈이 피스톤 설치가 허용됩니다.
- **미구매 주택 공용 사용 복원**: 기존 주택 공간은 구매권 없이 수정할 수 있습니다. 구매된 청크의 집 부분은 소유자·현재 같은 길드/파티 권한을 적용합니다. 마을 바닥·지하의 직접 파괴는 계속 차단합니다.
- **관리자 토지 관리**: `/rpg:admin` 도구에서 대상 플레이어 선택 → 현재 청크를 대상에게 지정 또는 현재 청크 소유권 해제. 다이아·구매권 소비 없이 권리만 바꾸고 건축물은 유지합니다.
- **좀비 보존**: 마을 안 자연 출현 좀비는 정리하고 소환알·외부 유입 좀비는 마을/평화/동굴/밤·아침 정리에서 보존합니다. 기존·로드 개체도 보존하며, 바닐라 햇빛·사망·평화로움 난이도 등은 유지합니다.
- 청크 소유권·길드/파티 공동 건축, 마법사 마나 절반·선택 평타, 상태창 분류, 날개·마나 공물 등 이전 기능·데이터를 유지합니다.
