# RPG 애드온 v0.5.68 — 몬스터 레벨·후반 던전 난이도

[설치용 애드온 다운로드](downloads/RPG_v0568.mcaddon?raw=true) · [소스와 안내](downloads/RPG_v0568_source_and_notes.zip?raw=true)

커스텀 RPG 몬스터·엘리트·보스 22종에 영속 레벨과 체력·공격·방어 보정을 추가했습니다. 같은 몬스터도 초반 Lv.1~15, 중반 Lv.20~55, 후반 Lv.70~145의 후보 중 하나로 등장합니다. 바닐라 몬스터에는 적용하지 않습니다.

던전은 단계별로 적 레벨과 체력 압박이 증가합니다. 10단계 일반 Lv.145~220·엘리트 Lv.220·보스 Lv.260. 무기·RPG 갑옷·장착 룬 전설 +10 수준의 4인 파티를 기준으로 설계했으며, 장비 입장 제한은 없습니다. 솔로 입장도 유지합니다. 고정 피해는 레벨 방어를 상쇄합니다.

투신은 기존 레벨 40·무투가 조건을 유지하고 필요한 솔로 클리어만 5단계 이상 → 2단계 이상으로 낮췄습니다. 기존 달성 기록은 유지합니다.

[전체 레벨 표·전투 수치·설계 가정](docs/v0568-changes.md) · [SHA-256](downloads/SHA256SUMS_v0568.txt)

팩 UUID·기존 레벨·카멜레온·장비·재화 저장 키를 유지합니다. 기존 월드에 BP·명령어 BP·RP를 모두 새 버전으로 적용하세요. 적용 전 월드 백업을 권장합니다.

자동 검사 464개(JavaScript 459 + Python 5) 통과. JSON 528개·JS 163개·import 606개와 원본 PNG·팩 무결성을 확인했습니다. 10단계 참고 DPS 모델에서 일반 +10은 보스 제한시간을 넘고 전설 +10은 제한 안에 들어오는 것을 검사했습니다. 실제 모바일·렐름 플레이 측정은 아니며 직업 조합·SP·인챈트·운용에 따라 결과가 달라집니다.
