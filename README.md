Bedrock 1.21.100 이상. BP·Commands BP·RP 모두 v0.6.49로 활성화하고 월드를 다시 여세요.

- **경험치 상점:** `/rpg:wallet` → 상점에서 기본 마인크래프트 경험치 40레벨로 룬 가루 200개 구매. 지갑에 바로 지급합니다.
- **재화 송금:** `/rpg:pay` 또는 지갑의 재화 송금에서 접속 중인 다른 플레이어에게 골드·강화석·룬 가루를 수수료 없이 보냅니다. 수량 입력과 확인 후 지급하며, 잔액/한도/접속 상태를 검사하고 실패 시 양쪽 잔액을 복구합니다.
- **촉매 일괄 강화:** `/rpg:runebatch`에서 룬마다 사용할 촉매 0~5개 선택. +2부터 적용하며 전체 비용과 촉매가 부족하면 시작하지 않습니다.
- **룬 자동 완성:** `/rpg:runeauto` 또는 `/rpg:runes` → 자동 완성에서 종류·목표 등급·목표 강화·촉매 수량을 입력하세요. 인벤토리와 룬 가방의 재료를 가져와 **+5 두 개 → 상위 등급 +0 → 목표 강화** 과정을 재귀적으로 진행합니다.
- 자동 완성은 장착한 룬을 보호하고 기존 비용·실패·강등·파괴 확률을 적용합니다. 재료·골드·룬 가루·선택한 촉매 부족 시 종료하며 중간 룬과 남은 재화를 보존합니다. `/rpg:runeautostop`으로 중단할 수 있습니다.
- 기존 PK 감옥·용기사·던전 밸런스·미사용 데이터 정리는 유지합니다.
