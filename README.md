- **좀비 주민 보존**: 구형·신형 좀비 주민도 소환알·감염·외부 유입·로드 후 마을/평화/동굴/밤·아침 정리에서 보존합니다. 마을 내부 자연 출현 제한과 바닐라 햇빛·사망 등은 유지합니다.

- **간접 피해 방어**: 투사체·마법·폭발·번개·불·용암도 마을 주민에게 피해를 주지 않습니다. 이 유형은 비플레이어 출처도 함께 차단합니다. 낙하·질식·익사 등 나머지 기본 환경 피해를 전부 무효화하지는 않습니다.
- 기존 주민을 교체하지 않으며 기본 거래·번식·AI와 좀비 감염/치료 데이터는 유지합니다. 마을 밖 주민은 기존 동작을 유지합니다.
- 부동산·길드/파티 공동 건축·공용 주택·관리자 토지·피스톤 설치·마법사·상태창·날개·마나 공물 등 이전 기능과 데이터를 포함합니다.
