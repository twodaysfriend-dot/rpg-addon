# RPG 애드온 v0.5.43 — 월룡륜미 전방위 참격·복수귀 신규 공격

[설치용 애드온 다운로드](downloads/RPG_v0543.mcaddon?raw=true) · [소스와 전체 안내](downloads/RPG_v0543_source_and_notes.zip?raw=true)

**월룡륜미**를 반경 12칸, 360도 전방위로 큰 청록색 초승달과 작은 보랏빛 초승달이 퍼지는 참격으로 변경했습니다. 기본 물리 피해 28·MP 70·쿨 9초는 유지하며, 같은 적에게 한 번만 피해를 줍니다. 벽 뒤와 아군은 제외합니다. 첨부 이미지의 큰 초승달/작은 달 구성을 기존 참격 텍스처와 전용 파티클로 구성했습니다.

복수귀에 짧은 쿨타임의 두 공격을 추가했습니다.

| 기술 | 기본 효과 | MP | 쿨 |
|---|---|---:|---:|
| 딥 피어스 | 전방 5.5칸 관통 찌르기, 피해 18 | 18 | 2.5초 |
| 찢어내기 | 전방 베기 16 + 3초간 출혈 총 9, 합계 25 | 24 | 4초 |

별도 대상 지정 없이 전방을 공격합니다. 같은 시전자의 출혈은 갱신하며 중첩하지 않습니다. 카멜레온도 각각 3 SP의 일반 기술로 학습하며 사용 횟수 제한은 없습니다.

복수귀 순서는 **딥 피어스 → 찢어내기 → 작살 → 돌진 → 영혼작살 → 잠수 → 영혼분리 → 처형**입니다. 공격 먼저·버프/유틸 뒤·처형 마지막으로 정렬하고, 기존 복수귀도 자동으로 이전합니다. 기존 쿨타임과 유효한 스킬 꺼짐 설정은 유지합니다.
