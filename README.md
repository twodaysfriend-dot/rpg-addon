# RPG 애드온 v0.5.57 — 골렘 확대·보스 모션

[설치용 애드온 다운로드](downloads/RPG_v0557.mcaddon?raw=true) · [소스와 전체 안내](downloads/RPG_v0557_source_and_notes.zip?raw=true)

마공학 블럭 골렘 모델을 각 축 1.5배로 확대했습니다. 발 위치·면별 UV·표시 범위를 정렬하고 충돌 크기를 너비 5.1·높이 7.5칸으로 키웠습니다. HP·피해량·공격 주기·경험치·드롭은 유지합니다.

보스 4종에 대기·실제 이동에 따른 보행·근접 공격 동작을 연결했습니다. 마공학 골렘은 분절 팔·다리·코어, 바위 골렘은 무거운 걸음과 내려찍기/충격파, 외눈 거인은 보행과 발구르기, 히드라는 머리·꼬리 흔들림과 기어가는 동작을 사용합니다. 히드라의 원본 6,399개 큐브와 UV를 모두 보존했습니다.

바위 골렘의 0.7초 뒤 내려찍기, 외눈 거인의 0.8초 뒤 발구르기는 기존 피해 발생 시점에 모션을 맞췄습니다. 연속 피해로 모션이 재시작되거나 준비 동작이 덮이지 않도록 처리했습니다. 모션 실패가 전투 처리를 중단시키지 않습니다.
