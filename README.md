# RPG 애드온 v0.5.54 — 투신 궁극기 천멸격

[설치용 애드온 다운로드](downloads/RPG_v0554.mcaddon?raw=true) · [소스와 전체 안내](downloads/RPG_v0554_source_and_notes.zip?raw=true)

투신 궁극기의 이름을 **천멸격**으로 변경했습니다. 스킬 선택·준비/발동 알림·HUD·규칙서·스킬 도감·RPG 정보 안내에 적용했습니다. 카멜레온이 배운 기술에도 새 이름이 표시됩니다.

다음 평타 10배·MP 300·쿨타임 90초·이펙트를 유지합니다. 내부 스킬 ID와 저장 키를 유지하여 기존 학습·쿨타임·준비 상태와 호환됩니다.

[변경 안내](docs/v0554-changes.md) · [현재 스킬 도감](docs/v0554-skills.md) · [기본 아이템 피해 목록](docs/v0554-melee.md) · [SHA-256](downloads/SHA256SUMS_v0554.txt)

카피·유도탄·천체 스킬 등 이전 기능을 포함합니다. 세 팩을 모두 0.5.54로 갱신하세요. UUID와 기존 월드 저장 정보를 유지합니다.

관련 자동 검증 31개 및 JSON·JS·리소스·압축 무결성 검사를 통과했습니다. 실제 Bedrock 화면은 미검증입니다.
