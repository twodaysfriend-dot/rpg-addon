# RPG v0.5.78 — 손잡이 정렬·네더라이트 검 기준 표시

[애드온 다운로드](downloads/RPG_v0578.mcaddon?raw=true)

손에서 떨어져 보이던 적월선 등 근접 무기 24종의 표시용 도트를 네더라이트 검의 손잡이 기준에 정렬했습니다. 원본 PNG 파일은 보존하고, 표시용 복사본에 좌우 반전·픽셀 복제·여백 정렬만 적용했습니다. 픽셀을 자르거나 재색칠하지 않습니다. 표시용 복사본은 인벤토리 아이콘에도 적용됩니다.

1인칭·3인칭의 추가 회전은 제거하고 바닐라 도구의 기본 자세를 사용합니다. 기존 2배 배율·아이템 ID·전투·성장 저장 데이터는 유지합니다.

자동 검사 502개와 24종 표시용 픽셀 보존 검증을 통과했습니다. 실제 모바일 화면은 직접 확인하지 못했습니다.

**이전 RP를 모두 끄고 BP·명령어 BP·RP를 v0.5.78로 함께 적용한 뒤 월드를 다시 여세요.**
