# RPG 애드온 v0.5.36 — 흡혈 룬과 투신

[설치용 애드온 다운로드](downloads/RPG_v0536.mcaddon?raw=true) · [소스와 전체 안내](downloads/RPG_v0536_source_and_notes.zip?raw=true) · [건틀릿 128×128 도트](downloads/war_god_gauntlets_128.png?raw=true)

흡수의 룬은 적에게 준 피해의 5~12%를 HP로 회복하는 흡혈 룬입니다. 받는 피해 감소가 아닙니다. 강화별 수치는 5 / 6.4 / 7.8 / 9.2 / 10.6 / 12%이며 룬 전용 보관함에서 장착합니다. 기존 드롭 확률을 유지하면서 6종 중 무작위 드롭, 던전 보급 순환과 작업대 제작에 추가했습니다.

투신은 근력 기반 히든 4차 직업입니다. 권골·레벨 40·무투 계열 처치 150·보스 5 조건 후 `/rpg:job 투신`으로 전직합니다. 관리자는 `/rpg:force 투신`으로 확인할 수 있습니다. 첨부 이미지를 바탕으로 만든 검붉은 건틀릿 도트를 128×128 투명 아이콘으로 적용했습니다.

| 스킬 | 기본 피해 | MP | 쿨 |
|---|---|---:|---:|
| 존나쎄게 치기 | 40 | 60 | 6초 |
| 존나쎄게 연타 | 10×6 | 120 | 10초 |
| 존나쎈 발차기 | 48·밀치기 | 90 | 8초 |
| 존나쎈 발차기 연타 | 18×4·마지막 밀치기 | 160 | 16초 |
| 흑섬 — 궁극기 | 다음 평타 한 번 ×10 | 300 | 90초 |

흑섬은 적에게 기본 근접 공격을 맞힐 때 한 번 소비하며 스킬·아군·허공 타격은 소모하지 않습니다. 준비 상태와 쿨타임은 재접속 후에도 유지합니다. 카멜레온도 학습할 수 있습니다.
