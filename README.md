# RPG 애드온 v0.5.40 — 파티 기여 전직·천사 회복 보상·성장 보완

[설치용 애드온 다운로드](downloads/RPG_v0540.mcaddon?raw=true) · [소스와 전체 안내](downloads/RPG_v0540_source_and_notes.zip?raw=true)

- 파티 전직용 처치: 최근 30초 동안 해당 적에게 공격·탱킹·전투원 유효 회복으로 기여한 현재 파티원도 인정합니다. 처치 위치 32칸·같은 차원·생존 조건입니다. 주민·샌드백도 현재 직업 조건을 갖춘 기여자에게 인정합니다. 기존 파티 XP 각자 75%는 유지합니다.
- 천사: 아군에게 실제로 회복한 HP 300마다 축복의 빛 1개. 성직 재생 기술·길들인 아군 동물도 지원하고 자가 회복·초과 회복은 제외합니다. 잔량·가방 부족 미지급 보상을 저장하며 `/rpg:status`에서 진행도를 확인합니다.
- 상위 던전: 1단계 보상은 유지합니다. 10단계 개인 클리어 보상은 골드 31,000·강화석 124·룬 가루 31·촉매 20·룬 3개·제작 재료 4배입니다. 몹 처치 재화와 개인 누적 3회마다 촉매 +1은 별도입니다.
- 스탯 초기화 주문서: 배분한 스탯을 기본 5로 되돌리고 배분 SP를 환급합니다. 종이 4·청금석 3·금 주괴 1로 제작합니다.
- 전직 포기각서: 견습으로 돌아갑니다. 레벨·스탯·재화·갑옷·룬·전직 진행도·쿨타임은 유지하고 직업 무기와 기술을 회수합니다. 종이 4·먹물 주머니 2·철 주괴 2로 제작합니다. 카멜레온은 차용 기술을 분해 환급하고 사용 횟수 기록을 유지합니다. 성직 계열 사망 목격 5회 후 사용한 각서는 타락천사 전직으로 이어집니다.
- 바닐라 XP: 일반 몹 10, 적대 몹 대부분 30, 좀벌레·좀비화 피글린 5. RPG 커스텀 몹과 드래곤·위더·워든의 기존 XP는 유지합니다.
