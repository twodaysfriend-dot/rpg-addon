# RPG v0.5.77 — 네더라이트 검 기준 3인칭 방향 보정

[애드온 다운로드](downloads/RPG_v0577.mcaddon?raw=true)

3인칭에서 검날이 아래로 향하던 마공학 대검 등 역방향 무기의 방향을 반전했습니다. 기본 검과 같은 방향의 무기는 바닐라 자세를 사용하고, 3인칭의 추가 기울기는 제거했습니다.

1인칭 설정·원본 도트·2배 배율·기존 저장 데이터는 유지합니다. 관련 모델 검사 9개와 팩 검증을 수행했으며 실제 모바일 화면은 직접 검증하지 못했습니다.

**이전 RP를 모두 끄고 BP·명령어 BP·RP 모두 v0.5.77로 적용하세요.**
