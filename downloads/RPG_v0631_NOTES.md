# RPG v0.6.31 · 마을 청크 부동산·마법사 평타·상태창 분류

Bedrock 1.21.100 이상. RPG BP·Commands BP·RP 세 팩을 모두 v0.6.31로 활성화하고 월드를 다시 여세요. UUID를 유지하며 v0.6.30의 날개 속도·책 +50/다이아 블록 +200 마나 공물 및 모든 이전 기능·데이터를 포함합니다.

## 마을 부동산과 건축

상태창 → **지갑·상점·부동산 → 경험치 상점·부동산 구매권**에서 **다이아몬드 아이템 5개**로 **부동산 구매권 1개**를 구매합니다. 이 상품에는 경험치 레벨을 사용하지 않습니다. 구매권 1개가 마을의 1청크(16×16) 소유권에 해당합니다.

1. 구매권을 주 손에 들고 원하는 마을 청크에 서세요. 현재 청크 경계를 입자로 표시하고 소유 상태를 액션바에 표시합니다.
2. 구매권을 사용한 뒤 확인창에서 구매를 누르면 현재 청크를 취득하고 구매권 1개를 소비합니다. 확인 중 다른 청크로 이동하면 거래를 취소합니다.
3. 구매자 본인만 해당 청크의 **마을 바닥 Y 좌표보다 위**에서 블록을 설치·파괴할 수 있습니다. 높이 상한은 Minecraft 차원의 기본 건축 한도입니다.
4. **마을 바닥 Y와 그 아래는 구매자도 파괴할 수 없습니다.** 다른 사람의 청크와 미구매 청크도 건축을 차단합니다. 바닥 윗면에 블록을 올리는 것은 구매자에게 허용합니다.

월드 좌표 기준 청크를 사용하며, 마을 경계에 걸쳐 온전히 들어오지 않는 청크는 구매할 수 없습니다. 구매권은 이 애드온의 생성된 250×250 마을에서 사용합니다. 소유권은 플레이어 ID와 월드 데이터에 영구 저장합니다. 기존 자유 리모델링 주택 구역도 이제 청크 구매가 필요합니다. 마을 밖의 기존 건축 규칙은 유지합니다.

이미 판매된 청크·잘못된 위치·확인 취소에는 구매권을 소비하지 않습니다. 구매권 상점에서 다이아몬드가 부족하면 거절하며, 가방 부족/저장 오류는 거래를 취소하고 복구합니다. 마을은 폭발로도 손상되지 않으며 기존 피스톤 경계 보호를 유지합니다. 자연 유체 흐름 등 모든 게임 물리의 차단까지 검증한 것은 아닙니다.

## 마법사 스킬과 평타

`line: mage`에 속하는 마법사·현자 스킬의 **기본 마나 소모를 절반**으로 줄입니다. 지능 할인은 그 다음에 적용하고 최종 소모는 기존 정수 올림 규칙을 따릅니다. 예: 파이어볼 기본 15→7.5, 지능 5에서 실제 소모 8. 다른 계열의 기본 마나는 유지하며, 카멜레온이 빌린 마법사 계열 기술도 해당 기본 마나를 사용합니다.

상태창 → **내 캐릭터 → 마법사 평타 선택**에서 마법사·현자는 **파이어볼 / 번개 / 그래비티 / 봄바예 중 1개**를 선택합니다. 기본 선택은 파이어볼입니다.

- 직업 책·지팡이 또는 대체 공통 무기를 들고 좌클릭/휘두르기로 선택한 마법 평타를 사용합니다. 엔티티·블록 타격도 입력으로 처리합니다.
- 선택한 평타만 **공유 쿨타임 1초(20틱), 기존 스킬 피해 ×0.8**을 적용합니다. 봄바예의 발사 수·기존 발당 계수 등은 유지하며 직접 피해에 0.8을 곱합니다.
- 원래 스킬 정의를 변경하지 않고 평타용 사본으로 실행합니다. 우클릭 일반 스킬은 기존 피해·쿨타임이며 마나 소모 절반은 적용됩니다.
- 평타 선택을 바꿔도 공유 쿨타임을 우회하지 못합니다. 마나 부족·시간 정지 중에는 사용하지 않습니다. 설정은 저장되며 한 번에 1개만 적용합니다.

## 상태창 분류

첫 화면을 21개에서 **9개 버튼**으로 줄였습니다. 7개 분류와 새로고침·닫기로 구성합니다.

- **내 캐릭터**: 스탯, 전직, 스킬 켜기·끄기, 날개 속도, 마법사 평타.
- **파티·길드**: 파티, 길드/기지, 받은 초대.
- **던전·PvP**: 던전 입장, PvP 결투.
- **이동·TPA**: 스폰 귀환, TPA 요청, TPA 수락·거절.
- **장비·강화**: 공통 무기 대체, 장비, 룬, 강화, 강화 이전.
- **스킬·제작 도감**: 스킬 효과, 조합법.
- **지갑·상점·부동산**: 지갑/골드 상점, 경험치 상점/부동산 구매권.

하위 화면의 뒤로를 누르면 분류 목록으로 돌아갑니다. 기존 기능을 유지합니다.

## 개발·검증

Node.js 24·Python 3.12. 외부 패키지·서비스·비밀값은 필요 없습니다.

```sh
python3 checks/validate.py .
node tools/build_monster_balance.mjs --check
node --experimental-vm-modules checks/integration.mjs . --gameplay-only-wings
for suite in integration worldUnlock behavior balance world rebalance frost holyOrb vitality dragonSnow statInput wings townMuda; do
 node --experimental-vm-modules "checks/$suite.mjs" . || exit "$?"
done
python3 tools/package.py /tmp/rpg-release
```

13개 모의 API 테스트 묶음과 본체 단독 날개 명령어 검사, JSON·JS/import, 1430개 몬스터 컴포넌트 그룹, 배포 ZIP 검사를 통과했습니다. 새로 확인한 동작은 다음과 같습니다.

- 실제 상점 폼 → 다이아 5개 차감 → 구매권 지급 → 아이템 컴포넌트 → 구매 확인 → 소유권 저장. 부족·가방 가득 참·취소·중복 구매·이동·저장 실패 복구.
- 주인/다른 사람/인접 청크/바닥·지하·상공의 권한, 실제 파괴/설치/상호작용 훅과 바닥 윗면 설치, 폭발 보호, 음수 청크 좌표, 경계 미포함 청크 거절, 입자 테두리, 손상된 소유 데이터의 보호 유지.
- 마법사 계열 마나 절반과 다른 계열 유지, 4개 중 1개 평타의 피해·쿨타임, 선택 변경 악용 차단, 마나·직업 제한 및 실제 휘두르기 입력.
- 상태창 9개 첫 버튼, 이전 기능 유지, 파티/길드·던전/PvP·TPA 요청/수락·평타 설정·상점 경로, 뒤로/닫기.

실제 Minecraft 클라이언트·서버 실행은 이 환경에서 불가능하여 게임 내 입자 표시·모바일 입력·건축 보호·메뉴 표시·물리 동작은 미검증입니다.
