# RPG v0.6.23 · 냉기 능력자 개편

Bedrock 1.21.100 이상. RPG BP·Commands BP·RP 세 팩을 모두 v0.6.23로 적용하세요.

| 스킬 | 변경 내용 | 유지되는 항목 |
|---|---|---|
| 서리탄 | 쿨타임 1초, 기본 마법 피해 10, 유도탄 | MP 35, 사거리 32칸, 둔화 4초 |
| 빙결의 손 | 전방 총각도 60도(좌우 30도)·반경 7칸 부채꼴의 적 전체에 기본 마법 피해 24 | MP 55, 쿨타임 8초, 동결 2초 |
| 빙주난사 | 쿨타임 5초 | MP 95, 유도탄 5발×피해 7, 사거리 24칸 |
| 빙하보 | 신속 V·저항 III 10초 | MP 55, 쿨타임 10초, 이동 가능한 전방 최대 6칸 이동 |
| 대빙해소 | 기본 마법 피해 68 | MP 100, 쿨타임 14초, 준비 0.4초, 사거리 10칸, 동결 3초 |
| 영점빙옥 (궁극기) | 기본 마법 피해 56 | MP 300, 쿨타임 45초, 반경 12칸, 동결 5초 |

설한결계는 유지합니다. 피해 수치는 마력·비전 룬·장비·초월 및 적 방어 보정 전입니다. 냉기 능력자와 해당 스킬을 사용하는 카멜레온 모두 같은 변경을 적용합니다. 보스 제어 시간 절반 규칙도 유지합니다.

서리탄은 전방 90도 시야 안에 보이는 적을 선택하고, 발사 후 적의 현재 위치를 계속 추적합니다. 벽에 닿거나 총 비행 거리 32칸을 넘으면 사라지며, 대상이 소멸하거나 다른 차원으로 이동하면 정리됩니다. 유도할 적이 없을 때는 조준한 방향으로 발사합니다.

빙결의 손은 수평 부채꼴로 판정하고 시전자와 높이 차이가 3칸을 넘는 적은 제외합니다. 각 적은 한 번만 타격하고, 아군·뒤쪽·벽 뒤·각도/거리 밖 적은 제외합니다. 정확히 ±30도·7칸 경계에 있는 적은 포함합니다.

v0.6.22의 룬·근력 너프, 기준 섬멸 98.2, 야생 RPG 몬스터 약화, 2~10단계 던전 강화와 이전 마을 보호·무다무다·스탯 입력 수정 등을 포함합니다.

## 검증

실제 스킬 함수로 움직이는 적을 추적하는 서리탄, 벽/대상 소멸/거리 제한 시 정리, 빙결의 손 다중 적중·경계·중복/아군/벽/뒤쪽/높이 제외, 빙하보 실제 버프 증폭 4/2(게임 표기 V/III)와 200틱, 빙주난사 5회×7, 대빙해소 1회×68·동결 60틱, 영점빙옥 56·동결 100틱을 모의 API에서 확인했습니다. 정적 파일·전체 활성 모듈 연결 및 기존 전투 회귀 검사도 실행했습니다.

```sh
node tools/build_monster_balance.mjs --check
python3 checks/validate.py .
for suite in integration balance behavior world rebalance frost; do
 node --experimental-vm-modules "checks/$suite.mjs" . || exit "$?"
done
```

Python 3.12·Node.js 24 사용. 실제 Minecraft 클라이언트 실행은 미검증입니다.
