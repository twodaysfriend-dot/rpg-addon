# RPG v0.6.40 · 전방위 난식·귀심 팔중·홀리 스피어

Bedrock 1.21.100 이상. BP·Commands BP·RP 모두 v0.6.40을 활성화하고 월드를 다시 여세요. 팩 UUID·아이템 ID를 유지합니다. v0.6.39의 대형 몬스터 판정·심연 수호자 강화와 기존 수정 사항을 포함합니다.

## 투신 난식

첨부된 청백색 전방위 충격파의 느낌을 반영했습니다. 수평 360도로 충격파 16발을 0.3초 간격으로 4번 발사합니다. 사거리 25칸, 탄당 기본 물리 피해 8.5. MP 120·쿨타임 10초 유지. 64발은 여러 방향으로 퍼지므로 한 대상에게 모두 적중한다는 뜻은 아닙니다. 각 탄은 이동하며 첫 적 또는 벽에서 멈추고 아군은 제외합니다.

## 투신 신규 기술: 귀심 팔중

양팔을 번갈아 총 8번 난타하고 전방으로 강력한 청백색 충격파를 발사합니다. 왼손 4회·오른손 4회, 0.2초 간격, 사거리 20칸, 타격당 기본 물리 피해 18·8발 전탄 적중 합계 144. MP 180·쿨타임 20초. 기존 투신도 스킬 목록에 자동 추가됩니다. 이미지 자체를 게임에 복사하지 않고 파티클과 이동 타격으로 표현합니다.

두 기술은 한 번 시전한 모든 충격파에 천멸격 3배가 적용됩니다. 첫 실제 명중에서 강화 준비를 소비하며, 전부 빗나가면 유지합니다. 동일 강화의 중복 사용을 막고, 시전자 사망/차원 이동 시 남은 발사를 종료합니다. 시간 정지 중에는 진행을 멈춥니다.

## 홀리 스피어 이펙트

기존 방향 정렬 창을 더 굵고 밝게 표시하고, 시전 섬광·금빛 잔상·명중/벽 충돌 시 빛의 광륜을 추가했습니다. 근접 적중에도 광륜을 표시합니다. 기존 피해·사거리·마나·쿨타임은 유지합니다. 시각 파티클이 피해나 블록 변경을 일으키지 않습니다.

## 요청한 피해 계산

근력 250, 전설 힘의 룬 +10, 검성의 검 +10, 검성 기준입니다. 갑옷 세트·힘 효과·기타 버프 없이, 적 방어/저항 적용 전 명목 피해입니다.

- 근력 배율: 1 + 0.021×2.8×0.4×(250−5) = 6.7624
- 전설 힘의 룬 +10 배율(전설 +8/+10 보너스 포함): 2.591125
- 직업 무기 +10 배율: 1.2
- 섬멸: 41×6.7624×2.591125×1.2 = **862.09340604**, 대상당 1회
- 러쉬: 6×6.7624×2.591125×1.2 = **126.16001064**, 8회 모두 적중 시 **1,009.28008512**

실제 런타임 skillDamageFor에 실제 룬 보관함·장비·스탯을 주입해 확인했습니다. 몬스터 방어, 갑옷 세트, 힘 효과가 있으면 최종값이 달라집니다.
