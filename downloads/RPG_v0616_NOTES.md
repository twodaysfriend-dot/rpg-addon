# RPG v0.6.16

Bedrock 1.21.100 이상. BP·Commands BP·RP 세 팩을 모두 0.6.16으로 적용하세요. 이전 버전의 팩을 동시에 활성화하지 마세요.

## 마을 건축

- 250×250 성곽 도시를 유지하고 주택·왕궁에 방향이 있는 계단 지붕, 역계단 처마, 용마루 슬래브와 목재 테두리를 추가했습니다. 탑에는 석재 계단 지붕을 배치했습니다.
- 중심 광장·큰길은 어두운 석재 테두리와 밝은 돌의 반복 문양, 샛길은 석재 벽돌·이끼 낀 벽돌·이끼 낀 조약돌·이끼·안산암을 섞었습니다. 바닥 계단은 뒤집어 윗면을 평평하게 유지합니다.
- 벤치, 시장 차양 2곳, 나무와 화단을 추가했습니다. 26동 건물, 성문, 창문, 중심 스폰, 전직관 8명의 이동 공간을 유지합니다.
- 새 마을: **`/rpg:citycreate`**. 실행한 X/Z를 중심으로 생성하며 높이는 자동 검사합니다. 높이 지정은 `/rpg:citycreate 200`처럼 사용하세요.
- 이미 완성된 250 마을은 월드를 열면 **같은 위치에서 장식을 자동 갱신**합니다. 진행 중이던 옛 250 설계는 저장 지점에서 완성한 다음 갱신합니다. 접속자가 없으면 대기하고 재접속·재시작 후 이어집니다. `/rpg:cityresume`이나 추가 승인은 필요 없습니다.
- 갱신은 이전 설계의 원래 재질과 일치하는 블록만 교체·제거하며, 새 장식은 비어 있는 곳에 배치합니다. 다른 재질로 수정한 블록과 인벤토리를 가진 블록은 보존합니다. 같은 원래 재질로 수정한 블록은 원본과 구별할 수 없습니다.
- `/rpg:citystatus` 진행도 / `/rpg:citystop` 관리자 수동 중지 / `/rpg:cityresume` 수동 중지 해제.

## 마을 동물

마을 250×250의 생활 높이(바닥 아래 4칸~위 40칸)에서 자연 생성 몬스터·박쥐를 정리합니다. 동물은 기본 게임 생성 규칙을 따르며 계속 남습니다. 주민·전직관·길들인 동물·소유 소환수·던전 몹과 소환알로 직접 만든 몹은 보존합니다. 바깥 사냥터와 지하 던전의 생성 규칙은 유지합니다.

## 경험치 상점

**`/rpg:wallet` → 기본 경험치 상점**. RPG 레벨이 아닌 초록 경험치바의 기본 마인크래프트 레벨을 사용합니다.

| 상품 | 수량 | 가격 |
| --- | ---: | ---: |
| 주민 소환알 | 1개 | 30레벨 |
| 좀비 소환알 | 1개 | 50레벨 |
| RPG 경험치 포션 | 3개 | 50레벨 |
| 강화 촉매 | 25개 | 50레벨 |
| 황금 당근 | 8개 | 1레벨 |

가방 공간이 부족하거나 지급이 실패하면 아이템과 경험치를 복구합니다.

## 선택한 종류·등급의 룬 각각 일괄 강화

**`/rpg:runebatch`** 또는 `/rpg:upgrade` → 룬 강화 → 같은 종류·등급 룬 일괄 강화.

1. 일반 가방에 있는 룬을 `/rpg:runes`로 전용 보관함에 넣습니다.
2. 종류·등급 묶음을 선택하면 해당 묶음의 +10 미만 룬을 각각 **1회씩** 강화합니다. 다른 종류·등급은 제외합니다.
3. 대상 번호·현재 강화 단계·전체 비용을 확인한 뒤 실행합니다.
4. 기존 개별 강화 비용과 성공·유지·강등·파괴 확률을 적용합니다. 일괄 강화의 촉매는 0개입니다. 촉매를 쓰려면 개별 강화 메뉴를 이용하세요.
5. 장착 중인 룬도 포함합니다. 파괴된 룬만 장착 해제하며, +10 룬은 건드리지 않습니다. 재료 룬끼리 합치는 기능이 아닙니다.
6. 전체 비용 부족·확인 뒤 룬 변경 시 실행하지 않습니다. 도중 저장 실패 시 묶음 전체의 룬과 재화를 복구합니다. 처리 결과를 성공·유지·강등·파괴 수로 보여줍니다.

## 크리에이티브 무한 재화

- **`/rpg:creativefunds`**: 크리에이티브에서 골드·강화석·룬 가루를 각각 1,000,000,000까지 충전합니다. 횟수 제한 없이 다시 충전할 수 있습니다.
- 크리에이티브 아이템 목록의 **크리에이티브 무한 재화 지급권**을 사용해도 됩니다. 아이템은 소모되지 않습니다. 관리자 지급: `/give @s rpg:creative_funds`.
- 모든 실행 경로에서 실제 게임 모드를 확인합니다. 서바이벌에서는 지급권을 가지고 있어도 사용할 수 없습니다. 지급권의 조합법·드롭은 없습니다.

## 이전 기능

혈술사 스킨·전직 카드, 더 월드 흡혈 자동 대상·숙련도 1~6초·흡혈 시간 50% 증가, 카멜레온의 넨·더 월드 학습, 스폰 신속 VI·야간투시·포화와 퇴장 해제, 10단계 던전 생성, 종족·돌가면, 성직자 몬스터 회복 피해, 몬스터 피해 0.7배, 공통 무기 대체 등 이전 변경을 포함합니다.

## 검증 범위

JSON 파싱, 모든 JavaScript 문법·상대 import, 전체 활성 모듈 연결, Mojang 메타데이터 기준 건축 블록 41종과 계단·슬래브 상태를 검사했습니다. 모의 API에서 새 마을 전체 생성·옛 250 장식 갱신·중단 후 재시작·수정 블록과 보관함 보존, 마을 몬스터 정리·소환알 예외, 알 구매·경험치 환불, 일괄 강화 결과·재화 차감·전체 롤백, 크리에이티브 모드 제한과 반복 충전을 확인했습니다. 이전 던전·버프·직업·더 월드 테스트도 통과했습니다.

실제 Minecraft 클라이언트 실행과 인게임 외관은 이 환경에서 검증하지 않았습니다.

소스 ZIP의 `checks` 폴더에서 재현할 수 있습니다. 각 스크립트에 압축을 푼 소스 루트 경로를 인자로 넘기세요.

```sh
python checks/validate.py .
node --experimental-vm-modules checks/behavior.mjs .
node --experimental-vm-modules checks/integration.mjs .
node --experimental-vm-modules checks/city.mjs .
node --experimental-vm-modules checks/dungeons.mjs .
node --experimental-vm-modules checks/spawnEffects.mjs .
node --experimental-vm-modules checks/world.mjs .
```
