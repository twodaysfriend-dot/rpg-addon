# RPG v0.6.27 · 스탯 효과 절반·더 월드 해금 조건

Bedrock 1.21.100 이상. RPG BP·Commands BP·RP 세 팩을 모두 v0.6.27로 적용하세요.

## 근력·마력

요청의 “지력”은 현재 스탯 이름에 없는 항목이므로 마법 피해를 올리는 **마력**으로 해석했습니다. 지능(마나 절약)과 체력은 유지합니다.

| 스탯 효과 | 이전 | 변경 |
|---|---:|---:|
| 근력 1포인트의 물리 피해 증가율 | 4.704% | 2.352% |
| 마력 1포인트의 마법 피해 증가율 | 11.76% | 5.88% |
| 마력 1포인트의 직접 회복량 증가율 | 1.96% | 0.98% |

초기 5를 초과한 투자량에 적용하는 추가 효과를 0.5배로 줄입니다. 기본 피해·기본 회복량 자체를 반으로 줄이지 않습니다. 무기·룬·힘 버프·고정 피해 계수와 체력 50→기본 HP 120 기준은 유지합니다. 예: 근력 25·레어 힘의 룬 +0·무기 +6의 섬멸은 대상 방어 등 적용 전 98.212 → **74.408**입니다.

던전 몬스터 수치를 다시 낮추지 않았으므로 기존 장비로는 더 어렵습니다. 이전 근력 40·레어 힘의 룬 +10·무기 +6 기준의 공격력 모델은 이번 하향으로 2단계 보스 처치 약 301초가 되어 솔로 제한 270초를 넘습니다. 이는 공격 가능 시간 70%와 섬멸/평타만 사용한 모델이며 실제 게임 클리어 검증은 아닙니다.

## 스탠드 구현의 화살

기존 더 월드 전용 무기와 구분되는 **스탠드 구현의 화살** 아이템을 추가했습니다. 작업대 칸 번호는 왼쪽 위부터 1~9번입니다.

| 1 | 2 | 3 |
|---|---|---|
| 금 블록 | 금 블록 | 금 블록 |
| 금 블록 | 화살 | 금 블록 |
| 다이아몬드 블록 | 네더라이트 주괴 | 다이아몬드 블록 |

금 블록 5개·화살 1개·다이아몬드 블록 2개·네더라이트 주괴 1개로 **스탠드 구현의 화살 1개**를 제작합니다. 새 화살은 기존 “더 월드의 화살 · 전용 건틀릿”과 다른 아이템입니다.

## 더 월드 전직 조건

기존 조건에 다음을 추가하고 최소 RPG 레벨을 40에서 **60**으로 올립니다.

- 기본 직업(2차) 이상.
- RPG 레벨 60 이상. 마인크래프트 경험치 레벨과 다릅니다.
- **돌가면을 실제로 사용한 이력**.
- **스탠드 구현의 화살 제작 후 소지**.
- 기존 보스 3마리 처치·오버월드 밤 적 60마리 처치.

제작 화살을 손에 들고 사용하거나 더 월드 전직관에서 전직을 요청합니다. 전직 확인 시 인벤토리에 새 화살이 있어야 하며 화살은 소모되지 않습니다. 실제 제작자 이력을 추적하는 방식이 아니라 해당 제작 아이템을 마련해 소지한 상태를 조건으로 판정합니다. 보관함에 넣어 둔 화살이나 기존 전용 무기로는 충족하지 않습니다.

돌가면 사용 이력은 사용 성공·소비가 완료됐을 때 개인 동적 속성에 저장해 직업 변경 후에도 유지합니다. 혈술사 등 타고난 흡혈귀라는 이유만으로 충족하지 않습니다. 업데이트 시 돌가면으로 흡혈귀가 된 현재 상태가 남아 있으면 해당 사용 이력을 복원합니다. 과거 사용 후 이미 직업이 바뀌어 기록이 남지 않은 경우에는 재사용이 필요합니다.

이미 더 월드인 플레이어의 직업과 스킬은 유지합니다. 새 조건은 신규 전직 요청에 적용하고 관리자 강제 전직은 유지합니다. 새 화살을 얻으면 개인 히든 발견 기록을 남기며 발견 후 전직 안내/제작 도감에서 확인합니다. 일반 스킬 안내·GPT에 미발견 히든 조건을 노출하지 않습니다.

v0.6.26의 용의 선택과 눈 지형 스트레이, 축복 구슬 경량화, 체력 기준 등 이전 기능을 포함합니다.

## 검증

모의 API의 실제 돌가면 사용·소비·이력 저장, 직업 변경 후 유지, 태생 흡혈귀 구분, 기존 돌가면 상태 이력 복원을 검사했습니다. RPG 레벨 59 거부/60 허용, 화살 미소지 및 기존 처치 조건 미달 거부, 실제 아이템 사용 → 확인창 → 더 월드 무기/스킬 전직 경로를 실행했습니다. 조합 1~9번 칸·결과 아이템·아이콘과 근력/마력/직접 회복 추가 효과 절반·지능 마나 절약 유지도 검사했습니다.

```sh
python3 checks/validate.py .
node tools/build_monster_balance.mjs --check
for suite in integration worldUnlock behavior balance world rebalance frost holyOrb vitality dragonSnow statInput; do
 node --experimental-vm-modules "checks/$suite.mjs" . || exit "$?"
done
```

Python 3.12·Node.js 24 사용. 실제 Minecraft 클라이언트 실행은 미검증입니다.
