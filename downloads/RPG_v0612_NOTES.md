# RPG v0.6.12 — 요청 변경사항 일괄 적용

기준: 첨부 RPG v0.6.10 + 앞서 제공한 v0.6.11. 팩 UUID는 유지하고 BP / Commands BP / RP 모두 0.6.12로 올렸습니다.

## 사용 명령어

- `/rpg:weapon` — 보유한 공통 무기를 선택해 직업 아이템 대신 단축바 1번 칸에서 사용합니다. 메뉴의 ‘대체 해제’로 직업 아이템으로 돌아갈 수 있습니다.
- `/rpg:spawncreate` — 관리자 전용. 남쪽(+Z) 20칸을 중심으로 17×17 스폰 광장과 전직관 8명을 생성합니다. 기존 건축물을 덮어쓰지 않습니다.
- `/function rpg_spawn` — 플레이어가 실행하는 스폰 생성 대체 명령어.
- `/rpg:status` 또는 상태창 아이템 — 현재 종족 확인.
- `/rpg:craft` — 돌가면·파편 조합법 확인.

## 공통 무기 대체

실제로 보유한 공통 무기 중 하나를 골라 사용합니다. 등급·강화·내구도·이름·인챈트를 가진 실제 아이템을 이동하며, 무기를 새로 복제하지 않습니다. 기존 직업 아이템은 선택 무기가 있던 인벤토리 칸으로 이동합니다.

선택 무기는 1번 칸에 고정되고 사망 시 유지됩니다. 재접속·직업 변경·상위 전직 후에도 선택 무기와 강화 상태를 유지하며 기술은 새 직업의 기술을 사용합니다. 강화된 결과도 같은 무기로 1번 칸에 남습니다. 내구도 소진 또는 강화 파괴로 선택 무기가 없어지면 현재 직업 아이템이 다시 지급됩니다(최대 약 1초). 견습은 선택 당시 계열의 시작 아이템으로 돌아갑니다.

우클릭/모바일 사용: 직업 기술. 웅크려 사용: 기술 메뉴. 좌클릭 대상 기술은 기존처럼 대상을 때려 사용합니다. 궁수 계열도 대체 무기에서 화살을 발사하며 일반 궁수는 화살이 필요합니다. 천궁의 기존 마나 화살 규칙은 유지합니다. 카멜레온은 공통 무기 대체 중 두 전용 무기 간 교체 대신 `/rpg:weapon` 메뉴에서 해제할 수 있습니다.

## 종족과 돌가면

| 종족 | 직업 |
|---|---|
| 흡혈귀 | 더 월드·혈술사 |
| 언데드 | 복수귀 |
| 인간 | 나머지 직업 |

돌가면을 손에 들고 사용하면 1개를 소비해 흡혈귀로 변합니다. 이미 흡혈귀이면 소비하지 않습니다. 다음에 다른 직업으로 전직하면 새 직업의 종족으로 변경됩니다.

흡혈귀는 오버월드 낮·맑은 날·머리 위가 가려지지 않은 곳에서 받는 피해가 1.5배입니다. 밤·실내·비/뇌우·다른 차원에서는 햇빛 배율이 적용되지 않습니다. 햇빛 자체로 별도 주기 피해를 추가하지 않았습니다. 패시브는 적에게 실제로 준 피해의 10%를 최대 체력까지 회복합니다. 기존 룬/기술 흡혈과 별도로 더해집니다. 아군·전직관·샌드백 등의 대상은 흡혈에서 제외합니다.

돌가면과 파편은 모두 512×512 투명 도트 텍스처입니다.

작업대 조합(각 1개 생산):

```text
돌가면 파편             돌가면
돌  돌  돌             파편  파편    파편
돌  금  돌             파편  네더    파편
돌  돌  돌             파편  파편    파편
```

금 = 금 블록 1개, 네더 = 네더라이트 주괴 1개. 돌은 조약돌이 아닌 `minecraft:stone`입니다.

## 전투와 처치 안내

- 몬스터의 공격으로 플레이어가 받는 피해를 기존의 0.7배로 조정했습니다. 기존 방어 룬 배율과 함께 적용하며 플레이어 공격에는 몬스터 감소 배율이 붙지 않습니다. 햇빛 아래 흡혈귀의 몬스터 피격 배율은 두 효과를 곱해 0.7×1.5=1.05배입니다.
- 성직자 단일 힐을 적 몬스터에게 사용하면 계산된 회복량의 3배를 피해로 줍니다. 천사 축복의 즉시 회복과 회복 장판의 회복 주기에도 범위 내 적 몬스터에게 같은 규칙을 적용합니다. 아군의 회복은 유지하고, 지원 전용 부착 구슬은 아군 전용으로 유지합니다.
- 스트레이·블레이즈 누적 처치 1 / 10 / 20 / 30 / 40회에 각 1번 `(???/50)`, 50회에 `(50/50)`이 채팅에 표시됩니다. 스트레이는 `§r§l§b`, 블레이즈는 `§r§l§6`입니다. 50회 이후에는 반복 출력하지 않습니다. 기존 생존/모험 모드 시련 처치 집계를 사용합니다.

## 스폰과 이전 변경사항

스폰 전직관: 궁수·성직자·검사·마법사·무투가·넨·더 월드·투신 총 8명. 생성할 17×17×6 공간이 비어 있어야 하며 충돌 시 생성을 거부합니다. 기존에 만든 v0.6.11 광장을 자동 변경하지는 않으므로 새 빈 공간에서 생성하거나 `/rpg:hito archer`, `/rpg:hito holy`, `/rpg:hito sword`, `/rpg:hito mage`, `/rpg:hito fist`로 소환알을 받아 추가 배치할 수 있습니다. 월드 스폰 위치는 생성 메시지의 `/setworldspawn X Y Z`를 실행해 지정합니다.

v0.6.11 변경도 포함합니다: XP 상점 포션 3개/촉매 25개(각 기본 XP 50레벨), 투신 난참 포함 기술 6개, 더 월드 전직 조건·금색 외형 전직관, 넨 전직 조건 및 오라 파티클. 더 월드 전직관은 별도 스킨 첨부가 없어 첨부본 내부 금색 스킨을 재사용했습니다.

## 설치와 검증 범위

월드를 백업한 후 mcaddon을 가져오고 BP·Commands BP·RP 세 팩을 모두 v0.6.12로 활성화하세요. 최소 Minecraft Bedrock 1.21.100, server API 2.2.0 / server-ui 2.0.0입니다.

전체 소스 ZIP을 풀고 Python 3.12 및 Node.js 24에서 실행할 수 있습니다. 추가 의존성 설치는 필요하지 않습니다.

```sh
python3 checks/validate.py .
node --experimental-vm-modules checks/behavior.mjs .
node --experimental-vm-modules checks/integration.mjs .
```

검증 범위: JSON·JavaScript 문법, 활성 BP 로컬 import, 전체 게임플레이 모듈 연결/평가, 새 명령어와 아이템 컴포넌트 등록, 기존 상점과 투신·전직 테스트, 종족/돌가면/햇빛/흡혈, 몬스터 피해·방어 룬 조합, 힐 공격, 처치 알림, 공통 무기의 실제 강화 트랜잭션·파괴·전직·칸 이동·인벤토리 가득 참·해제 시 중복 방지를 모의 Minecraft API로 검증했습니다.

이 클라우드에는 실제 Minecraft Bedrock 런타임이 없어 게임 가져오기, 엔진의 피해 필터/이벤트 순서, NPC 대화, 모바일 입력과 파티클/아이템 렌더링은 실게임에서 검증하지 못했습니다. 모의 API 테스트가 엔진 검증을 대신하지는 않습니다. 테스트 월드에서 `/rpg:ping`, `/rpg:weapon`, `/rpg:spawncreate`, 돌가면 사용과 낮/밤 피격을 확인해 주세요.
