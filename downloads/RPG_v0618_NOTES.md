# RPG v0.6.18

Bedrock 1.21.100 이상. RPG BP·Commands BP·RP 세 팩을 모두 0.6.18로 적용하세요.

## 투신 난식

- 부채꼴 원거리 충격파를 **12발** 동시에 발사합니다.
- 탄당 기본 피해는 이전 34의 1/4인 **8.5**입니다. 각 탄이 첫 번째 적 또는 벽에서 멈춥니다.
- 같은 적에게 여러 발이 맞으면 **매 탄마다 개별 피해**가 들어갑니다. 12발 전탄 적중의 명목 기본 합계는 **102**입니다. 실제 피해는 근력·장비·방어·명중 상황에 따라 달라집니다.
- 사거리 25칸, MP 120, 쿨타임 10초 유지. 천멸격의 3배는 해당 시전의 모든 탄에 적용하며 완전히 빗나가면 준비를 유지합니다.

## 카멜레온 스킬 초월

**`/rpg:skillbook` → 스킬 초월 / 초월강화**.

이미 배우고 **진화한 공격·직접 회복 기술**의 위력을 높입니다. 초월 기술은 동시에 최대 **3개**입니다. 직접 피해·회복 수치가 없는 지원·시간정지 기술은 대상에서 제외해, 위력 증가가 없는 기술에 재료를 쓰지 않도록 했습니다.

| 초월 순서 | 골드 | 강화석 | 추가 재료 |
| --- | ---: | ---: | --- |
| 1번째 | 200,000 | 800개 | 네더라이트 주괴 2개 + 다이아몬드 블록 9개 |
| 2번째 | 500,000 | 2,000개 | 네더라이트 주괴 2개 + 다이아몬드 블록 9개 |
| 3번째 | 750,000 | 3,000개 | 네더라이트 주괴 2개 + 다이아몬드 블록 9개 |

첫 비용의 2.5배가 2번째이고, 2번째의 1.5배가 3번째입니다. 현재 초월한 기술 수를 기준으로 다음 비용을 정합니다.

초월한 기술은 각각 **최대 3회** 초월강화할 수 있습니다. 매회 **골드 30,000 + 강화석 100개**를 사용하며 추가 실물 재료는 없습니다.

위력 증가 수치는 미지정이어서 안내한 기본값으로 적용했습니다.

| 단계 | 피해·직접 회복 수치 보정 |
| --- | ---: |
| 초월 | +25% |
| 초월강화 +1 | +35% |
| 초월강화 +2 | +45% |
| 초월강화 +3 | +55% |

- 시전할 때 해당 기술의 수치만 복사·보정합니다. 다른 기술과 다른 직업의 공유 데이터는 바꾸지 않습니다. 충전·지연 공격은 시전 시점의 위력을 유지합니다.
- 사거리·반경·탄 수·지속 시간·상태이상 시간·마나·쿨타임은 유지합니다. 기존 진화의 횟수 무제한도 유지합니다. 고정 처형 조건 등 직접 피해 수치 이외의 규칙은 바꾸지 않습니다.
- 초월 상태와 강화 단계는 재접속·월드 재시작 후 유지됩니다. 다른 직업에서는 해당 초월 보정을 적용하지 않습니다.
- 스킬을 분해하면 그 기술의 진화·초월·초월강화가 함께 사라집니다. 원래 분해 SP만 환급하며, 진화·초월에 쓴 골드·강화석·재료는 반환하지 않습니다. 확인창에 표시합니다.
- 전체 비용·실물 재료가 부족하면 아무것도 차감하지 않습니다. 확인 뒤 상태가 바뀌면 다시 선택해야 합니다. 저장 중 오류가 나면 재료·지갑·초월 상태를 함께 복구합니다.
- 기존 카멜레온 성장 데이터에는 빈 초월 정보를 추가하며, SP·사용 횟수·진화·대기 스킬북은 유지합니다.

## 룬 강화 확률

촉매를 적용한 기존 최종 확률에서 **강등 확률을 절반**으로 낮춥니다. 줄어든 확률은 **성공·유지에 각각 반씩** 더합니다. 파괴 확률은 유지하며 갑옷·무기 확률은 바꾸지 않습니다. 개별 강화와 같은 확률 함수를 쓰는 일괄 강화 모두 적용됩니다.

예: +2 룬, 촉매 없음의 성공/유지/강등/파괴는 `70/28/2/0%`에서 **`70.5/28.5/1/0%`**로 바뀝니다. 촉매 5개일 때도 `98/0/2/0%` → `98.5/0.5/1/0%`로 정확히 반씩 배분합니다.

## 방출 · 오라포

쿨타임을 **900틱 = 45초**로 변경했습니다. 넨 능력자와 이 기술을 배운 카멜레온 모두 적용됩니다. 1초 충전과 기존 피해·범위·마나 비용은 유지합니다.

## 이전 기능과 검사

v0.6.17의 직업별 추천 스탯·장비 등급 설정 명령어, 마을·소환알 상점·룬 일괄 강화·크리에이티브 재화 등 이전 기능을 포함합니다.

JSON·모든 JavaScript 문법/상대 import·전체 활성 모듈 연결을 검사했습니다. 모의 API에서 난식 12회 피해와 네이티브 피해 거부 시 보완·천멸격·벽/아군/사거리 제외, 모든 단계/촉매의 확률 합계와 분배, 정확한 초월 비용·재료·횟수 제한·전체 복구·메뉴 실행·실제 시전 위력·지연 시전 수치 유지·기존 저장 호환·45초 재사용 대기시간을 확인했습니다. 룰북은 기존 50쪽 제한 안에 유지합니다.

실제 Minecraft 클라이언트 실행은 미검증입니다. 소스 ZIP에 검사 스크립트를 포함했습니다.

```sh
python checks/validate.py .
node --experimental-vm-modules checks/integration.mjs .
node --experimental-vm-modules checks/balance.mjs .
node --experimental-vm-modules checks/behavior.mjs .
node --experimental-vm-modules checks/world.mjs .
```
