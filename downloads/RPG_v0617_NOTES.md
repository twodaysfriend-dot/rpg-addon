# RPG v0.6.17

최소 Bedrock 1.21.100. RPG BP·Commands BP·RP 세 팩을 모두 0.6.17로 활성화하세요.

## 직업별 추천 스탯

`/rpg:skillguide`의 직업 계열 목록·설명·스킬 상세, `/rpg:skills`의 스킬 설정창, `/rpg:jobs`의 전직 상세에 추천 스탯을 표시합니다. 카멜레온은 스킬 학습창에서도 **복합**으로 표시합니다. 피해량·회복량 계산이나 밸런스는 변경하지 않습니다.

| 직업 계열 | 표시 내용 |
| --- | --- |
| 검사·검성·타락검성 | 근력 |
| 궁수·천궁 | 근력 — 기본 화살은 엔진 피해, 마나 화살의 기본 피해는 고정 |
| 망나니·야수, 암살자·그림자 암살자, 작살꾼·복수귀 | 근력 |
| 더 월드, 투신, 달의 후예 | 근력 |
| 마법사·현자, 성직자 계열 | 마력 — 성직 직접 회복량도 마력 적용 |
| 냉기 능력자, 화염술사, 마법공학사, 해커, 악마 | 마력 |
| 무투가·권골 | 근력 우선 · 풍압은 마력 |
| 용기사 | 근력 우선 · 브레스는 마력 |
| 혈술사 | 마력 우선 · 혈인 근접은 근력 |
| 해의 후예 | 마력 우선 · 메테오드라이브 충돌은 근력 |
| 넨 능력자 | 복합 (근력·마력) — 경·주·참격파는 근력, 발 구체·연탄·오라포·오라 폭주는 마력 |
| 카멜레온 | **복합** — 배우고 주로 사용하는 기술에 맞춰 투자 |
| 견습 | 체험 중인 계열에 맞춰 선택 |

기술별 예외와 고정 피해·시간 정지 숙련도 등의 설명을 함께 표시합니다. 성직 계열의 긴 보상 설명은 계열 제목에서 본문으로 옮겼습니다.

## 관리자 장비 등급 설정

```text
/rpg:setgrade <등급> [대상]
```

| 예시 | 대상 |
| --- | --- |
| `/rpg:setgrade 신화` | 손에 든 RPG 장비 |
| `/rpg:setgrade 일반 hand` | 손에 든 장비를 일반으로 낮춤 |
| `/rpg:setgrade 전설 head` | 현재 착용한 투구 |
| `/rpg:setgrade 영웅 chest` | 현재 착용한 흉갑 |
| `/rpg:setgrade 고대 legs` | 현재 착용한 각반 |
| `/rpg:setgrade 에픽 feet` | 현재 착용한 장화 |
| `/rpg:setgrade 6 rune1` | 장착 룬 1번 슬롯을 신화로 설정 |
| `/rpg:setgrade 레어 rune:r12` | 룬 보관 번호 r12를 레어로 설정 |

- 등급: **일반 / 레어 / 에픽 / 고대 / 영웅 / 전설 / 신화** 또는 **0 / 1 / 2 / 3 / 4 / 5 / 6**. 높이거나 낮출 수 있습니다. 비용과 강화 시련이 없습니다.
- 대상 생략 시 손에 든 아이템입니다. `hand`, `head`, `chest`, `legs`, `feet`, `rune1`~`rune5`, `rune:보관번호`를 지원합니다. 부위는 `손`, `머리`, `가슴`, `다리`, `발`, 장착 룬은 `룬1`~`룬5`도 됩니다.
- RPG 갑옷·공통 무기 및 보관함 룬의 실제 등급을 변경합니다. 착용 갑옷 HP와 룬 능력 등 기존 등급별 효과에 반영됩니다.
- 강화 단계, 인챈트, 내구도, 사용자 이름, 기존 옵션·로어, 공통 무기 고유 번호와 룬 장착 상태는 유지합니다. 등급 표시만 새 등급으로 갱신합니다.
- 일반 가방에서 여러 개 쌓이는 룬은 `/rpg:runes`로 보관함에 넣고 장착 슬롯이나 보관 번호를 지정하세요. 가방의 룬 묶음에 직접 동적 속성을 쓰지 않습니다.
- 직업 전용 무기는 기존과 같이 강화 전용이며 등급을 붙이지 않습니다. 바닐라 아이템 및 등급 시스템에 없는 아이템도 제외합니다.
- 관리자 전용입니다. 슬래시·스크립트 이벤트·채팅 별칭 실행에서도 권한을 확인합니다. 예: `/scriptevent rpg:setgrade 신화 head`.
- 잘못된 등급·빈 장비·해금하지 않은 룬 슬롯은 변경하지 않습니다. 저장 오류 시 원본을 복구합니다.

## 포함된 이전 기능

v0.6.16의 계단 지붕·장식 바닥·기존 마을 자동 갱신, 자연 몬스터 정리, 경험치 상점 주민알 30레벨·좀비알 50레벨, 선택한 종류·등급의 룬 각각 일괄 강화, 크리에이티브 무한 재화와 모든 이전 변경을 유지합니다.

## 검증

모든 JSON 파싱·JavaScript 문법·상대 import와 전체 활성 모듈 연결을 검사했습니다. 모의 API에서 각 직업 추천 표시, 실제 스킬 도감·설정창 본문, 카멜레온 복합, 등급 이름·숫자, 관리자 제한, 두 활성 명령어 등록 경로의 인자 전달, 갑옷·장착 룬·보관 번호 지정, 실제 HP·룬 능력 변화, 강화·이름·내구도·고유 번호 보존과 저장 실패 복구를 확인했습니다. 기존 직업·무기·상점·룬 일괄 강화·더 월드 숙련도·흡혈 검사도 통과했습니다.

실제 Minecraft 클라이언트 실행은 이 환경에서 검증하지 않았습니다. 소스 ZIP의 `checks` 폴더에 검사를 포함했습니다.
