# RPG v0.6.49 · 룬 제작 편의·재화 송금

Bedrock 1.21.100 이상. BP·Commands BP·RP 세 팩 모두 v0.6.49로 활성화하고 월드를 다시 여세요. 팩 UUID, 기존 아이템 ID, 지갑·룬·장비·감옥 저장 데이터는 유지합니다.

## 경험치 상점: 룬 가루 200개

`/rpg:wallet` → 기본 경험치 상점 → 룬 가루 200개. **기본 마인크래프트 경험치 40레벨을 소모**하며 RPG 직업 레벨과는 별개입니다. 룬 가루는 지갑에 바로 지급하여 인벤토리가 가득 차도 살 수 있습니다. 경험치 부족/지갑 한도 초과 시 구매하지 않고, 저장 실패 시 차감한 경험치와 지갑을 복구합니다. 기존 상품·가격은 유지합니다.

## 골드·강화석·룬 가루 송금

`/rpg:pay` 또는 `/rpg:wallet` → 재화 송금에서 **접속 중인 받는 사람 → 재화 종류 → 수량 입력 → 최종 확인** 순서로 사용하세요. 골드·강화석·룬 가루 각각 1 이상의 정수 수량을 수수료 없이 즉시 보냅니다. 자신에게 송금, 잔액 부족, 받는 지갑 한도 초과, 상대 접속 종료 시 취소합니다. 한도는 재화당 기존 10억입니다. 처리 중 중복 송금을 막고 저장 실패 시 양쪽 지갑을 복구합니다.

## 룬 일괄 강화: 촉매 선택

`/rpg:runebatch`에서 **종류·등급 → 룬별 촉매 0~5개 → 전체 비용 확인** 후 실행하세요. 같은 종류·등급의 룬을 각각 한 번씩 시도합니다. 촉매는 현재 +2 이상의 룬에만 선택한 수량을 쓰며, +0/+1은 촉매 없이 강화하고 +10은 제외합니다. 예: +1/+2/+9 룬에 3개 선택 시 총 6개 사용입니다.

전체 골드·룬 가루·촉매가 부족하면 시작하지 않습니다. 진행 중 저장 오류가 나면 해당 일괄 작업 전체의 룬·지갑·촉매를 복구합니다. 기존처럼 장착 중인 룬도 일괄 강화에 포함하며, 개별 강화의 성공·유지·강등·파괴 확률을 적용합니다.

## 룬 자동 완성

`/rpg:runeauto` 또는 `/rpg:runes` → 룬 자동 완성에서 다음 네 값을 입력합니다.

- 룬 종류: 힘/근력, 비전/마력, 수호/방어, 생명/체력, 샘/마나, 흡수/흡혈 (정식 이름·영문 ID도 지원).
- 목표 등급: 일반·레어·에픽·고대·영웅·전설·신화 또는 0~6.
- 목표 강화: 0~10.
- 시도당 촉매: 0~5. 현재 +2부터 해당 수량을 사용합니다.

확인 후 인벤토리와 룬 전용 가방을 매 단계 다시 읽어, 같은 종류의 재료를 가져옵니다. 이미 목표 등급·강화 이상인 룬이 있으면 추가 비용 없이 완료합니다. 이미 강화된 사용 가능 재료를 우선하며, **현재 장착한 룬과 시작 당시 장착한 룬은 자동 작업의 강화·합성 재료에서 제외**합니다. 다른 종류와 목표보다 높은 등급은 소비하지 않습니다. 목표 결과는 룬 가방에 남으며 자동 장착하지 않습니다.

진행 예: 에픽 +3 목표라면 일반 룬 두 개를 각각 +5로 강화 → 레어 +0 합성 → 같은 과정을 반복해 레어 두 개를 각각 +5로 강화 → 에픽 +0 합성 → +3까지 강화합니다. 인벤토리 룬은 한 개씩 옮기므로 묶음 전체를 한 번에 소비하지 않습니다.

기존 강화 비용·촉매 보정·실패·강등·파괴, 기존 합성 성공률을 적용합니다. 합성은 같은 종류·등급 +5 이상 두 개를 사용하며 성공하면 하나를 소비하고 남은 룬이 상위 등급 +0이 됩니다. 둘 다 +10이면 기존처럼 100%, 그 외에는 기존 등급별 90/85/80/75/70/60%입니다. 합성 실패는 두 룬을 보존하며 50% 확률로 주장비가 1강 하락합니다. 하락하면 +5를 다시 만들고 재시도합니다. 강화 중 파괴되면 남은 재료로 다시 시작할 수 있습니다. **미장착 고강화 룬도 합성 재료가 될 수 있으므로 시작 전 재료를 확인하세요.**

필요한 골드·룬 가루·선택 수량의 촉매·룬 재료 부족, 룬 가방 공간 부족, 저장 오류가 나면 종료합니다. 선택한 촉매가 부족해도 수량을 임의로 줄이거나 무촉매로 계속 시도하지 않습니다. +0/+1은 촉매 적용 대상이 아니므로 촉매 없이 진행합니다.

**2틱마다 한 번 작업**하여 장시간 연속 실행도 서버 이벤트 처리를 막지 않습니다. `/rpg:runeautostop`으로 즉시 중단하거나 `/rpg:runeauto`를 다시 열어 중단을 선택할 수 있습니다. 사망·접속 종료·월드 재시작 시 중단하고 자동 재개하지 않습니다. 이미 완료한 강화·합성 비용은 돌려주지 않으며, 완성/중간 룬과 남은 재화는 보존합니다. 실패 확률 때문에 필요한 총 비용이나 성공 횟수는 보장되지 않습니다.
