# RPG v0.6.13

v0.6.12의 모든 변경을 유지하면서 10단계 던전 생성, 1000×1000 판타지 성곽 도시, 구욱과 카멜레온 전직 카드를 추가·수정했습니다.

## 10단계 던전 생성

관리자 플레이어가 오버월드에서 실행하세요.

```mcfunction
/rpg:dungeoncreate 10
```

확실한 대체 경로:

```mcfunction
/function rpg_dungeon10
```

`/dungeoncreate 10` 별칭도 등록하도록 추가했습니다. 다만 일부 Bedrock 버전은 네임스페이스 없는 커스텀 명령어를 허용하지 않으므로, 위의 `/rpg:dungeoncreate 10` 또는 `/function rpg_dungeon10`을 사용하세요.

확인하고 수정한 문제:

- 기존에는 `/dungeoncreate` 별칭이 없었습니다.
- 개별 난이도 생성이 항상 실행자 위치를 사용해 이미 만든 던전과 겹치면 중단됐습니다. 이제 전체 생성과 같은 80블록 간격의 격자를 사용하고, 기존 등록 위치를 피해 빈 등록 자리를 찾습니다. 1~9단계가 등록된 상태에서 10단계를 만들 수 있습니다.
- 이미 생성 중인 10단계에 명령어를 다시 실행하면 작업을 중복 생성하지 않고 현재 작업을 안내합니다.
- 생성 예약·오류·완료 메시지를 채팅에도 표시합니다. 완료 메시지에 좌표와 입장 명령어가 나옵니다.

생성은 여러 틱에 나누어 진행하며 동굴 완성 검사 후 입장할 수 있습니다. 완료 후 `/rpg:dungeon 10`으로 입장하세요. 기존 건축물·지형은 지우지 않으며, 실제 블록이 있는 자리에서는 생성이 중단될 수 있습니다. 기존 던전의 좌표와 블록은 이동·초기화하지 않습니다.

## 1000×1000 판타지 성곽 도시

```mcfunction
/rpg:citycreate
/rpg:citystatus
/rpg:citystop
/rpg:cityresume
```

관리자 전용입니다. 기본 바닥 높이는 Y=200이며 월드 스폰의 X/Z를 중심으로 정확히 1000×1000 범위에 만듭니다. 다른 높이는 `/rpg:citycreate 240`처럼 지정할 수 있습니다(-62~260).

중앙 성채, 탑, 성벽, 네 방향 출입문, 대로·골목, 주거/상점/회관 147동, 분수 광장, 조명, 전직관 8명을 포함합니다. 전체 공간을 먼저 검사하고, 64×64 이하 구역을 하나씩 로딩해 공기 블록에만 배치합니다. 전체 범위를 동시에 로딩하거나 기존 건물을 밀어버리지 않습니다.

속도를 제한하므로 완성까지 수십 분 이상 걸릴 수 있습니다. 실제 시간은 기기 성능과 서버 TPS·청크 로딩에 따라 달라집니다. 중지·재접속·월드 재시작 후 `/rpg:cityresume`으로 이어서 진행합니다. 생성자가 접속을 종료하면 중지합니다.

지형 또는 건축물이 선택 높이와 겹치면 건축 시작 전 검사를 중단합니다. 아직 공간 검사 단계라면 `/rpg:cityreset`으로 검사 작업만 취소하고 더 높은 곳으로 다시 시작할 수 있습니다. 이미 건축을 시작한 도시는 지우거나 초기화하지 않고 이어서 완성합니다.

완성하면 월드 기본 스폰을 도시 중앙 광장으로 지정하고 이동용 `/tp` 명령어를 채팅에 표시합니다. 기존 침대·개인 리스폰 지정은 별개입니다. 옛 17×17 광장 명령어 `/rpg:spawncreate`도 유지합니다.

## 구욱과 카멜레온 전직 카드

- NPC 표시 이름은 접두어 없이 **구욱**입니다. 기존에 배치했던 NPC도 로딩되면 이름을 갱신합니다.
- 외형은 사용자가 준 이미지의 검은 머리·보라색 눈·검은 옷 디자인을 기준으로 재구성한 128×128 텍스처와 표준 인간형 UV 모델을 적용했습니다. 원본 PNG 파일의 바이트 단위 복사본은 아닙니다.
- 카드를 들지 않으면 구욱은 일반 대화만 보여줍니다. 카드를 손에 들고 대화하면 카멜레온 전직 메뉴를 사용할 수 있습니다.
- 카드는 크리에이티브 아이템 목록에서 **카멜레온 전직 카드**로 찾습니다. 식별자는 `rpg:chameleon_job_card`입니다. 제작법·드롭·생존 모드 자동 지급은 없습니다.
- 카드 소지가 기존의 직업 3종 습득·전직 포기·NPC 발견·레벨 시련을 대체합니다. 카드를 실제 주 손에 들고 있어야 하며 인벤토리에만 있으면 인정하지 않습니다. 전직할 때 카드는 소비하지 않습니다.
- 구욱 배치는 기존 관리자 명령어 `/rpg:hito 구욱`으로 소환알을 받아 사용하거나 크리에이티브에서 구욱 소환알을 사용하세요.

## 설치와 검증

월드 백업 후 파일을 가져오고 **RPG BP·Commands BP·RP 세 팩 모두 v0.6.13**으로 활성화하세요. 이전 버전 UUID를 유지했습니다. 최소 Bedrock 1.21.100, Script API server 2.2.0 / server-ui 2.0.0입니다.

구조·문법과 모의 API 테스트를 통과했습니다. 실제 Minecraft 엔진 실행·모바일 입력·피해 이벤트 순서·텍스처 렌더링은 이 환경에서 검증하지 못했습니다.

소스 ZIP을 풀고 Python 3과 Node.js 24에서 실행:

```sh
python3 checks/validate.py .
node --experimental-vm-modules checks/behavior.mjs .
node --experimental-vm-modules checks/integration.mjs .
node --experimental-vm-modules checks/dungeons.mjs .
node --experimental-vm-modules checks/city.mjs .
```

10단계 검증은 기존 1~9단계 등록 후 실제 생성 루프·전체 동굴 블록 검사, 청크 일시 중단, 누락 바닥 복구, 전체 1~10단계 생성 완료, 부분 건설 후 복구를 포함합니다. 도시 검증은 100만 열의 범위 검사, 전체 모의 건축 완료, 전직관 8명, 중지·재개·체크포인트·기존 블록 보존을 포함합니다.
