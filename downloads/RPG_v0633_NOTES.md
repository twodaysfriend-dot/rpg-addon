# RPG v0.6.33 · 피스톤·공용 주택·관리자 토지·좀비 보존

Bedrock 1.21.100 이상. RPG BP·Commands BP·RP 세 팩을 모두 v0.6.33으로 활성화하고 월드를 다시 여세요. 기존 UUID·청크 소유권·길드/파티 공유·마나 공물·마법사 평타·상태창 분류·날개 속도 등 이전 기능과 데이터를 유지합니다.

## 피스톤 설치

기존에는 설치 지점 주변 여섯 방향을 각각 13칸씩 검사하여 근처에 마을 바닥이나 다른 보호 구역이 있기만 해도 피스톤을 막았습니다. 이를 플레이어 위치/시선으로 추정한 실제 설치 방향의 밀기 공간·끈끈이 당기기 공간 검사로 좁혔습니다. 공기 뒤 불필요한 공간은 검사하지 않습니다.

자신에게 편집 권한이 있는 토지나 미구매 공용 집 내부에서는 일반·끈끈이 피스톤을 설치할 수 있습니다. 다른 방향에 있는 바닥 때문에 수평 설치를 거부하지 않습니다. 추정 방향의 헤드/밀기·당기기 위치가 보호 바닥이나 타인 토지이면 설치를 거부합니다. 블록 직접 파괴·설치와 폭발에 대한 기존 바닥 보호를 유지합니다.

실제 피스톤 설치 방향, 설치 후 블록 변경·슬라임/꿀 블록의 연결 이동 등 엔진 물리 전체를 검증한 것은 아닙니다. 안정 Script API 2.2.0에는 피스톤 활성화 전 취소 이벤트가 없어 이 변경은 설치 시점 검사이며, 모든 기계적 이동을 차단한다고 보장하지 않습니다.

## 집 내부의 기본 사용

**미구매 청크에 있는 기존 마을 주택 공간은 구매권 없이 누구나 수정**할 수 있도록 복원했습니다. 생성 데이터의 기존 주택 경계와 마을 바닥 위 1~16 높이를 기준으로 합니다. 주택이 여러 청크에 걸치면 각 부분의 청크 소유권을 따릅니다.

- 마을 바닥과 지하는 계속 직접 파괴할 수 없습니다. 공용 집 바닥 위에 블록을 올릴 수 있습니다.
- 구매된 청크의 집 부분은 구매자·현재 같은 길드/파티만 수정할 수 있습니다.
- 공용 집 바깥의 마을 공간은 기존처럼 청크 권한이 필요합니다.
- 소유권을 해제하면 해당 집 부분은 다시 공용으로 돌아갑니다. 건축물은 자동으로 변경하거나 삭제하지 않습니다.

## 관리자 토지 지정·해제

`/rpg:admin`으로 운영자 관리 도구를 받고 사용하세요.

1. 변경할 마을 청크에 섭니다.
2. **대상 플레이어 선택**으로 온라인 플레이어를 선택합니다.
3. **현재 청크를 대상에게 지정** → 확인하면 기존 소유자가 있어도 새 소유자로 지정합니다.
4. **현재 청크 소유권 해제** → 확인하면 현재 청크의 소유권을 삭제합니다. 해제에는 기존 소유자의 접속이 필요하지 않습니다.

다이아몬드·구매권을 소비하지 않고 건축물을 유지합니다. 관리자 권한을 실제 저장 직전에 다시 확인하고, 확인 중 다른 청크로 이동하면 취소합니다. 일반 플레이어가 아이템을 갖는 것만으로 사용할 수 없습니다. 저장 오류 시 기존 소유권 복구를 시도합니다.

## 마을 좀비 유지

마을 안에서 **자연 출현한 좀비는 제거**합니다. **소환알 좀비와 외부에서 들어온 좀비는 애드온의 마을 정리로 삭제하지 않습니다.** 불명확한 기존/로드 개체는 외부 유입일 수 있으므로 보존합니다.

마을 정리 외에도 평화 구역, 동굴 자연 출현 제한, 밤 몬스터·아침 정리에서 허용된 좀비를 보존하도록 연결했습니다. 자연 출현 여부는 출현 시점·위치에 기록하고, 소환알은 사용 시점·위치와 대조합니다. 출현 뒤 늦게 들어오는 소환알 이벤트를 기다리는 유예를 둡니다. 자연 출현 좀비는 잠시 생성된 뒤 정리되는 방식입니다.

다른 몬스터 정리 규칙은 유지합니다. 바닐라의 햇빛 화상·사망·평화로움 난이도·거리 소멸 등 기본 게임 동작을 무효화하지는 않습니다.

## 검증

Node.js 24·Python 3.12. 외부 패키지·서비스·비밀값은 필요 없습니다.

```sh
python3 checks/validate.py .
node tools/build_monster_balance.mjs --check
node --experimental-vm-modules checks/integration.mjs . --gameplay-only-wings
for suite in integration worldUnlock behavior balance world rebalance frost holyOrb vitality dragonSnow statInput wings townMuda; do
 node --experimental-vm-modules "checks/$suite.mjs" . || exit "$?"
done
python3 tools/package.py /tmp/rpg-release
```

13개 모의 API 테스트 묶음, 본체 단독 날개 등록, JSON·JS/import, 몬스터 컴포넌트 및 배포 ZIP 검사를 통과했습니다.

- 공용 주택과 개인 토지에서 수평 일반/끈끈이 피스톤 설치 허용, 바닥으로 향하는 헤드 거부.
- 미구매 집 수정 허용·바닥 보호·구매 후 권한 제한·해제 후 공용 복구.
- 실제 관리자 메뉴의 대상 선택 → 지정 → 해제, 일반 사용자 거부, 확인 후 권한 상실/위치 변경 거부, 저장 오류 복구.
- 외부 자연 출현 → 마을 이동 → 마을/동굴/평화/아침 정리에서 유지, 마을 내부 자연 출현 제거, 출현 뒤 소환알 이벤트 처리, 로드 개체 유지, 다른 몹 구분.

실제 Minecraft 클라이언트·서버 실행·피스톤 물리·스폰 원인 이벤트·모바일 UI는 미검증입니다.
