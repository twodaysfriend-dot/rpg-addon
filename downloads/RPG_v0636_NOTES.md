# RPG v0.6.36 · 야수 도발·공격 강화·기도·성수

Bedrock 1.21.100 이상. RPG BP·Commands BP·RP 세 팩을 모두 v0.6.36으로 활성화하고 월드를 다시 여세요. 기존 팩 UUID와 월드 데이터를 유지하며 v0.6.35의 엔드·수중 출현·주민 할인·습격 수정도 포함합니다.

## 야수

- **도발 추가**: 시전 시 같은 차원의 반경 50칸 이내, 현재 로드된 적대 몬스터 전체를 대상으로 30초 동안 시전자를 향해 추적 이동시키며 나약함 II를 30초 부여합니다. 대상 수 제한은 없고 정확히 50칸도 포함합니다. 보스도 나약함은 30초입니다. 플레이어·아군·길들인 동물·소환수는 제외합니다. 마나 80·재사용 30초로 설정했습니다. 기존 야수도 전용 무기를 들면 도발을 자동 습득합니다.
- **내려찍기**: 야수의 최초 기본 물리 피해 30, 띄워진 적이 실제 착지하면 기본 물리 피해 10을 한 번 추가합니다. 천장 때문에 띄우지 못했거나, 상승 정점에서 지상 판정만 남아 있는 경우는 착지 피해를 주지 않습니다. 보스의 최대 띄우기 높이는 기존 절반 정책입니다. 망나니는 기존 최초 피해 18을 유지합니다. 바닐라 낙하 피해를 별도로 무효화하지 않습니다.
- **참수**: 야수의 다음 기본 근접 공격 배율을 ×4에서 **×6**으로 1.5배 강화했습니다. 망나니와 기존 참수 차용 카멜레온은 ×4를 유지합니다. 최대 체력 15% 미만 처형과 한 번 사용 후 소모는 유지합니다.
- **대폭발**: 기본 피해 **70 → 90**. 반경 15칸·1초 준비·지형 비파괴는 유지합니다.
- **화염방사**: **3발 → 5발**, 발당 기본 물리 피해 **15 → 25**. 전탄 적중 시 명목 기본 피해 합계는 125이며 화상은 별도입니다.

피해 수치는 장비·근력·룬·대상 방어 적용 전 기본값입니다. 카멜레온이 학습한 야수 전용 화염방사·대폭발에도 새 기본값이 적용되며 새 도발도 학습 목록에 등록됩니다. 공용 내려찍기·참수의 야수 추가 강화는 실제 야수 직업에만 적용합니다.

도발은 지원되는 이동 impulse로 추적하며 벽 충돌을 검사합니다. 안정판 Script API에는 모든 몹에 대해 공격 대상을 직접 지정하는 기능이 없어 네이티브 공격 대상 변경이나 복잡한 지형의 완전한 길찾기를 보장하지 않습니다. 시전자 사망·접속 종료·차원 변경·도발 사용 불가 직업 변경·시간 만료 시 추적이 끝납니다. 약화 효과는 이미 부여한 30초의 엔진 효과로 남습니다. 새 도발이 같은 대상에 적용되면 가장 최근 시전자를 따릅니다.

## 기도·성수

- **기도 보상 2배**: 성직자 **2개**, 천사 **4개**, 미카엘 **6개**의 축복의 빛을 받습니다. 기도 10초·게임 날짜 하루 1회 제한은 유지합니다. 아군 치유 누적 보상의 개수는 변경하지 않았습니다.
- **성수**: 사용을 완료하면 **힘 III·저항 II를 120초(2400틱)** 부여합니다. 기존 디버프 제거와 재생 II 10초를 유지하며 모든 직업이 사용할 수 있습니다.
- 게임 내 스킬 안내와 성수 효과 안내도 갱신했습니다.
