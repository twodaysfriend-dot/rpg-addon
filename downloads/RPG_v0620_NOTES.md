# RPG v0.6.20

Bedrock 1.21.100 이상. RPG BP·Commands BP·RP 세 팩을 모두 v0.6.20로 적용하세요.

## 마을 건축 보호

생성된 250×250 마을에서는 집 26곳의 건물 부지 안에서만 블록 설치·파괴를 허용합니다. 집 바닥 높이부터 위로 16블록까지 리모델링할 수 있습니다. 집 밖의 성·성벽·탑·광장·도로와 마을 지하는 보호합니다. 마을 안 금블록은 집 구역 안에 있더라도 파괴할 수 없습니다. 마을 밖과 다른 차원에는 이 마을 보호를 적용하지 않습니다.

기존 마을 좌표를 사용하므로 마을 재생성은 필요 없습니다. 보호 구역의 폭발 블록 피해, 양동이·불붙이기 등 블록 변경 도구와 경계를 넘는 피스톤 설치도 제한합니다. 상자 열기 같은 블록을 변경하지 않는 사용은 허용합니다. 크리에이티브도 플레이어 설치·파괴 보호를 따릅니다. 관리자 명령어(/setblock, /fill 등)나 다른 애드온의 직접 월드 수정까지 막는 기능은 아닙니다.

## 무다무다

첨부된 참고 이미지처럼 짙은 윤곽·황금색 관절·하이라이트가 있는 전용 주먹 텍스처를 추가했습니다. 좌우 주먹이 높이와 전방 거리를 달리하며 겹쳐 나타납니다. 타격마다 6개, 기본 8회면 총 48개입니다. 벽 너머에는 표시하지 않습니다. 기존 투신 파동을 무다무다에서는 사용하지 않습니다.

피해·범위·마나·쿨타임·타격 간격은 유지합니다. 기본 8회×6, High한 기분 중 16회 연타 규칙도 유지합니다. v0.6.19의 흡수 회복 절반·룬 등급 성장·근력/마력 피해 증가와 이전 기능을 모두 포함합니다.

## 검증

JSON 557개, JavaScript 206개의 문법·상대 import, 전체 활성 모듈 연결, integration/balance/behavior/world/city 검사와 신규 townMuda 검사를 통과했습니다. 신규 검사는 집 26곳 경계·높이, 금블록·성·성벽·도로, 실제 설치/파괴/상호작용/폭발 이벤트 경로, 무다무다 분기와 황금 주먹 48개·벽 차단·텍스처 연결을 확인합니다. 실제 Minecraft 클라이언트에서 시각 표현과 게임 실행은 미검증입니다.

소스 ZIP을 풀고 Python 3.12, Node.js 24에서 실행합니다. 추가 npm 패키지는 필요 없습니다.

```sh
python3 checks/validate.py .
for suite in integration balance behavior world city townMuda; do
  node --experimental-vm-modules "checks/$suite.mjs" . || exit "$?"
done
```
