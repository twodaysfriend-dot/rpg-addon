# RPG v0.6.35 · 엔드·수중 출현·전직 표시·치료 할인·습격 수정

Bedrock 1.21.100 이상. RPG BP·Commands BP·RP 세 팩을 모두 v0.6.35로 활성화하고 월드를 다시 여세요. 기존 팩 UUID를 유지합니다.

- **엔드 RPG 몹 차단**: 모든 RPG 자연 출현 규칙에 엔드 제외 조건을 추가했습니다. 22개 RPG 전투 몹은 엔드에서 생성·로드·초기 조회 시 제거합니다. 엔드에서 명령·알·던전으로 생성한 해당 RPG 전투 몹도 제거됩니다. 바닐라 엔드 몹과 전직관은 대상이 아닙니다.
- **카멜레온 전직 조건 표시 제거**: 카멜레온일 때 전체 전직 안내 메뉴를 열지 않고, NPC 조건 진행도·실패 메시지·신전의 전직 조건을 숨깁니다. 시련 완료 수에 따른 히든 자동 발견도 적용하지 않습니다. 이미 저장한 발견 기록과 기존 카멜레온 스킬북·차용 기술은 유지합니다. 실제 전직 자격 판정은 기존 조건을 적용합니다.
- **가디언 대신 드라운드**: 가디언 자연 출현 규칙을 차단하고 자연 생성된 일반 가디언은 드라운드로 대체합니다. 드라운드의 해양·강·점적석 동굴 수중 출현 규칙에 지표 출현·밀도 설정을 추가했으며 지상 동굴 제한으로 삭제하지 않습니다. 수중 출현과 밝기·난이도 조건을 유지합니다. 기존 이름 붙인 가디언·소환알·엘더 가디언은 별도 제거하지 않습니다. 기존 마을·평화구역·밤 정리 정책은 드라운드에도 적용됩니다.
- **반복 치료 할인**: 신형 주민의 13개 경제 거래 직업에서 회당 할인 [-25, -20]을 유지하고 최대 누적 할인 한도를 [-125, -100]으로 확장했습니다. 구버전의 네이티브 cured_discount/max_cured_discount 방식을 사용해 최대 5회 누적을 허용합니다. 모든 거래가 매번 내려가는 것은 아니며 최소 가격·거래별 가격 계수·수요는 엔진 규칙을 따릅니다. 기존 거래·번식·AI·좀비 변환 이벤트와 마을 주민 보호는 유지합니다.
- **습격 몹 삭제 방지**: 약탈자·변명자·소환사·파괴수·마녀·벡스를 동굴 전용 제한, 마을 정리, 평화구역, 밤/아침 정리에서 제외했습니다. Script API 생성 원인만으로 습격 웨이브를 확실하게 구분할 수 없어 해당 종 전체를 보존합니다. 따라서 평소 출현한 마녀·순찰대도 이 정리에서 보존됩니다. 바닐라 습격 생성·난이도·게임 규칙은 변경하지 않습니다.
