# RPG v0.6.45 · 용기사 강화·질주 조향·현월수룡

Bedrock 1.21.100 이상. BP·Commands BP·RP 모두 v0.6.45로 활성화하고 월드를 다시 여세요. UUID·아이템 ID·전직/스킬 목록을 유지합니다.

피해는 스탯·룬·강화·힘 효과·적 방어 적용 전 기본값입니다. 질주는 새 적마다 1.5배 증가하므로 28→42→63→94.5…이며 같은 적은 한 번만 타격합니다. 삼조격 외 별도 3타 패시브(추가 물리 10·HP 6 회복)는 유지합니다. 마나·쿨타임·사거리·지속시간은 유지합니다.

## 용의 질주 방향 조정

시선의 수평 방향을 매 틱 읽어 질주 방향을 변경합니다. 초당 21칸·5초·고정 높이 이동을 유지하며 시선을 옆으로 돌리면 경로가 휘어집니다. 위/아래를 수직으로 바라볼 때는 직전 수평 방향을 유지합니다. 처음부터 수직으로만 바라보면 방향 확인 안내 후 발동하지 않습니다.

벽 충돌 검사와 짧은 구간 이동을 유지합니다. 벽·차원 이동·사망·권한/직업 변경·시간 만료 시 종료합니다. 같은 적 중복 타격 방지를 유지합니다.

## 현월수룡

반경 7칸·10초, 시전 위치에 고정되는 기존 영역입니다. 전개 피해 50·매초 10과 끌어당김을 적용합니다. 영역 안의 적 몬스터에게 나약함 II를 5틱마다 짧게 갱신합니다. 플레이어·아군·비몬스터 동물·영역 밖 대상은 이 효과에서 제외합니다. 퇴장 후 마지막 짧은 효과가 자연 만료되며 보스에게는 기존 군중제어 지속시간 절반 규칙이 적용됩니다.

외부에서 진입하는 실제 엔티티 투사체(화살·삼지창 등 minecraft:projectile 컴포넌트)를 매 틱 직접 삭제합니다. 이전 위치→현재 위치와 현재 위치→예측 위치의 선분을 영역과 검사하므로 빠른 투사체가 한 틱에 영역 전체를 통과하는 경우도 처리합니다. 외부 아군이 쏜 투사체도 차단합니다. 내부에서 발사한 투사체·영역을 빗나가는 투사체·일반 엔티티는 유지합니다.

영역은 시전자 사망·접속 종료·다른 차원 이동·시간 만료 시 제거됩니다. 삭제 동작은 optional before-hurt 이벤트에 의존하지 않습니다. 별도 스크립트 타이머/파티클로만 표현되는 기술은 엔티티 투사체 삭제 대상에 포함되지 않습니다.

아군 저항 V는 기존처럼 최초 진입 때 3초간 한 번 부여합니다. 용의 시선 표식의 받는 피해 +30%는 기존 before-hurt 지원 제한이 유지되며 이번 변경 범위가 아닙니다.
