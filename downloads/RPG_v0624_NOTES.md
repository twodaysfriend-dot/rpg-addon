# RPG v0.6.24 · 히든 직업 발견 기록

Bedrock 1.21.100 이상. RPG BP·Commands BP·RP 세 팩을 모두 v0.6.24로 적용하세요.

## 상태창

상태창에서 “전직 안내 / 직업·조건” 버튼을 제거합니다. `/rpg:status`도 다음 전직의 조건·진행도와 공물용 책 진행도를 표시하지 않습니다. 현재 직업·스킬·스탯·HP/MP 등 상태 정보는 유지합니다.

## 히든 직업 조건

`/rpg:jobs`는 일반 직업과 자신이 발견한 히든 직업만 표시합니다. 야수·그림자 암살자·복수귀처럼 히든 시작 직업에서 이어지는 상위 직업도 발견 전에는 숨깁니다. 숨겨진 직업 이름으로 전직 명령어를 시도해도 실패 시 구체적인 조건 대신 탐험 안내만 표시합니다.

발견은 플레이어별 동적 속성에 저장하며 재접속·직업 변경 후에도 유지합니다. 다음 실제 게임 경험으로 발견합니다.

- 해당 전직관과 대화: 해당 전직관이 다루는 직업을 발견합니다. 다른 계열을 모두 해금하지 않습니다.
- 전직 카드 획득: 인벤토리 변경/접속/주기 검사에서 카멜레온·혈술사 카드를 확인하면 해당 직업의 발견 기록을 남깁니다. 전직 자체에는 기존처럼 카드를 손에 들어야 합니다.
- 로토 대화: 해커를 발견합니다. 기존 퀴즈·최초 정답자 규칙은 유지합니다.
- 활성 신전 제단을 직접 방문: 현재 제단에 해당하는 후예만 발견합니다. 멀리서 신전 명령어를 실행해도 미발견 직업의 조건을 공개하지 않습니다.
- 실제 전직 완료: 해당 히든 직업을 기록합니다. 업데이트 전부터 현재 히든 직업인 플레이어도 현재 직업을 아는 것으로 처리합니다.

발견 후 조건·진행도는 해당 전직관이나 `/rpg:jobs`에서 확인합니다. 실제 전직 자격·시련·비용은 바꾸지 않습니다. 조건을 자연스럽게 모두 달성해 직접 전직에 성공하는 경로도 유지합니다. 히든 전직을 공개하지 않던 GPT/룰북 정책은 유지합니다.

v0.6.23의 냉기 개편과 이전 룬·근력·던전 밸런스·마을 보호·황금 주먹 무다무다·스탯 입력 수정 기능을 포함합니다.

## 검증

전체 활성 모듈을 연결한 모의 API에서 상태창 전직 버튼 제거, 상태 명령어의 조건/진행도 제거, 미발견 히든 직업과 상위 직업 목록 제외, 이름을 추측한 명령어의 조건 비공개, 실제 NPC 대화 후 해당 직업만 표시, 플레이어별 독립·저장 복원·직업 변경 유지·기존 현재 직업 호환을 검사했습니다. 원격 신전 명령의 비공개와 제단 방문 발견, 로토 발견, 카드 획득 후 카드가 없어져도 발견 유지 및 전직 시 손에 들기 조건 유지도 확인했습니다.

```sh
python3 checks/validate.py .
for suite in integration behavior balance world rebalance frost statInput; do
 node --experimental-vm-modules "checks/$suite.mjs" . || exit "$?"
done
```

Python 3.12·Node.js 24 사용. 실제 Minecraft 클라이언트 실행은 미검증입니다.
