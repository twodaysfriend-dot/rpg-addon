# RPG v0.6.38 · 언데드 방어·전직 최대 마나 보존

Bedrock 1.21.100 이상. RPG BP·Commands BP·RP 세 팩을 모두 v0.6.38로 활성화하고 월드를 다시 여세요. UUID와 기존 데이터를 유지하며 v0.6.37의 미카엘 스킬과 이전 수정 사항을 포함합니다.

## 언데드 종족

- **언데드가 몬스터에게 받는 종족 피해 배율은 0.7배**입니다. 기존에 모든 종족에게 적용되던 공통 0.7배를 언데드 전용으로 변경했습니다. 인간·흡혈귀의 기본 몬스터 피해 배율은 1배입니다.
- 수호 룬과 흡혈귀 햇빛 피해 배율은 별도 적용합니다. 몬스터 자체의 레벨·던전 공격력도 변경하지 않습니다.
- 몬스터가 아닌 플레이어 공격·일반 환경 피해에는 언데드 0.7배를 적용하지 않습니다.
- 복수귀의 종족은 언데드입니다. 돌가면으로 흡혈귀가 되면 언데드 방어가 해제되며, 전직할 때 종족 태그도 즉시 갱신합니다.
- 기본 플레이어·전체 수호 룬 단계의 네이티브 피해 센서와 직접 HP 감소 경로를 함께 처리했습니다. 이미 종족 배율이 적용된 피해의 추가 계산에서는 중복 적용하지 않습니다.

## 전직 최대 마나 수정

원인은 직업에 따라 최대 마나를 매번 재계산하던 방식입니다. 일반 직업은 1000, 마법/성직은 200+기존 책 보너스였으므로 전직 시 최대치가 달라졌습니다.

- 업데이트 후 **처음 계산하는 기존 자연 최대 마나의 기본값을 개인 데이터에 저장**합니다. 새 전직 전에 먼저 이전 직업 값으로 저장하도록 처리했습니다.
- 이후 **일반↔마법↔성직↔히든 전직, 견습 초기화, 재접속에도 최대 마나를 유지**합니다.
- 실제 책 공물 +50, 다이아몬드 블록 +200은 기존처럼 누적됩니다. 새 공물과 기존 책 보너스를 중복 계산하지 않습니다.
- 관리자 고정 최대 마나는 유지하며 reset하면 저장된 자연 기본값+공물 보너스로 돌아옵니다.
- 전직 시 현재 마나를 채우는 기존 동작은 유지합니다. 이번 수정은 최대치 보존입니다.
- 이미 업데이트 전에 사라진 과거 최대 마나를 추정해 복원하지는 않습니다. 최초 이행 시점의 현재 직업·기존 책·공물 값이 기준입니다.

게임 내 언데드 방어와 최대 마나 안내도 추가했습니다.

```sh
set -e

 node --experimental-vm-modules "checks/$suite.mjs" .
done
python3 tools/package.py /workspace/rpg-release/v0638
```
