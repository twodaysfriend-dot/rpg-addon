# RPG v0.6.14

## 250×250 성곽 스폰 마을

관리자 플레이어가 원하는 위치에서 한 번 실행하세요.

```mcfunction
/rpg:citycreate
```

이제 **명령어를 실행한 플레이어의 X/Z 좌표를 중심**으로 정확히 250×250 범위에 만듭니다. 월드 기본 스폰 좌표를 기준으로 생성하던 방식을 바꿨습니다. 성채·성벽·네 방향 문·광장·분수·건물 26동과 전직관 8명을 포함합니다.

기본 바닥은 실행자 발밑 높이를 기준으로 정합니다. 전체 공간 검사에서 더 높은 지형·기존 건물이 발견되면 이를 보존하도록 바닥을 위로 자동 조정합니다. 높이를 직접 정하려면 `/rpg:citycreate 200`처럼 실행하세요. 직접 정한 높이에 건물·지형이 있으면 기존 블록을 보존하며 자동 재시도합니다.

생성·청크 재로딩·일시 오류 재시도·월드 재시작 후 이어짓기는 **재개 명령어 입력 없이 자동 진행**합니다. 실행한 관리자가 나가도 다른 플레이어가 접속 중이면 계속 진행하고, 접속자가 없으면 대기했다가 접속 시 이어집니다. `/rpg:citystatus`로 진행도를 볼 수 있습니다.

`/rpg:citystop`으로 관리자가 명시적으로 중지한 경우에는 중지 상태를 유지합니다. 기존 재개 명령어는 수동 관리용으로 남겨두었습니다. 확인창이나 승인 질문은 없습니다.

### 이전 1000×1000 마을 줄이기

이전 버전 마을의 생성 기록이 있다면, **그 마을 안에서 `/rpg:citycreate`를 실행**하세요. 새 250×250 마을을 만든 후 유지할 범위 밖의 이전 생성 블록을 자동으로 정리합니다. 저장 기록상 건축이 확인되는 범위에서, 해당 마을의 설계와 현재 블록 종류가 일치하는 위치만 제거하고, 종류가 바뀐 블록·물건이 든 상자·유지 범위 안은 남깁니다. 같은 재료로 같은 위치에 다시 놓은 블록은 원래 블록과 구분되지 않을 수 있습니다.

바닥이 제거될 영역의 생존/모험 플레이어는 새 중앙 광장으로 안전하게 이동시킵니다. 새 마을 완성과 외곽 정리는 분할 작업으로 이어지므로 전체 정리가 끝날 때까지 시간이 걸립니다. 기존 마을 생성 기록이 없거나 새 생성 위치가 이전 마을 밖이면 자동 철거하지 않습니다. 미완성 구버전도 기록된 건축 구역까지만 정리하고, 아직 건축한 것으로 확인되지 않는 위치는 보존합니다.

## 스폰 버프

마을의 **250×250 수평 경계 안, 오버월드**에 있는 플레이어에게 다음 효과를 계속 갱신합니다. 높이는 제한하지 않습니다.

- 신속 VI (API 증폭 값 5)
- 야간 투시
- 포화

경계를 벗어나거나 다른 차원으로 이동하면 다음 틱(통상 0.05초)에 스폰이 지급한 효과를 해제합니다. 외부 포션/기술 효과가 있었다면 남은 효과를 보존합니다. 재접속 시에도 경계 밖에서 스폰 효과가 남지 않도록 지급 기록을 관리합니다.

기존 `/rpg:peace`의 몬스터 제거 기능은 유지합니다. 야간 투시·포화 지급은 새 마을 경계에서만 관리하도록 바꾸어, 마을 밖의 평화구역에서 같은 버프가 다시 붙는 것을 막았습니다.

## 카멜레온 더 월드·넨 학습

```mcfunction
/rpg:skillbook
```

학습 메뉴에 **더 월드 6개 기술**, **넨 능력자 10개 기술**을 추가했습니다. 기존 SP·사용 횟수·궁극기·진화 규칙을 그대로 사용합니다. 시간 정지 세션과 넨의 경·주·은·원 후속 효과도 학습한 카멜레온에게 작동하도록 직업 검사를 수정했습니다.

기술을 배우더라도 직업·종족은 카멜레온 상태를 유지합니다. 원래 직업 전용 패시브와 `/rpg:wfly` 상시 비행 권한은 자동으로 추가하지 않습니다. 시간 정지 기술에 포함된 동작은 해당 기술의 지속 시간 동안 적용됩니다.

## 설치와 검증

BP·Commands BP·RP 세 팩을 모두 **v0.6.14**로 활성화하세요. 기존 UUID와 플레이어 데이터를 유지했습니다. 최소 Minecraft Bedrock 1.21.100, Script API server 2.2.0 / server-ui 2.0.0입니다.

v0.6.13의 구욱 외형·이름, 전직 카드, 10단계 던전 생성 수정을 포함해 이전 기능을 유지합니다. 10단계 생성은 `/rpg:dungeoncreate 10`, 대체 명령어는 `/function rpg_dungeon10`입니다.

실제 Minecraft 실행은 이 환경에서 검증하지 못했습니다. 구조·문법·전체 모듈 연결과 다음 모의 API 테스트를 통과했습니다: 250×250 전체 생성, 현재 좌표 중심 배치, 자동 높이·오류 재시도·재접속/재시작 자동 진행, 이전 외곽 정리와 상자·변경 블록 보존, 스폰 효과 지속/즉시 경계 해제/외부 효과 보존, 더 월드·넨 실제 SP 학습과 발동, 기존 무기·종족·상점·던전 회귀 검사.

소스 ZIP을 풀고 Python 3 및 Node.js 24에서 실행:

```sh
python3 checks/validate.py .
node --experimental-vm-modules checks/behavior.mjs .
node --experimental-vm-modules checks/integration.mjs .
node --experimental-vm-modules checks/dungeons.mjs .
node --experimental-vm-modules checks/city.mjs .
node --experimental-vm-modules checks/spawnEffects.mjs .
```
