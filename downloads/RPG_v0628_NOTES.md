# RPG v0.6.28 · 날개 속도·전직 조건 공개·회복 보상·메뉴 이동·가방 무기 강화

Bedrock 1.21.100 이상. RPG BP·Commands BP·RP 세 팩을 모두 v0.6.28로 활성화하세요. 기존 팩 UUID를 유지하여 업데이트합니다. v0.6.27의 기능·밸런스를 포함합니다.

- 천사·미카엘: `/wings 1` 기본, `/wings 2` 2배, `/wings 3` 5배. `/rpg:wings 1|2|3`도 지원합니다. 네임스페이스 없는 별칭을 지원하지 않는 엔진에서는 `/rpg:wings`를 사용하세요. 인자 없이 실행하면 기존 날개 켜기·끄기입니다. 속도 설정은 개인별로 저장되며 날개를 끄지 않습니다. 날개 장착 후 더블 점프로 비행을 시작합니다. 타락 계열은 기존 속도를 유지합니다.
- 상태창 → 전직 방법: 히든 직업별 시련 항목을 2개 이상 완료하면 해당 직업의 전체 조건과 진행도가 공개되고 발견 기록이 유지됩니다. 레벨 항목도 1개 조건으로 계산합니다. `또는` 묶음은 1개 조건입니다. 조건 공개는 전직 허용과 별개이며 남은 조건·직전 직업 요건은 그대로 적용합니다. 기존 전직관·아이템 발견도 유지됩니다. 단일 카드 방식 직업은 기존 발견 방식을 유지합니다.
- 성직자·천사·미카엘: 아군에게 실제 회복한 HP가 누적 300이 될 때마다 축복의 빛 1개. 초과분 이월, 다량 회복은 여러 개 지급합니다. 자신 회복·초과 회복·크리에이티브/관전자 회복은 보상에서 제외합니다. 가방이 가득 차면 보관 후 공간이 생기면 자동 지급합니다. 천사의 기존 누적 기록도 유지합니다.
- 상태창 → 스폰으로 이동: 개인 침대가 아닌 월드 스폰(오버월드)으로 무료 이동합니다.
- 상태창 → 길드 확인 → 길드 기지로 이동: 길드장이 먼저 `현재 위치를 길드 기지로 설정`을 선택합니다. 기지 차원·좌표는 길드 데이터에 저장되며 현재 길드원만 무료 이동할 수 있습니다. 건축물을 자동 생성하지 않습니다.
- 스폰·길드 기지 이동은 던전·결투·시간 정지·사망 중 차단되며 착지 위치가 막혀 있으면 엔진의 충돌 검사를 적용합니다.
- 강화 → 무기 강화: 가방의 공통 무기를 슬롯 번호·이름·강화 단계로 골라 강화합니다. 손에 들 필요가 없습니다. 직업 전용 무기는 기존처럼 주 손에서 강화합니다. 확인 중 장비가 바뀌면 비용을 차감하지 않습니다. 기존 확률·촉매·파괴·환불 규칙을 유지합니다.

## 개발 및 검증

Node.js 24, Python 3.12. 외부 npm 패키지·서비스·비밀값은 필요 없습니다. 소스 ZIP을 별도 작업 디렉터리에 풀어 사용하세요.

```sh
python3 checks/validate.py .
node tools/build_monster_balance.mjs --check
for suite in integration worldUnlock behavior balance world rebalance frost holyOrb vitality dragonSnow statInput wings; do
 node --experimental-vm-modules "checks/$suite.mjs" . || exit "$?"
done
python3 tools/package.py /tmp/rpg-release
```

JSON·JavaScript 구문·상대 import, 1430개 몬스터 컴포넌트 그룹, 위 12개 모의 API 테스트 묶음과 배포 ZIP 무결성 검사를 통과했습니다. 실제 게임 API의 더블 점프 이벤트를 모의하여 1/2/5배 비행 제어, 전직 조건 1→2개 경계·미충족 전직 거부, 3직업 회복량/잔여분/가방 가득 참 지급, 스폰·길드 기지 이동·권한·던전 탈출 방지, 손에 들지 않은 공통 무기 강화·변경 감지·저장 실패 환불을 확인했습니다.

실제 Minecraft 클라이언트·서버 실행, 고속 비행의 실제 체감 속도·청크 로딩·게임 내 메뉴 표시·차원 이동은 미검증입니다. 비행 배율은 기존 목표 속도와 제어 한도에 적용되며 게임 물리·충돌에 따라 실제 이동 거리는 달라질 수 있습니다.
