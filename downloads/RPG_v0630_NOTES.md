# RPG v0.6.30 · 날개 명령어 본체 등록·마나 공물

Bedrock 1.21.100 이상. RPG BP·Commands BP·RP 세 팩을 모두 v0.6.30로 활성화하고 월드를 완전히 나갔다 다시 여세요. 기존 UUID와 v0.6.29의 기능·저장 데이터를 유지합니다.

## 날개 속도

사용자 화면에서 `/wings 3`과 `/rpg:wings 3` 모두 숫자 3에서 구문 오류가 나는 것을 확인했습니다. 화면은 명령어 이름을 인식하고 인자를 거부하는 증거이며, 실제 적용된 명령어 등록/게임 런타임 상태를 이 환경에서 확인할 수 없어 정확한 엔진 원인은 확정하지 못했습니다. 앞선 네임스페이스 변경만으로 충분하다는 설명을 바로잡습니다.

v0.6.30은 RPG 본체의 실제 gameplayEntry에서 날개 명령어를 직접 등록합니다. Commands BP·기존 bootstrap·core 명령어 파일의 날개 등록은 제거하여 본체가 단독 소유합니다. 숫자는 문자열 대신 정수형 선택 인자로 등록하고 스크립트 이벤트 중계를 거치지 않고 실행합니다.

- `/rpg:wings 1`: 기본, `/rpg:wings 2`: 2배, `/rpg:wings 3`: 5배.
- **인자 없는 대체 명령어** `/rpg:wings1`, `/rpg:wings2`, `/rpg:wings3`: 각각 기본·2배·5배. 숫자 인자 구문 오류가 계속되면 이 경로를 사용하세요.
- **상태창 → 날개 비행속도 → 기본/2배/5배**로도 설정할 수 있습니다.
- `/rpg:wings`: 기존 날개 켜기·끄기. `/rpg:wingspeed`: 속도 메뉴, `/rpg:wingspeed 3`: 5배.
- 천사·미카엘 전용입니다. 날개를 장착하고 더블 점프로 비행합니다. 설정은 개인별로 저장하며 날개를 켜거나 끄지 않습니다. 타락 계열 속도는 유지합니다.
- 성공 메시지에 `[날개 v0.6.30] 비행속도: 5배`가 표시됩니다. `/rpg:wingcheck`에서도 버전·속도를 확인할 수 있습니다.

## 마나 공물

`/rpg:offer` 사용 시 가방의 **일반 책·효과부여 책은 1권당 최대 마나 +50**, **다이아몬드 블록은 1개당 최대 마나 +200**입니다. 모든 직업에 적용합니다. 해당 재료는 가방에서 전량 소비되므로 남길 재료는 미리 상자에 보관하세요. 증가는 영구 저장되며 직업 변경 후에도 유지됩니다. 현재 마나도 최대 마나 증가분만큼 올려 기존 마나 부족량을 유지합니다.

예: 책 2권·다이아몬드 블록 3개를 바치면 최대 마나 +700. 효과부여 책은 기존 전직 시련 진행도에도 인정되며 같은 책을 두 번 소비하지 않습니다. 일반 책은 효과부여 책 전직 시련으로 인정하지 않습니다. 검·기존 추가 공물의 시련은 유지합니다.

이전 버전의 책으로 얻은 마나는 그대로 유지하고, 이번 버전부터 실제 소비한 책·블록에 새 수치를 적용합니다. 직업별 기존 책 시련 한도를 채워도 마나 공물은 계속 바칠 수 있습니다. 관리자 고정 최대 마나가 설정된 경우에는 재료를 소비하지 않고 `/rpg:setmana reset` 안내를 표시합니다. 저장 실패 시 아이템·진행도·현재 마나를 복구합니다.

전직 조건 2개 달성 공개, 성직자·천사·미카엘의 아군 회복 300 HP마다 축복의 빛 지급, 스폰·길드 기지 이동, 가방 공통 무기 강화 및 이전 기능을 포함합니다.

## 개발·검증

Node.js 24·Python 3.12. 외부 패키지·비밀값·서비스는 필요 없습니다.

```sh
python3 checks/validate.py .
node tools/build_monster_balance.mjs --check
node --experimental-vm-modules checks/integration.mjs . --gameplay-only-wings
for suite in integration worldUnlock behavior balance world rebalance frost holyOrb vitality dragonSnow statInput wings; do
 node --experimental-vm-modules "checks/$suite.mjs" . || exit "$?"
done
python3 tools/package.py /tmp/rpg-release
```

12개 모의 API 테스트 묶음 및 별도 본체 단독 날개 등록 실행, JSON·JS 구문/import, 1430개 몬스터 컴포넌트 그룹, 배포 ZIP 검사 통과. Commands BP와 legacy bootstrap을 로드하지 않고도 본체에서 명령어 5개가 등록되고 속도가 바뀌는 것을 검사했습니다. 전체 그래프에서도 각 날개 명령어의 등록이 정확히 1개임을 확인했습니다. 정수형·인자 없는 속도 변경·기존 비행 제어 1/2/5배·메뉴 선택을 검사했습니다.

마나 공물은 5종 직업에서 일반/효과부여 책 +50·블록 +200, 최대/현재 마나, 기존 기록 보존·전직 시련 중복 소비 방지, 재접속 데이터·재실행·직업 변경, 가방·진행도·마나 저장 실패 복구, 관리자 고정값 중 재료 보존과 해제 후 재시도를 검사했습니다.

실제 Minecraft 클라이언트·서버는 이 환경에 없어 네이티브 명령어 구문 분석·게임 내 메뉴·물리 동작은 미검증입니다.
