# RPG v0.6.32 · 길드·파티 부동산 공동 건축

Bedrock 1.21.100 이상. RPG BP·Commands BP·RP 세 팩을 모두 v0.6.32로 활성화하고 월드를 다시 여세요. 기존 팩 UUID와 부동산 저장 형식을 유지하므로 구매한 청크를 다시 살 필요가 없습니다.

## 건축 권한

구매자 본인 외에도 **구매자와 현재 같은 길드 또는 같은 파티인 플레이어**는 해당 청크의 마을 바닥 위에서 블록을 설치·파괴할 수 있습니다. 길드·파티 중 하나만 같아도 허용합니다. 소유권은 구매자에게 그대로 남습니다.

- 구매자가 오프라인이어도 저장된 현재 길드·파티 명단으로 권한을 판단합니다.
- 가입 후 권한이 적용되고, 탈퇴·추방·해산으로 같은 그룹이 아니게 되면 다음 수정 시도부터 거부합니다. 청크 구매 당시의 그룹에 권한을 고정하지 않습니다.
- 초대만 받은 상태나 수동 팀/길드 태그는 건축 권한을 주지 않습니다. 다른 길드·파티의 플레이어와 미가입자는 계속 수정할 수 없습니다.
- **마을 바닥 Y 좌표와 그 아래는 구매자·같은 길드·같은 파티 모두 파괴할 수 없습니다.** 허용된 사용자는 바닥 윗면에 블록을 올릴 수 있습니다. 인접 미구매 청크는 계속 보호합니다.
- 구매권 확인창에 공동 건축 안내를 표시하고, 구매권을 들었을 때 소유자와 본인의 `수정 가능/불가`를 표시합니다.

v0.6.31의 다이아몬드 5개당 마을 1청크 구매, 청크 테두리, 마법사 계열 기본 마나 절반, 선택 평타 1초·피해 0.8배, 상태창 9개 분류 버튼과 v0.6.30의 날개 속도·마나 공물 등 이전 기능을 유지합니다. 부동산 구매·평타·분류 사용법은 이전 버전과 같습니다.

## 개발·검증

Node.js 24·Python 3.12. 외부 패키지·서비스·비밀값은 필요 없습니다.

```sh
python3 checks/validate.py .
node tools/build_monster_balance.mjs --check
node --experimental-vm-modules checks/integration.mjs . --gameplay-only-wings
for suite in integration worldUnlock behavior balance world rebalance frost holyOrb vitality dragonSnow statInput wings townMuda; do
 node --experimental-vm-modules "checks/$suite.mjs" . || exit "$?"
done
python3 tools/package.py /tmp/rpg-release
```

13개 모의 API 테스트 묶음, 본체 단독 날개 명령어, JSON·JS/import, 몬스터 컴포넌트 및 배포 ZIP 검사를 통과했습니다. 공동 건축 검사는 저장된 길드/파티 명단, 오프라인 구매자, 길드만 같은 사람·파티만 같은 사람의 허용, 다른 길드·위조 태그 거부, 실제 길드/파티 탈퇴 UI 실행 후 권한 즉시 회수, 구매자 소유권 유지, 바닥·지하 보호와 바닥 위 설치를 확인했습니다. 기존 부동산 구매·환불·보호·마법사·상태창 테스트도 통과했습니다.

실제 Minecraft 클라이언트·서버 실행 및 네이티브 건축 보호·입자·모바일 입력·메뉴 표시·게임 물리는 미검증입니다.
