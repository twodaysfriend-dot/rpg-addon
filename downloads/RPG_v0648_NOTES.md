# RPG v0.6.48 · PK 누적 감옥 시스템

Bedrock 1.21.100 이상. BP·Commands BP·RP 모두 v0.6.48로 활성화하고 월드를 다시 여세요. 팩 UUID·아이템 ID·기존 스탯/장비를 유지합니다.

## 관리자가 먼저 감옥을 설치하세요

오버월드의 넓고 빈 평지에서 **/rpg:jailcreate**를 실행하세요. 선택적으로 **/rpg:jailcreate 64**처럼 바닥 Y를 지정할 수 있습니다. 현재 위치에서 X/Z 양의 방향으로 각각 5칸 떨어진 곳에 약 21×12·높이 5칸 범위의 시설을 배치합니다. 10개 감옥 내부는 각각 가로1×세로1, 천장까지 여유 높이3칸입니다. 기반암 바닥/지붕과 철창 벽, 대기/석방용 발판을 만듭니다.

기존 건물·상자·공중 블록과 겹치면 건축 전 검사에서 중단합니다. 바닥의 잔디/흙/모래/자갈만 교체할 수 있습니다. 블록 기록 중 실패하면 이번에 기록한 블록을 되돌립니다. 한 번 설치되면 /jailcreate 재실행으로 다른 위치에 중복 생성하지 않습니다. 시설은 생존 플레이어의 블록 변경·피스톤·폭발로부터 보호하며 관리자는 수정할 수 있습니다. 청크 유지를 위해 tickingarea 1개를 사용합니다.

## PK 스택·형기

- 기존 비합의 PK 판정에 연결합니다. 합의된 결투, 결투 직후 기존 유예, PK 표식 대상의 정당한 현상금 처치는 새 감옥 스택에서 제외됩니다.
- PK 1회마다 스택 +1, 세 번째에 수감 처분이 생기고 스택을 **0**으로 초기화합니다. 현재 수감/처분 대기 중에는 새 수감 처분을 중복 생성하지 않습니다.
- **첫 수감 5분 → 두 번째 10분 → 세 번째 20분 → 네 번째 40분…**. 수감 횟수와 남은 시간은 월드에 저장하며 접속 종료/재시작으로 초기화되지 않습니다. 큰 수에서도 형기를 임의 상한으로 자르거나 오버플로로 줄이지 않도록 정수 문자열로 보관합니다.
- 기존 PK 표식·현상금은 유지합니다. 감옥 스택은 이 버전부터 새로 집계하며 과거 PK 킬 수를 소급 합산하지 않습니다.
- 감옥이 아직 설치되지 않았다면 처분을 보관하고 형기를 차감하지 않습니다. 관리자가 생성하면 온라인 대상부터 수감합니다.

## 이탈·TPA·접속 종료 방지

각 플레이어에게 감옥 한 칸을 배정합니다. 지정 칸의 X/Z 한 블록 범위를 벗어나거나 다른 차원으로 이동하면 원래 칸으로 되돌립니다. 감옥 밖으로 한 칸만 이동해도 그동안 남은 시간은 줄지 않습니다.

형기는 감옥 내부에 연속해서 있는 게임 틱만 차감합니다. **6000틱=20TPS 기준 5분**이며 서버 틱이 느려지면 실제 시계상 더 길 수 있습니다. 밖으로 이동/재이동한 틱, 사망/리스폰 대기, 미접속, 빈 감옥 대기에는 차감하지 않습니다.

수감자와 수감 대기자를 대상으로 한 TPA 요청/수락은 양방향으로 차단합니다. 요청을 보낸 뒤 수감된 경우도 수락 시 다시 검사해 이동/골드 차감하지 않습니다. 스킬 발동과 이동 스킬 텔레포트, 결투·던전 입장을 차단합니다. 이미 진행 중이던 결투/던전 복귀 상태는 정리하여 감옥과 서로 텔레포트 경쟁하지 않게 합니다. 외부 /tp·포털·아이템 이동으로 위치가 바뀌어도 감옥 감시가 되돌립니다.

10칸이 모두 사용 중이면 처분은 대기열에 보관하고 대기 발판에서 위치를 제한합니다. 대기 시간은 형기에 포함하지 않습니다. 접속 종료한 수감자는 칸을 비우지만 남은 형기를 보존하고, 재접속 때 빈 칸을 다시 배정합니다. 빈 칸이 없으면 대기합니다.

## 명령어

| 명령 | 권한·기능 |
|---|---|
| /rpg:jail | 누구나 자신의 PK 스택·수감 횟수·남은 형기 확인 |
| /rpg:jailcreate [바닥Y] | 관리자: 감옥 10칸 설치 |
| /rpg:jailstatus [플레이어이름] | 관리자: 설치 좌표·전체 수감/대기자 또는 지정 기록 확인 |
| /rpg:jailrelease 플레이어이름 | 관리자: 즉시 석방. 반복 수감 배율은 유지 |
| /rpg:jailreset 플레이어이름 | 관리자: PK 스택/수감 횟수 초기화. 수감 중이면 남은 시간을 5분으로, 다음 수감도 5분으로 복원 |

이름에 공백이 있으면 따옴표로 감싸세요. 접속 종료 상태의 플레이어도 저장된 이름으로 석방/초기화할 수 있습니다. 오프라인 석방은 다음 접속 때 실제 감옥 출구로 이동합니다. 출구가 막혀 이동에 실패하면 석방 이동을 재시도하므로 관리자에게 출구를 확인받으세요.

수감 시간 만료 시 자동으로 석방 발판으로 이동합니다. 기존 /rpg:pkclear는 PK 표식/현상금 해제용이며 감옥 석방/형기 초기화와 별개입니다.

## 검증·변경 범위

새 감옥 테스트는 다음을 검사합니다.

- 10칸·각1×1·독립 칸 배정, 기존 블록/상자 보존, 건축 실패 롤백과 구조물 보호.
- PK 1/2/3스택, 수감 때0 초기화, 5/10/20분과 큰 수 반복 배율, 관리자 권한/석방/현재 및 다음5분 초기화.
- 1칸 이탈·다른 차원·사망·접속 종료·월드 재시작의 시간 차감 방지, 오프라인 석방 후 물리적 출구 이동.
- 11명 동시 처분의 빈 칸 대기, 접속 종료 시 칸 반환과 재배정.
- 실제 PvP 사망 경로의 중복 이벤트 방지, 합의된 결투/현상금 제외, 오프라인 간접 PK 기록.
- TPA 양방향/수락 직전 수감 재검사·골드 보존, 스킬/던전 이동 차단과 던전/결투장 복귀 충돌 방지.
- 두 명령 등록 팩의 관리자 권한과 위조 스크립트 이벤트 거절.

몬스터/던전/보스 수치·피해 감소·용기사 패시브/조향/스킬·이전 미사용 데이터 정리는 유지합니다. 기존 16개 회귀 묶음과 마을·던전·장비/종족/부활 검사도 실행합니다.
