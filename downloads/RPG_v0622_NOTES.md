# RPG v0.6.22

Bedrock 1.21.100 이상. RPG BP·Commands BP·RP 세 팩을 모두 v0.6.22로 적용하세요.

## 플레이어 피해 조정

- 힘·비전 룬은 기본 피해 100%를 증폭하지 않고 **추가 피해 부분에만** 등급 배율을 적용합니다. 그 추가 피해와 +8/+10 추가 피해 효과를 60% 줄여 기존 계수의 40%로 적용합니다. 룬 등급은 일반→레어→에픽→고대→영웅→전설→신화이며 추가 효과에 1.5배씩 누적합니다.
- 힘/비전 룬 일반 +0은 +6.8%, 일반 +10은 +20.4%. 레어 +0은 +10.2%, 레어 +10은 +30.6%. 이 수정은 룬이 일반 공격에 주던 추가 피해에도 적용합니다. 생명·수호·샘·흡수의 수치와 상태 효과는 이번 변경 대상이 아닙니다.
- 근력의 포인트당 물리 피해 증가율은 **11.76% → 4.704%**로 60% 낮춥니다. 초기 근력 5를 초과한 투자량에 적용합니다. 이번 요청에서 지정한 근력만 변경하며 마력·체력·지능 계수는 유지합니다.
- 섬멸 기본 피해는 **52 → 41**로 조정합니다. 범위·단발 판정·마나·5초 쿨타임은 유지합니다.

**기준 피해**: 근력 25·레어 힘의 룬 +0·카멜레온 무기 +6, 다른 장비·힘 효과·초월 없음.

`41 × (1 + 20 × 0.04704) × 1.102 × 1.12 = 98.211932672`

방어 없는 대상에게 약 **98.2**입니다. 실제 적의 방어·보스 약점이나 다른 버프가 있으면 표시 피해가 달라집니다. 근력 40·레어 힘의 룬 +10·같은 무기 +6이면 방어 적용 전 **158.709**입니다.

## 야생 몬스터

레벨이 적용되는 RPG 몬스터 22종의 야생 체력·공격력을 같은 레벨의 이전 수치보다 약 **10% 낮춥니다**. 레벨당 방어 증가도 0.004 → 0.0036으로 소폭 완화합니다. 레벨 분포·경험치·보상은 유지합니다. 일반 바닐라 몬스터의 기본 데이터는 변경하지 않습니다.

기존 야생 몬스터는 로드 시 새 레벨 수치를 다시 적용하고 현재 체력 비율을 보존합니다. 업데이트로 전부 회복되지 않습니다. 던전·길들인 몹·강령술 소환물은 이 야생 갱신에서 제외합니다.

## 던전 강화

1단계의 몬스터 수치는 유지합니다. 2단계부터 야생 약화와 분리된 전용 체력·공격력·방어 계산을 적용합니다. 기존 런의 공통 스케일만 적용되어 단계 배율이 빠지던 경로를 정리해 실제 생성되는 몬스터와 스크립트 보스 공격에도 단계 배율이 반영되게 했습니다. 입장 장비 제한을 추가하지 않습니다.

| 단계 | 체력 배율¹ | 공격 배율¹ | 추가 방어 계수² |
|---|---:|---:|---:|
| 1 | 1.0 | 1.00 | 1.00 |
| 2 | 3.0 | 1.35 | 1.00 |
| 3 | 3.2 | 1.50 | 1.04 |
| 4 | 3.4 | 1.65 | 1.08 |
| 5 | 3.6 | 1.80 | 1.12 |
| 6 | 3.8 | 2.00 | 1.16 |
| 7 | 4.0 | 2.20 | 1.20 |
| 8 | 4.2 | 2.40 | 1.24 |
| 9 | 4.4 | 2.65 | 1.28 |
| 10 | 4.6 | 2.90 | 1.32 |

¹ 레벨 보정에 추가로 곱합니다. 2단계 이상 엘리트는 체력 ×1.35, 보스는 체력 ×2를 더 적용합니다. 각 단계의 적 종류·레벨도 기존처럼 올라갑니다.
² 레벨 방어 계산 후 들어오는 피해를 해당 계수로 나눕니다.

**2단계 솔로 기준**: 근력 40·레어 힘의 룬 +10·무기 +6, 방어구와 회복 수단 준비를 권장합니다. 2단계 보스는 HP **8,514**, 기본 근접 공격 설정 **31.02**이며, 실제 플레이어 피해에는 방어구·레벨·수호·공통 몬스터 피해 보정 등이 적용됩니다.

공격력 기준 모델은 무기 평타 초당 1회와 섬멸 5초마다 1회, 공격 가능한 시간 70%, 다른 스킬·초월·버프 없이 계산했습니다. 기준 장비의 보스 처치 예상은 **248.6초**, 근력 25·레어 +0 장비는 **363.9초**로 솔로 보스 제한 **270초**를 넘습니다. 근력 40·레어 +10에서 여유가 적도록 맞춘 수치 기준이며, 실제 솔로 가능 여부를 보장하는 게임 플레이 검증은 아닙니다. 마나·회피·생존·다른 기술 조합에 따라 결과가 달라집니다. 일반/엘리트 50+5마리와 보스 1마리, 솔로/파티 제한 시간·입장·보상 규칙은 유지합니다.

## 검증과 재생성

모의 API에서 실제 카멜레온 스킬 입력부터 섬멸 타격까지 연결해 **한 대상에게 정확히 한 번 98.212 피해**와 기존 쿨타임을 확인했습니다. 22종의 야생·던전 컴포넌트 그룹 1,430개를 실제 JSON과 런타임 방어/보스 공격 계산으로 대조했습니다. 야생 갱신의 체력 비율 보존·중복 적용 방지와 던전 제외도 검사했습니다.

생성 스크립트는 기본 몬스터 데이터를 바꾸지 않고 레벨·던전 컴포넌트 그룹만 갱신합니다.

```sh
node tools/build_monster_balance.mjs --check
# 수치 설정을 수정했을 때만 다시 생성:
# node tools/build_monster_balance.mjs
python3 checks/validate.py .
for suite in integration balance behavior world dungeons city townMuda statInput rebalance; do
  node --experimental-vm-modules "checks/$suite.mjs" . || exit "$?"
done
```

Python 3.12·Node.js 24 사용, 추가 npm 패키지 불필요. 기존 마을 보호·황금 주먹 무다무다·스탯 입력 경고 제거 등 이전 기능 포함. 실제 Minecraft 클라이언트 실행과 실제 던전 클리어 난이도는 미검증입니다.
