# RPG v0.6.15

## 혈술사 전직관·전직 카드

혈술사 전직관에 첨부한 금발·검은색/금색 의상 이미지를 기준으로 재구성한 128×128 스킨과 표준 인간형 UV 모델을 적용했습니다. 원본 PNG의 바이트 복사본은 아닙니다. 기존 혈술사 전직관도 새 외형을 사용합니다.

카드는 카멜레온 카드와 같은 방식입니다.

- 크리에이티브 목록에서 **혈술사 전직 카드**를 꺼냅니다. 식별자: `rpg:blood_job_card`.
- 제작법·드롭·생존 자동 지급은 없습니다.
- 실제 주 손에 카드를 들고 혈술사 전직관과 대화하거나 전직 메뉴를 사용합니다. 인벤토리에만 있으면 인정하지 않습니다.
- 카드 소지가 기존 레벨 15·적 80회 처치 조건을 대체합니다. 견습에서도 카드로 전직할 수 있습니다.
- 카드는 전직 시 소비하지 않습니다. 확인창을 여는 동안 카드를 내려놓으면 전직하지 않습니다.
- 전직관은 `/rpg:hito 혈술사`로 소환알을 받아 배치할 수 있습니다.

## 흡혈 우클릭 자동 선택

더 월드의 **흡혈**을 우클릭/사용 버튼으로 발동하면 주변 **6칸**에서 시간 정지 강화 대상 몬스터를 찾아 가장 가까운 적에게 자동 사용합니다. 시선 뒤쪽도 검색하며 벽 너머·아군·죽은 몹·범위 밖은 제외합니다.

대상은 기존과 같은 보스, 데스웜/엘리트 데스웜, 고블린 대장/엘리트 고블린 대장입니다. 해당 몹이 없으면 기존처럼 전방의 근접 적을 선택합니다. 좌클릭으로 직접 맞힌 유효 대상이 있으면 그 대상을 우선합니다.

기본 피해 12·HP 8 회복, 재생 II 10초·저항 II 30초, MP 60·쿨 30초는 유지합니다. 대상이 없으면 기존 자기 강화만 적용합니다. 대상 피해가 실패하면 HP 8 회복과 시간 연장 강화는 주지 않습니다.

## 시간 정지 숙련도

- **첫 성공 시전: 기본 1초**
- 성공적으로 사용할 때마다 숙련도 +1, **다음 시전 기본 시간 +0.1초**
- **50회 숙련 후 기본 최대 6초**
- 숙련도는 플레이어에게 저장되어 재접속·전직·재학습 후에도 유지합니다.
- 권한 없는 사용, 이미 정지 중인 중복 사용, 시전 실패는 숙련도를 올리지 않습니다.
- 대상 몹이 없어도 정상적으로 기술을 사용했으면 숙련도가 오릅니다. 기존 MP·쿨타임은 사용합니다.

별도 과거 사용 기록이 없던 기존 캐릭터도 이 버전의 최초 기록은 0/50, 첫 정지는 1초부터 시작합니다. 성공 회수는 최대 숙련도 50까지 저장합니다.

## 흡혈 강화: 현재 숙련 시간 +50%

지정 몬스터에게 흡혈이 성공하면 **60초 안에 사용하는 다음 시간 정지 1회**가 현재 숙련 시간의 **1.5배**가 됩니다.

| 기본 시간 | 흡혈 강화 시간 |
|---|---|
| 1초 | 1.5초 |
| 2초 | 3초 |
| 4초 | 6초 |
| 6초 | 9초 |

흡혈을 여러 번 해도 배율은 중첩하지 않고 강화 유효 시간만 갱신합니다. 성공적인 시간 정지 시 강화 1회를 소비합니다. 실패하면 숙련도와 강화 상태를 복구합니다. 기존 보스의 정지 시간 절반 규칙은 유지합니다.

현재 숙련도와 기본 시간은 `/rpg:status`, 상태창 아이템, 시간 정지 스킬 도감에서 확인합니다. 시전 메시지에는 실제 시전 시간과 증가한 숙련도를 표시합니다. 카멜레온이 학습한 시간 정지에도 같은 숙련도·흡혈 규칙을 적용합니다.

## 설치와 유지되는 기능

BP·Commands BP·RP 세 팩을 모두 **v0.6.15**로 활성화하세요. 기존 UUID와 다른 플레이어 데이터는 유지했습니다. 최소 Bedrock 1.21.100, Script API server 2.2.0 / server-ui 2.0.0입니다.

250×250 현재 위치 중심 마을·자동 이어짓기와 외곽 정리·지역 버프·카멜레온 더 월드/넨 학습·구욱·10단계 던전 수정 등 이전 변경도 포함합니다.

## 검증 범위

JSON·JavaScript 문법과 로컬 import, 실제 모듈 연결, 기존 기능 통합 테스트, 혈술사 카드의 주 손/조건/미소비/확인 후 재검사, 숙련도 1초 시작·0.1초 증가·6초 상한·중복/실패 방지, 흡혈 자동 우선 선택과 벽/아군/사거리/사망 제외, 50% 강화·비중첩·소비·실패 복구를 모의 API로 검증했습니다. 실제 Minecraft의 가져오기·스킨 렌더링·전투 실행은 이 환경에서 검증하지 못했습니다.

소스 ZIP에 테스트를 포함했습니다. Python 3·Node.js 24에서 새 변경 검증:

```sh
python3 checks/validate.py .
node --experimental-vm-modules checks/integration.mjs .
node --experimental-vm-modules checks/world.mjs .
```

이전 도시·던전·버프 회귀 테스트도 함께 포함합니다.
