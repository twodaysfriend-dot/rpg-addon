# 실제 게임 체크리스트 — 아직 미실행

## 전직·외형
- [ ] 백업 후 세 팩 0.5.90 적용, 콘텐츠/스크립트 로그 오류 확인.
- [ ] 일반 전직은 해금 미정으로 차단. 관리자 /rpg:force the_world로 전직 가능.
- [ ] 화살 1종 지급·5개 스킬·MP 확인.
- [ ] 인벤토리 아이콘 표시, 손에서는 1인칭/3인칭 숨김.
- [ ] 다른 아이템을 들어도 스탠드가 등 뒤를 따라오며 중복 생성 없음.
- [ ] 사망·직업 변경·종료 시 스탠드 제거, 재접속/차원 이동 후 정상 재생성.

## 스킬
- [ ] 무다: 전방 4칸 부채꼴, 벽 차단, 0.25초마다 6 × 8회.
- [ ] 무다!!!: 기본 10, 강한 넉백·1초 둔화.
- [ ] 로드로러다!!: 전방 최대 3칸, 벽 통과 없음, 기본 35.
- [ ] High한 기분: 신속 II 8초, 전용 평타 간격 0.5초 → 0.25초 후 원복.
- [ ] 근력·힘·장비·무기 강화 보정 및 기존 직업 스킬 동작 유지.
- [ ] 궁극기 MP 320, 보정 후 최소 300·쿨 20초·ULTIMATE_IDS 유지 규칙 확인.

## 시간 정지
- [ ] 반경 20칸·최대 60개체. 아군·길드원·자신/아군 투사체 제외.
- [ ] 일반 6초·보스 3초. 시전자는 이동·전용 공격 가능.
- [ ] 대상 플레이어 이동·시점 잠금, 미지원 환경은 둔화·위치/회전 고정.
- [ ] 전용 공격 중 HP 유지, 해제 순간 합산 피해 1회 적용.
- [ ] 이전 효과·입력 하위 권한·투사체 속도 복원.
- [ ] 시전자 사망·종료·차원 이동·직업 변경 즉시 해제, 남은 누적 피해 취소.
- [ ] 대상 사망/소멸, 청크 언로드/로드, 서버/스크립트 재로드 후 영구 잠금 없음.
- [ ] 골렘/외눈박이 예약 공격과 정지 몹의 새 투사체가 정지 중 공격하지 않음.
- [ ] 해제 후 몬스터 이동·공격 정상.

## 결투
- [ ] PvP장 준비 후 정지·누적 피해·비살상 패배·원위치 복귀.
- [ ] 같은 길드 상대는 정지만 제외되며 일반 결투 공격 가능.
- [ ] 항복·시간 초과·접속 종료로 결투가 끝나면 누적 피해가 뒤늦게 적용되지 않음.
- [ ] 종료 후 입력·최소 HP·복귀 상태 정상, 기존 10초 PK 판정 제외 유지.

## 1,000골드 TPA
- [ ] 상태창의 이동 요청/받은 이동 요청, /rpg:tpa와 /rpg:tpaaccept 확인.
- [ ] 요청·거절·닫기·30초 만료 무차감.
- [ ] 상대 수락 후 안전한 곳으로 이동 성공 시 요청자에게만 정확히 1,000골드 차감.
- [ ] 잔액 999 이하 차단, 정확히 1,000이면 0으로 성공.
- [ ] 요청 후 잔액 부족·대상 종료 시 무차감.
- [ ] 공간 없음·이동 실패·지갑 저장 실패 시 위치/골드 복구.
- [ ] 같은 요청 재수락으로 중복 차감 불가.
- [ ] 던전 대기/진행·PvP·시간 정지·사망/귀환 대기 중 요청/수락 차단.
